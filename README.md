# リンデンベルク村

仮想の村で、自分の頭で考えて暮らす人々を眺めるゲームです。
見下ろし型のドット絵3Dマップを、角度とズームを自由に変えながらのぞけます。

住人たちは、自分がAIだとは思っていません。
村には300年あまりの歴史があります。住人一人ひとりに曾祖父母や高祖父母までさかのぼる祖先がいて、両親、きょうだい、幼なじみがいます。
子どものころの思い出も持っていて、村の世界を本物だと思って生きています。
（実際には、ゲームを開くたびに歴史が一から生成されます。）

## 遊び方

`index.html` をブラウザで開くだけです。ただし、ES Modules を使うため、ローカルのWebサーバーが必要です。

```bash
python3 -m http.server 8000
# http://localhost:8000 を開く
```

| 操作 | PC | スマホ |
|---|---|---|
| 回転 | 左ドラッグ ／ Q・E キー | 1本指 |
| 移動 | 右ドラッグ | 2本指 |
| 拡大・縮小 | ホイール | ピンチ |
| 時間の速さ | 1〜4キー、スペースで一時停止 | 上のボタン |

- 住人をクリックすると、その人の「心の声」を見られます。気分と欲求、性格、家族と祖先、好きな人・苦手な人、記憶も一覧できます。
- 建物をクリックすると、そこに住む家族や中にいる人がわかります。
- 左のパネルでは、村の会話や出来事、住人一覧、年代記（村の300年史）、市場の値段を見られます。
- 村はブラウザに自動で保存され、次に開くと続きから始まります。

## 外部AI・APIは使っていません

住人の思考と言葉は、すべてブラウザの中で組み立てています。そのためAPI料金はかかりません。

| 仕組み | ファイル | 内容 |
|---|---|---|
| 歴史 | `js/history.js` | 開拓者の6家族から300年分の誕生・結婚・死・移住・事件（凶作、流行り病、大洪水、鐘楼の完成など）を計算し、家系図と一人ひとりの人生の記録を作る |
| 記憶 | `js/sim.js` | 人生の記録を、本人の記憶として持たせる（「7歳のころ、大凶作で毎日お腹をすかせていた」など）。新しい出来事も記憶に加わり、大事でない記憶は忘れていく |
| 性格 | `js/history.js` | ビッグファイブ（開放性・誠実性・外向性・協調性・神経症傾向）と、信仰・野心・家族愛。両親から受け継ぐ |
| 欲求と気分 | `js/sim.js` | 満腹・元気・つながり・楽しさの4つの欲求に、お金、最近の記憶、性格が合わさって気分が決まる |
| 意思決定 | `js/sim.js` | 時刻・欲求・性格・予定から、働く、食べる、市場で買う、酒場に行く、友人を訪ねる、祈る、遊ぶ、眠る、などを選ぶ |
| 言葉 | `js/speech.js` | 話題（天気、仕事、物価、家族、祖先の言い伝え、噂話、夢、幼なじみとの思い出、恋、口論など）を、記憶と人間関係から選ぶ。語尾や一人称は、話し方（子ども・老人・丁寧・荒っぽい・ふつう）で変わる |
| 噂 | `js/sim.js` | 結婚・出産・口論・酒場での失敗などが噂として人から人へ伝わる。聞いた人の記憶にも「〇〇から聞いた」と残る |
| 経済 | `js/sim.js` | 農夫・パン職人・漁師・木こり・鍛冶屋・大工・酒場の主人・商人・司祭・村長が働き、市場の在庫によって値段が上下する。困った家には村の蓄えから施しが出る |
| 人生 | `js/sim.js` | 恋、婚約、礼拝堂での婚礼、妊娠と出産、老いと死、弔い、14歳での見習い、68歳での隠居、収穫祭 |

## ファイル構成

```
index.html        画面
css/style.css     見た目
js/main.js        起動とゲームループ
js/sim.js         シミュレーション本体
js/history.js     300年の歴史と家系の生成
js/speech.js      言葉の生成
js/kin.js         続柄の計算
js/world.js       マップ（土地・道・建物・畑・湖・森）の生成
js/path.js        経路探索（A*）
js/render.js      Three.js による3D描画
js/textures.js    ドット絵テクスチャ・住人のドット絵
js/ui.js          パネルと吹き出し
vendor/           Three.js r170（MIT License）
```
