# エルデラント年代記

剣と魔法の大陸エルデラントで、人も動物も魔物も魔王も、それぞれ自分の目的で生きています。その様子を眺めるゲームです。
見下ろし型のドット絵3Dマップを、角度とズームを自由に変えながらのぞけます。

住人たちは、自分がAIだとは思っていません。
大陸には280年の歴史があります。王朝の交代、国どうしの戦争、歴代の魔王と、それを討った勇者たちがいました。
住人一人ひとりには祖先・両親・きょうだい・幼なじみがいて、子どものころの記憶を持っています。

## 遊び方

ES Modules を使うため、ローカルのWebサーバーで開いてください。

```bash
python3 -m http.server 8000
# http://localhost:8000 を開く
```

| 操作 | PC | スマホ |
|---|---|---|
| 回転 | 左ドラッグ ／ Q・E キー | 1本指 |
| 移動 | 右ドラッグ ／ ミニマップをクリック | 2本指 ／ ミニマップをタップ |
| 拡大・縮小 | ホイール | ピンチ |
| 大陸全体を見る | M キー ／「全」ボタン | 「全」ボタン |
| 時間の速さ | 1〜4キー、スペースで一時停止 | 上のボタン |

- 住人・動物・魔物・建物・地面をクリックすると、詳しい情報が見られます。
  - 住人：心の声、7つの欲求、経験から学んだこと、家族と祖先、人間関係、記憶
  - 動物・魔物：強さ、進化、種族として学んだこと
- 左のパネル：出来事・住人・国々（王、国庫、税、技術、関係、戦争、魔王、討伐隊、お尋ね者）・年代記・暮らし（町ごとの物価）・図鑑・墓地
- 画面上部の速報をクリックすると、その現場へ移動します。カメラが勝手に動くことはありません。「追いかける」中は、その人が建物に入ると中の様子が開きます。
- 世界はブラウザ（IndexedDB）に自動で保存され、次に開くと続きから始まります。

## 外部AI・APIは使っていません

すべての思考と言葉はブラウザの中で組み立てています。そのためAPI料金はかかりません。

| 仕組み | ファイル | 内容 |
|---|---|---|
| 大陸 | `js/world.js` | 標高・気温・湿度から地形を作る。川は山から海へ流す。国・町・城・特別な場所・道を配置する |
| 歴史 | `js/history.js` | 280年分の誕生・結婚・死・移住・王位継承・王朝交代・戦争・魔王と勇者を計算する |
| 7つの欲求 | `js/sim.js` | 生存欲・睡眠欲・食欲・性欲（恋慕や親密さとして表現）・怠惰欲・感楽欲・承認欲。ショートスリーパーとロングスリーパーもいる |
| 学習 | `js/sim.js` | 行動の結果で好みが変わる（強化学習）。仕事の腕が上がる（名人になると語り草になる）。危ない場所を覚え、会話で人に伝える |
| 目的 | `js/sim.js` | 王は国を治め、騎士は守り、冒険者は名声と宝を求める。学者は研究し、商人は町から町へ商いをする。盗賊は盗み、宿なしは物乞いをする。恋をし、身分違いの恋は反対されて駆け落ちすることもある |
| 犯罪と裁き | `js/society.js` | 盗み・追いはぎ・けんか・復讐・殺人。目撃者がいればお尋ね者になり、衛兵が捕まえて牢獄へ入れる。脱獄もある。盗賊団には懸賞金がかかる |
| 生き物 | `js/creatures.js` | 草食動物は草を食べて逃げ、肉食動物は飢えると狩る。魔物は縄張りを守り、群れが大きくなると村を襲う。倒した数と生き延びた日数で進化する。仲間が倒された場所を種族として覚えて避ける |
| 国と魔王 | `js/politics.js` | 王が税・祝宴・宣戦・魔王討伐令を自分で決める。戦争に負けた国は村を割譲する。研究で新しい技術が生まれ、隣国へ伝わる。魔王は目覚めると軍勢を送り町を占領する。討たれると、負けた原因への耐性を得て復活する |
| 文化 | `js/politics.js` | ことわざが会話で広まり、使われなくなると廃れる。大事件のたびに新しいことわざが生まれる（「〇〇の悲劇を忘れるな」など） |
| 言葉 | `js/speech.js` | 40以上の話題を記憶・関係・情勢から選ぶ。王には「陛下」、王族には「殿下」と呼びかけ、目上には丁寧に話す。王は「余」「そなた」を使う。同じ人が同じ台詞を繰り返さない |
| 見た目 | `js/sprites.js` | すべての人・動物・魔物を、個体ごとに違う見た目で4方向の歩行ドット絵として描く |
