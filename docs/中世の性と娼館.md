# 中世の性と娼館 ― 昔の町は「恋の欲」をどう扱ったか

社長の問い「ファンタジー世界の性欲を発散する方法を調べて。風俗店とかあった？」に答えるために、中世ヨーロッパの町の記録と、日本の遊郭、恋愛や祭りの習わし、いまのファンタジー作品とゲームの扱いを調べた読み物です。
**社会の仕組みとお金の流れの話として書いており、露骨な描写はしていません。**
はっきりした記録がないもの、検索の要約からしか確かめられなかったものは「推定」と書いてあります。出典は各章の終わりと、最後の一覧にまとめました。

先に答えを言うと、**ありました**。しかも中世の終わりごろのヨーロッパでは、多くの町が**町の役所みずから館を建て、決まりを作って営んで**いました。ただしその裏には、貧しさ・借金・暴力による縛りがあり、1500年代に病気の流行と宗教改革で一斉に閉じられます。

## 1. 中世ヨーロッパの「町が認めた館」

### (1) どこにあったか
| 地域 | 例 | 年代 |
|---|---|---|
| 南ドイツ・オーストリア・スイス | 「女の家（フラウエンハウス）」と呼ばれた町営の館。レーゲンスブルク（1306年）、チューリヒ（1314年）、バーゼル（1356年）、ウィーン（1384年）などに記録。ニュルンベルク、ネルトリンゲン、ウルム、アウクスブルク、ストラスブール、コンスタンツにも館と決まり書きが残る | 1300〜1500年代 |
| 南フランス | 町の役人（執政）が建てた館。トゥールーズの「大修道院（グランド・アベイ）」という皮肉な名の館は、1525年に城壁の工事のため取り壊され、役人たちは2年がかりで新しい場所を探して「緑の城（シャトー・ヴェール）」を建てた。教会・修道院・学校に近すぎる場所は、次々に却下された | 1300〜1500年代 |
| イングランド | ロンドン対岸のサザーク（テムズ川の南岸）の「スチュー」。ほかにサウサンプトンとサンドイッチ（どちらも船乗りの多い港町）に公の館 | 1100年代〜1546年 |
| イタリア | ヴェネツィアはリアルト（商いの中心）に「カステレット（小さな城）」と呼ばれる区域を作り、見張りを付けて囲った | 1300年代〜 |

- ドイツ語圏では、1350年ごろから1500年ごろにかけて、多くの町がこれを「町の公共の務め」の一つとして扱ったとされます。
- 場所は**町の外れ・城壁ぎわ・首切り役人の家の近く**が多く、「社会の外れ」を形でも表していました（イタリアのボルツァーノの例）。

### (2) なぜ町が自分で営んだのか
町の役人や教会が挙げた理由は、おおよそ次の4つでした。

1. **若い独身の男たちの乱暴を防ぐ**。中世の町では、職人の弟子や見習いは親方として独り立ちするまで結婚できず、20代後半まで独身の男が大勢いました。フランスの歴史家ロシオは、15世紀の南東フランスの町で、若者の集団による女性への暴力が繰り返されていたことを記録から明らかにし、町の館は「妻や娘の名誉を守るための仕組み」と考えられていたと論じています。
2. **場所を決めて閉じ込める**。町のあちこちで商売されるより、一か所に囲って見張るほうが治安を保ちやすい。
3. **税とお金**。館の借り賃や上がりは町の収入になりました。サザークでは土地の持ち主がウィンチェスター司教だったため、**司教が回り回って館の家主**になっていました。働く女性は「ウィンチェスターの鵞鳥（がちょう）」とあだ名されました。
4. **教会の「必要悪」の考え方**（第3章）。

## 2. 館の決まり ― 何が禁じられ、何が守られたか

### (1) サザークの決まり書き（イングランド）
「サザークの館の主たちの取り締まりについての決まり」という文書が残っています。司教側は「1161年（または1162年）、ヘンリー2世の議会で定めた」と主張しましたが、その時代に議会はなく、**文書そのものは1400年代のもの**と見られています。36〜39か条あり、違反ごとに罰金が決まっていました。

| 決まり | ねらい |
|---|---|
| **聖なる日（祝日）は戸を開けない** | 女性たちを教会の礼拝へ行かせる |
| **結婚している女性と修道女は置かない** | 家庭と教会の秩序を守る |
| **働く女性はいつでも自由に出入りできる。主は女性を館に住まわせてはならず、女性は好きな所に下宿してよい** | 住み込みにして借金で縛るのを防ぐ（逆に言えば、それが実際に行われていた） |
| **「燃える病」（性の病）にかかった女性は働かせない** | 病気を広げない |
| **客を借金のかたに館に閉じ込めてはならない** | 客への乱暴を防ぐ |

1506年ごろ、ヘンリー7世が18軒の館を一時閉じ、**1546年にヘンリー8世が布告で廃止**しました。病気が兵士や水夫に広がることを恐れたのと、教会改革の流れの両方が理由とされます。

### (2) ドイツの町の決まり書き（フラウエンハウスの掟）
ニュルンベルク、ネルトリンゲン、ストラスブール、コンスタンツ、ウルムなどに、1400年代後半〜1500年代初めの決まり書きが残っています。
- **聖なる日は休み**。
- **結婚している男・聖職者・ユダヤ人は客にしてはならない**。見つかれば**客のほうが重い罰金**。館の側は罰されないことが多かった。
- 一人の客と長く過ごしすぎた女性に罰金を科した町もある（客が特定の女性に入れあげて家庭を壊さないため）。
- 館の主（フラウエンヴィルト）は町と誓約を結んで雇われ、町の決まりを守る義務を負った。ウィーンでは主はいつも女性で、**およそ2年ごとに入れ替わった**。
- 決まり書きには、女性たちの最低限の権利を守り、**搾取を防ぐ**ための条項が入っていた。

### (3) 服装の印
- 13世紀から、身なりの決まり（奢侈令）で「ひと目で分かる印」を付けさせた町が多い。**場所ごとに違い、全ヨーロッパ共通の印はない**。
  - マルセイユ：縞の外套。イングランド：縞の頭巾。ヴェネツィア：黄色の肩掛け。
  - 時代が下ると、腕や肩に付ける布の帯や房に小さくなっていった。
  - 宝石や刺繍などの飾りを禁じた町も多い（ボルツァーノでは宝飾品の禁止）。召使いなど身分の低い女性一般への決まりと同じ扱い。
- 「黄色は娼婦の色」という話はよく聞くが、**全体に当てはまる決まりではない**という指摘がある。

### (4) 働く女性の立場 ― 借金と搾取
記録からは、決まり書きが守ろうとしたものと、現実との差が見えます。
- ドイツの町では、女性たちは**館の主に大きな借金を負っていることが多く**、借金ごと別の町の館へ「売り買い」されることもあった。
- **ネルトリンゲンの事件（1471〜72年）**：館で働くエルス・フォン・アイシュテットという女性が、女将からひどい扱いを受けたという噂が町の役所に届き、12人の女性全員と女将・主が取り調べを受けた。女将は顔に焼き印を押されて町から追放、主は職を解かれ、**翌1472年、町は新しい決まり書きを作って同じことが起きないようにした**。女性たちが声をそろえて訴え、役所が聞き入れた点が注目されている。
- ロシオがディジョン（フランス）の1440〜1540年の記録を調べたところ、**多くの女性が貧しさから家族に売られたり、暴力の被害で「嫁にいけない」とされたりして、この道に入った**。多くはとても若かった。
- 一方、イングランドを調べたカラスは、女性たちは限られた中でもある程度は自分で選んでいたと論じ、また**館の経営は中世の女性が自分で商売できる数少ない道**でもあったと指摘している。

### (5) 暴力への罰
- 13世紀の神聖ローマ皇帝フリードリヒ2世の法では、この職の女性であっても**本人の意に反して暴力をふるった者は死罪**とされた（検索要約による。推定）。
- つまり「館の女性だから何をしてもよい」という建前ではなかった。

## 3. 教会はどう見たか ― 「必要悪」と悔い改めの家

### (1) 「なくせば世が乱れる」
- 4世紀の**アウグスティヌス**は『秩序について』で「娼婦を人の世から除けば、欲のためにすべてが乱れる」と書いた。
- 13世紀の**トマス・アクィナス**は『神学大全』でこの言葉を引き、「治める者は、より大きな悪を避けるために、ある悪を**見のがすことが正しい場合がある**」と説いた。
- よく「アクィナスが『宮殿から下水溝を除けば宮殿は悪臭で満ちる』と言った」とされるが、これは**弟子筋のルッカのプトレマイオスが、アクィナスの書きかけの本を書き継いだ部分**の言葉で、アクィナス本人のものではない。

つまり教会は、**「罪ではあるが、町の秩序のために囲って見のがす」**という立場でした。館が聖なる日に閉まり、聖職者の客が禁じられたのも、この考えの裏返しです。

### (2) マグダラの家 ― 足を洗う道
- 聖書のマグダラのマリアは「悔い改めた罪の女」とされ、この道から抜けたい女性の守り手になった。
- **1227年、教皇グレゴリウス9世が「悔い改めたマグダラのマリアの修道会」を認可**。白い衣から「白い婦人たち」と呼ばれ、ゴスラー（1215年ごろ）、ウォルムス、ストラスブール（1220〜30年）などヨーロッパ各地の町に家を建て、足を洗いたい女性を受け入れた。
- 教会の施しや、町の有力者が持参金を出して**結婚させる**ことも「よい行い」とされた（推定。各地の慈善の記録からの一般的な傾向）。

## 4. 公衆浴場とのつながり

- 中世の町には、蒸し風呂や湯船のある**公衆浴場**がたくさんあった。「中世の人は風呂に入らなかった」は誤解。
- 英語の「スチュー」はもともと**湯気で蒸す浴場**の意味で、のちに館そのものを指す言葉になった。浴場の一部は、表向きは風呂屋、実は館という場所でもあった。
- 中世の物語では、浴場は**浮気の起きる場所**として描かれることが多い。
- テューリンゲン地方の町では、館のある「バラ小路（ローゼンガッセ）」と、浴場の並ぶ「湯屋小路」が**並んで通っている**例がいくつもある。

## 5. 終わり ― 病気の流行と宗教改革

- **1495年ごろ**、とても激しい症状の性の病（梅毒）がヨーロッパ中に広がった。はじめの数十年は重く、のちに長く続く軽い病に変わった。
- 町は病人を隔離し、浴場や館を「病の巣」とみて取り締まった。チューリヒでは1496〜1585年に隔離の記録が残る。デンマークの研究では、浴場の閉鎖は1520年代前半が一番多く、病気のほか**薪の値上がり**や、人前で裸になることへの考え方の変化も理由だった。
- 宗教改革の町は、**「必要悪」を認めず、罪そのものとして禁じる**方向に変わった。町の館が閉じられた年：
  - ウルム 1531年、アウクスブルク 1532年、バーゼル 1534年、フランクフルト 1560年、ニュルンベルク 1562年。
  - イングランドのサザーク 1546年。
- 閉じた後、商売はなくならず、**町の外や裏通りへ隠れた**。見張る場所がなくなった分、取り締まりはかえって難しくなった、という見方もある。

## 6. くらべる ― 日本の遊郭（かんたんに）

- **1617年（元和3年）**、幕府が江戸に公認の遊郭「葭原（よしわら）」を許した。のちの吉原。**一か所に囲って見張る**という発想は、ヨーロッパの町の館と同じ。
- 幕府は建前では人身売買を禁じていたので、女性は表向き「**年季奉公**」（期限つきの住み込み奉公）とされ、証文も交わした。**実際は、貧しい親が給金を前借りして娘を渡す、事実上の身売り**だった。年季はおよそ10年、28歳が年季明けの目安とされる。
- 一方で吉原は、芝居・浮世絵・流行の発信地でもあり、教養や作法を身につける場という面もあった。**華やかさと苦しさ（「苦界」）が同居していた**点も、ヨーロッパと似ている。

## 7. 恋と欲のほかの形 ― 館だけではなかった

中世の人々の「恋の欲」の多くは、館ではなく、**ふつうの暮らしの中の恋と結婚**で満たされていました。

| 形 | 中身 |
|---|---|
| **求愛と結婚** | 若者は市・教会・仕事場・祭りで相手を見つけた。家どうしの話し合いや仲人も大きな役割を持ち、持参金や婚礼の支度にお金をかけた |
| **五月祭** | 5月1日は古くから恋の女神の祭りの日とされ、中世にも恋の季節の祭りだった。若者が森へ花や枝を摘みに行き、五月柱のまわりで踊った |
| **若者組** | 13世紀ごろから「若者の修道院」と呼ばれる若者の集まりがあり、祭りを取りしきり、**村の縁組みにも口を出した**。年の差が大きい結婚や再婚には、鍋を叩いて家の前で騒ぐ「シャリヴァリ（からかい囃し）」で村の不満を表した |
| **酒場と踊り** | 酒場や広場の踊りは、男女が知り合う大事な場。教会はたびたび眉をひそめた |
| **吟遊詩人と宮廷恋愛** | 11世紀末、南フランスの吟遊詩人（トルバドゥール）が恋の歌を広めた。騎士が貴婦人に仕え、その名誉のために手柄を立てる「宮廷恋愛」は、**触れない恋・憧れの恋**を美しいものとした。ドイツのミンネゼンガーも同じ流れ |

## 8. ファンタジー作品とゲームではどう描かれているか

### (1) 小説

## 9. まとめ ― 社長の問いへの答え

- **風俗店にあたるものはあった。** 中世の終わりのヨーロッパでは、多くの町が**町営の館**を町の外れに置き、決まりを作って管理した。イングランドでは教会の司教が家主だった。日本でも幕府が吉原を公認した。
- **町が管理した理由**は、独身の若者の乱暴を防ぐ・一か所に囲う・税。教会も「より大きな悪を防ぐための必要悪」として見のがした。
- **決まり**：聖なる日は休み、既婚の男・聖職者・よそ者（ユダヤ人）は客にできない、結婚している女性は働けない、病気の女性は休ませる、服装の印、住み込みと借金で縛るのを禁じる。
- **現実**は、貧しさ・借金・暴力で縛られた女性が多く、町は事件が起きるたびに決まりを足した。
- **足を洗う道**として、マグダラの修道会や、持参金を出して結婚させる施しがあった。
- **1495年ごろの病気の流行と宗教改革で、1530〜60年代に一斉に閉鎖**。商売は裏へ隠れた。
- 恋の欲の多くは、館ではなく**求愛・結婚・祭り・踊り・恋歌**で満たされていた。

## 10. エルデラントでの表し方（提案）

### (1) いまのゲームの流れ（調べた結果）
- 性欲（恋の欲）は、17歳以上だけが持つ。満たし方は **贈り物・逢い引きの食事（酒場）・仲人への礼金（教会）・婚礼の支度・夫婦の営み**（すべて抽象的）。
- 大人向けの重い要素は、設定の「大人向け」（matureCrimes）が有効なときだけ裏社会の仕組みで起き、当事者は必ず18歳以上。
- お金の置き場は、家計・財布・町の蓄え・国庫・施し箱など。病気（p.ail）と薬屋もある。

### (2) 二つの形 ― 設定で切り替える

| | 「大人向け」が有効 | 「大人向け」が無効（初期の公開版はこちらを推奨） |
|---|---|---|
| 建物 | 町が認めた**「歓楽の館」**（町の外れ・城壁ぎわ・浴場の隣） | 建てない。すでにある館は**「湯屋」**（ただの公衆浴場）として表示 |
| 満たし方 | 独身の大人が「歓楽の館を訪れた」 | **酒場の踊り**、**五月祭などの祭りの踊り**、**吟遊詩人の恋歌を聴く**、**湯屋でくつろぐ**、逢い引き、仲人、結婚 |
| 画面の文 | 「〇〇は歓楽の館を訪れた」だけ | 「〇〇は酒場で踊った」「〇〇は吟遊詩人の恋歌に聞きほれた」 |

- **画面には建物と「訪れた」という文だけ**。館の中は描かない、働き手の姿も館の外には出さない（内装も作らない）。
- 無効のときは、館・働き手・関係する噂・日誌の行を**すべて出さない**（公開先の審査のため）。

### (3) 館の決まり（史実を元にした案）
| 決まり | 中身 | 元になった史実 |
|---|---|---|
| **許可** | 町（町長か領主）が館の主に許可を出す。主は町と誓約し、毎月**借り賃（上がりの一部）を町の蓄えに納める** | 南ドイツの誓約、サザークの司教 |
| **場所** | 町の外れ・城壁ぎわ。教会・学校（寺子屋）・王城から一定の距離を離す | トゥールーズで場所を2年探した話 |
| **大人だけ** | 客も働き手も**18歳以上だけ**。未成年は近づくことも数えない | ― （このゲームの絶対の決まり） |
| **休みの日** | 聖なる日・祭日・休日は閉める | 各地の聖日休業 |
| **客の制限** | **結婚している人・聖職者・騎士団の誓いを立てた者**は客になれない。見つかれば客に罰金（評判も下がる） | 既婚者・聖職者の禁止 |
| **働き手の自由** | 住み込みにしない。いつでも辞められる。借金のかたに縛るのは罪 | サザークの決まり |
| **病気** | 病気の働き手は休ませる。町の医者か修道女が定期的に見回る | 「燃える病」の条項 |
| **服装の印** | 働き手は色の帯を付ける（見た目に小さく出すだけ。省いてもよい） | 奢侈令 |

### (4) 代金とお金の流れ（出どころと行き先）
**お金は訪れたときの取り引きでしか動かさない**（働いている最中に湧かない）。

| お金の動き | 払う側 → 受け取る側 | いつ |
|---|---|---|
| 館を訪れた代金（例：銅貨6〜10、町の豊かさで変える） | 客の財布 → **館の主の家計** | 訪れたとき |
| 働き手の取り分（代金のおよそ半分） | 館の主 → **働き手の家計** | 給料日（主が雇い主） |
| 館の借り賃と税（上がりの2割ほど） | 館の主 → **町の蓄え** | 税の日 |
| 違反の罰金（既婚者・聖職者の客、聖日の営業） | 違反した人 → 半分は告げた人、半分は**施し箱** | 捕まったとき |
| 足を洗うときの支度金 | 施し箱（教会） → 本人 | 教会が引き受けたとき |
| 館の物の仕入れ（酒・布・薪・石けん） | 館の主 → 商人・酒場・職人 | 仕入れのとき（品物の循環にのせる） |

- 値段は、使う人が多い町ほど下がりすぎないよう、**働き手の人数で上限**を持たせる（無駄に増やさない）。

### (5) 人の気持ちと評判
- 満たされる欲：性欲が大きく下がる（例：−40）。楽しみも少し上がる。
- **評判（見栄・名誉）**：訪れた人は、人に知られると承認欲が少し下がり、噂になる（「〇〇が館の方へ歩いていくのを見た」）。**結婚している人が行くと、配偶者との仲が大きく下がる**（夫婦げんか・別居のきっかけ）。
- 性格で行く・行かないが分かれる：信心深い人・誠実な人はほとんど行かない。独身の若い職人・兵士・船乗り・冒険者は行きやすい（史実でも港町と兵士が主な客）。
- **働き手の評判**：町の人からは低く見られる（結婚しにくい）。ただし**教会の支度金で足を洗うと、数年で評判が戻り、結婚もできる**（マグダラの家）。

### (6) 病気と教会
- 館を訪れると、ごく低い確率で「**恥の病**」（名前は抽象的に）にかかる。医者か修道女の見回りがある館ほど確率が下がる。
- 病が町で流行ると、**王や町長が館を閉じる**ことがある（1495年の流行と閉鎖の再現）。閉じたあとは、裏社会に**もぐりの商売**が生まれやすくなる（見張れなくなるので治安が少し悪化）。
- 教会の考えは王・司祭ごとに変える：「必要悪として見のがす」か「罪として閉じよ」か。**信心深い王の国では館が作られない**。国ごとの違いが物語になる。

### (7) 犯罪と取り締まり（裏社会とつなぐ）
- **借金の縛り**（働き手を借金で辞めさせない）：館の主の罪。役人に見つかると主は職を解かれ、働き手の借金は帳消し（ネルトリンゲンの事件の再現）。
- **人身売買**（本人の意思でなく連れてこられる）：重い罪。裏社会の誘拐・恐喝とつなげ、捕まれば追放か長い禁固。**被害者は保護され、施し箱から支度金**。
- **もぐりの館**（許可なしの営業）：罰金と取り壊し。
- 暴力をふるった客は、相手の職にかかわらず重く罰する（フリードリヒ2世の法の考え）。
- これらはすべて**事件の記録に年齢を残し、18歳未満がかかわっていないか点検**する（いまの裏社会の仕組みと同じ）。

### (8) 描写の決まり（必ず守る）
1. 画面・日誌・会話に**露骨な言葉を一切出さない**。使う言葉は「歓楽の館」「訪れた」「働き手」「館の主」まで。
2. 館の中（内装）は作らない。人が入ると姿が消え、しばらくして出てくるだけ。
3. **18歳未満は客にも働き手にもならない。近くの噂にも出さない。**
4. 「大人向け」が無効のときは、館・働き手・病・噂・罪の種類ごと**すべて出さない**。代わりに第(2)節の健全な形だけを使う。
5. 公開版（Cloudflare Pages と、将来の CrazyGames など）では**初期は無効**にし、有効にするには本人が設定で選ぶ形にする。
