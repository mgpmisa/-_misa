# 世界の物の決まり（素材管理部の共通ルール）

社長の指示：世界にある物を約5000種類つくる。すべて手に入り、すべてに利用価値がある。土を掘れば土や泥、石を掘れば砂利や石ころが手に入る。

## 1. 置き場所
- 物のデータは `js/catalog/` に分類ごとのファイルで置く（例：`js/catalog/earth.js`）。
- 各ファイルは `export default [ {...}, {...} ]` の形で、物の一覧を返すだけにする（処理は書かない）。
- 仕組み（採る・作る・使う）は `js/matter.js`（開発部）が受け持つ。

## 2. 1つの物の書き方
```js
{
  id: 'gravel',            // 英小文字と _ 。世界で1つだけ。ほかの分類とかぶらないよう、分類の頭文字を付けてもよい
  name: '砂利',             // 日本語の名前（ファンタジーらしく。カタカナの現代語は使わない）
  cat: 'earth',            // 大分類：earth 大地・鉱物 / plant 植物 / beast 動物・魔物 / food 食べ物・飲み物 / gear 道具・装備 / arcane 魔法・宝・趣味
  sub: 'stone',            // 小分類（自由。例：stone, soil, ore, metal, gem, herb, wood, meat, hide, drink, weapon, bag ...）
  w: 1.5,                  // 1個の重さ（kg）
  v: 0.3,                  // 値打ち（銅貨。ふつうの働き手の日当が8〜10銅貨、パン1個3銅貨）
  stack: 20,               // 1枠に重ねられる数（1なら重ねられない）
  rare: 0,                 // めずらしさ 0ふつう 1少ない 2まれ 3とてもまれ 4伝説
  src: [                   // どこで・どうやって手に入るか（1つ以上。必ず書く）
    { how: 'dig', on: ['rock', 'hill', 'mountain'], rate: 0.6 },
  ],
  use: [                   // 何に使えるか（1つ以上。必ず書く）
    { k: 'craft', note: '道の敷き石・漆喰の材料' },
    { k: 'build' },
  ],
  // 任意の項目
  make: { from: { clay: 2, straw: 1 }, by: 'potter', t: 2 }, // 作り方：材料・作る職業（JOBS の id か新しい職業名）・かかる時間（時間）
  food: 12,                // 食べられる物：空腹が満たされる量（1食＝30）
  drink: 10,               // 飲める物：のどの渇き
  keep: 3,                 // 腐るまでの日数（腐らない物は書かない）
  eq: { slot: 'bag', cap: 6, kg: 15 }, // 装備できる物（slot: weapon/armor/shield/head/hands/feet/bag/accessory/tool）
  fx: { hp: 5 },           // 使ったときの効き目（薬・魔法の品など）
  desc: '川原や崖の下でとれる小石の集まり。',   // ひとことの説明
}
```

### how（手に入れ方）の決まった言葉
`dig`（掘る）・`mine`（採掘）・`chop`（木を切る）・`gather`（摘む・拾う）・`harvest`（畑で収穫）・`fish`（釣り・漁）・`hunt`（狩る・倒した獣や魔物からはぎ取る）・`milk`（乳しぼり・毛刈りなど家畜から）・`craft`（作る。make を書く）・`cook`（料理。make を書く）・`brew`（酒や飲み物を造る。make を書く）・`loot`（宝箱・遺跡・ダンジョン）・`trade`（遠い国から商人が運んでくる）・`forage`（野で探す）

### on（場所）の決まった言葉
地形：`grass` `forest` `dense` `jungle` `savanna` `desert` `snow` `tundra` `swamp` `beach` `river` `lake` `sea` `deep` `hill` `mountain` `rock` `cave` `volcano` `field` `farm` `town`
魔物・獣から：`hunt` のときは on に種族の id（js/data.js の SPECIES：wolf, bear, dragon, slime など）を書く。
場所：`dungeon` `ruins` `demoncastle` `pyramid` `mine`

### use の k（利用価値）の決まった言葉
`craft`（作る材料）・`build`（建材）・`food`（食べる）・`drink`（飲む）・`fuel`（燃やす）・`medicine`（薬・治療）・`magic`（魔法・錬金）・`trade`（売り物として高い）・`luxury`（嗜好品・ぜいたく品）・`hobby`（趣味）・`collect`（収集品・飾り）・`ritual`（祈り・儀式・供え物）・`tool`（道具として使う）・`wear`（着る・装備）・`feed`（家畜の餌）・`fertilize`（畑の肥やし）・`dye`（染め物）・`gift`（贈り物）・`quest`（依頼の品）

**すべての物に、1つ以上の use を書くこと。** 使い道のない物は作らない。
**すべての物に、1つ以上の src を書くこと。** 手に入らない物は作らない。
**make の材料はすべて、どこかの分類ファイルにある id にすること。** 分類をまたぐ材料は、ほかの担当の id を使ってよい（`js/catalog/_ids.md` に、各担当が作った id の一覧を随時書き足す）。

## 3. 約束
- 名前はファンタジー世界にふさわしい日本語。実在の地名・商品名・現代の道具（電気・プラスチックなど）は使わない。
- 同じ物を2つ作らない。似た物は、産地・質・加工の違いで意味のある差を付ける（例：川砂・海砂・火山砂）。
- 値打ちと重さは、ほかの物とつり合いを取る。宝石は軽くて高く、石材は重くて安い。
- 今ある品（js/data.js の GOODS 20種、js/items.js の ITEMS 44種）は、同じ id で必ず含める（wheat, bread, fish, meat, wood, ore, tools, weapons, ale, cloth, furniture, gem, honey, wool, herbs, medicine, shoes, pottery, jewelry, stone と、ITEMS の各 id）。
- お金は取り引きでしか動かない（社長の決まり）。値打ちは「売り買いの目安」で、持っているだけでお金が湧くことはない。

## 4. 値段の決まり（社長の指示：市場にどれだけあるか・手に入れやすさ・有限度で変える）
- `v` は「ふつうの時の目安の値打ち」。実際の売り買いの値段は、仕組み（js/matter.js と経済部の市場）が毎日決める。
  - **市場にどれだけあるか**：その町の在庫が、欲しがる人の数（需要）より多ければ安く、少なければ高くなる。
  - **手に入れやすさ**：`rare` が高いほど、値上がりの幅が大きい。季節や天気で採れない時期は高くなる。
  - **有限度**：採り尽くせる物には `limit` を書く。残りが減るほど値段が上がる。
- 各担当は、物ごとに次の項目を書き足す。
  - `limit`：有限な物の目安。例として `limit: 'vein'`（鉱脈。掘れば減り、長い年月で少し戻る）、`limit: 'grove'`（林や群生地。切れば減り、育てれば戻る）、`limit: 'herd'`（群れ。狩れば減り、子が生まれて戻る）、`limit: 'relic'`（遺物。世界に数えるほどしかない）、`limit: 'none'`（土・水・砂のようにほぼ尽きない）。書かなければ、作って増やせる物とみなす。
  - `demand`：ふだん欲しがられる度合い。0（ほとんど誰も要らない）〜3（誰もが毎日要る）。例：パン3、塩3、薬草2、宝石1、化石0。
