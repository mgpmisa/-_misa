# 子どもの経験と職業（企画部）

社長の指示：「子どもの頃の経験で、大人になって就く職業が決まる。家庭環境とお金で、できる経験が変わる。」
この文書は、そのまま開発部・グラフィック部への指示書になるように、数字を入れて書く。

お金の目安（今の世界）：大人の日給＝9銅貨、パン1個＝3銅貨、1年＝40日（1季節＝10日）、子どもは14歳の誕生日に最初の職に就く。
家計の蓄え（種12345で測った値）：下から1割＝44銅貨、真ん中＝83銅貨、上から1割＝158銅貨、上から1分＝545銅貨。子ども（13歳以下）は744人中207人。

## 2. 子どもの経験（経験の種類）

子どもは行動するたびに「経験」がたまる。14歳の職選びは、この経験・生まれつきの才能・家業・町の事情で決まる。
経験は18種類。値は0〜100。

### 2-1. たまり方（数式）

- 1時間あたり：`xp += 率 × 0.12 × (1 − xp/110) × 年齢係数 × 先生係数 × 才能係数`
  - 年齢係数：4〜5歳 0.6、6〜9歳 1.0、10〜13歳 1.2
  - 先生係数：一人で遊ぶ 1.0、親の手伝い 1.2、お金を払って習う 1.5、住み込みの修業（小姓・修道院・学園） 1.7
  - 才能係数：その経験に対応する能力の素質 `p.gr.pot`（5〜16）から `0.7 + (pot − 10) × 0.06`（0.4〜1.06）。魔だけは素質（魔の芽）がない子は ×0.25
- 目安：同じ遊びを300時間（毎日2時間×150日＝約4年）で約30、800時間で約64。習い事に毎日通う子は60〜80に届く。
- 13歳を過ぎた経験は、子ども時代の記録として残し（`p.kid.xp`）、以後は増えない（大人の成長は今の growth.js の技能で続く）。
- 行動のたびに、今の growth.js の技能と能力も「子ども率 0.5倍」で伸ばす（既存の train と gainStat を呼ぶだけ）。

```
経験点 = 主の経験/50 + 副の経験/100            （表4-2。0〜3くらい）
才能点 = Σ(その職の能力の素質 pot − 10) / 3 / 能力の数   （−1.5〜2）
家業点 = 親と同じ職なら 1.5（家に畑・店・船・工房・爵位がある）／0.7（ない）
町の不足点 = 町に足りない職なら 0.8（今の lackingJobs を使う）
夢点   = 夢（p.dream）がその職なら 0.8
身分点 = 貴族・王族の子が貴族を選ぶなら 3、騎士の子が騎士の道なら 1
```

- 「必要な条件」を満たさない職業は候補から外す（表4-2の右の列）。
- 経験がどれも20未満の子（何もしなかった子）は、今どおり家業か町の不足で決める。
- 見習いで始まる職（魔法使い・騎士・学者など）は、14歳では「見習い」として就き、17〜20歳に一人前の判定をする（今の career.js の弟子のしくみを使う）。

### 4-3. 親の職業を継ぐ割合

- ねらい：全体で4〜5割が親の職を継ぐ（中世はこれより高いが、ゲームとして動きを出す）。
  - 家に財産がある家業（畑・店・船・工房・爵位）：6割
  - 財産のない雇われ仕事（人夫・召使い・兵士）：3割
  - 物乞い・盗賊の子：2割（残りは働く子の道へ）
- 家業の手伝い（3-B）で家業の経験が自然にたまるので、上の点数だけでおおむねこの割合になる。試験で測って、家業点を0.2きざみで直す。
- 別の経験が家業の経験より20以上高い子は、「家業を継がない」と言い出す（記憶と親子の会話が生まれる。親との好感度 −5、ただし30%で親が応援する）。

### 4-4. 才能（生まれつき）と経験の混ぜ方

- 才能：今の growth.js の素質 `p.gr.pot`（5〜16。親から半分ほど受け継ぐ）と、魔の芽（hash で決まる12〜22%）。
- 経験のたまりやすさに掛かる（2-1の才能係数）。才能のある子は同じ遊びでも1.5倍ほど早く伸びる。
- 点数では経験1.0に対して才能0.6。**経験が才能より重い**（社長の指示：子どもの行動で決まる）。
- 才能が高いのに経験がない子（例：知力の素質14なのに学校に行けない）は、「もったいない子」として4-5の拾い上げの候補になる。

## 7. 今のコードとの差

| いま | 問題 | この案でどうするか |
|---|---|---|
| 6〜13歳の全員が朝8〜12時に学校へ（sim.js decide の 'school'） | 貧しい子も貴族の子も同じ。学費がない。村の子も教会へ「登校」 | 家の段階で、学校・手習い・働く・家庭教師に分ける。学費を取る |

## 8. 実装の段取り

新しいファイル：`js/childhood.js`（開発部）、`js/anim_kids.js`（グラフィック部 人の担当）。本体への差し込みは部長。

### 状態（古いセーブでも動くように）

```
p.kid = p.kid || { v: 1, xp: {}, hrs: {}, tier: 3, lessons: {}, events: [], fav: null }
  xp     … 経験18種（0〜100）
  hrs    … 行動ごとの通算時間（格闘の時間・使い走りの回数などを数える）
  tier   … 家の段階（1〜5。季節のはじめに決め直す）
  lessons… 通っている習い事 { dojo: 来季まで, tutor: 次の日, … }
  fav    … 一番好きな遊び（会話と記憶に使う）
S.childhood = S.childhood || { v: 1, scholars: {}, picked: {}, stats: {} }
```
古いセーブの子は、今の年齢・家の段階・親の職から、これまでの経験を推定して作る（今の growth.js の ensureGrowth と同じ考え方）。

### 本体から呼ぶ関数

| 関数 | 呼ぶ場所 | すること |
|---|---|---|
| `childOptions(sim, p, add)` | sim.js decide の 'school' と 'play' の行（714〜716行）を置き換え | 年齢・時刻・季節・場所・家の段階・親の職・お金から、できる行動を候補に足す。行動の種類は `'kid'`、中身は `a.k = 'chanbara'` |
| `childDo(sim, p, dt)` | sim.js の行動中の処理（'school' の case の近く） | 経験をためる。駄賃・危険・出来事 |
| `childHourly(sim, people)` | growthHourly のあと | 技能と能力を子ども率で伸ばす |
| `childDaily(sim)` | newDay | 家の段階・月謝の支払い・奨学・拾い上げ・魔力の目覚め |
| `childFirstJob(sim, p)` | sim.js 1949行の civicFirstJob の代わり（中で chooseYouthJob を最後の手段に呼ぶ） | 4-1の点数で職を選ぶ |
| `childAnim(sim, p, a)` | anim_people.js の personAnimState の頭 | `a.k` から動きの名前を返す |
| `childCard(sim, p)` | ui.js の人物欄 | 「子ども時代」：好きだった遊び、経験の上位3つ、習い事、出来事 |

会話への利用：大人になっても `p.kid.fav` と出来事（E1〜E8）を話題にする（「子どものころ、川で溺れかけてね」）。社長の指示「その人の経験・記憶から話す」に合う。

### 段取りと規模

| 段 | 中身 | 担当 | 規模 |
|---|---|---|---|
| 第1段（先にやる） | 経験の器（p.kid）、家の段階、学校・手習い・家庭教師・道場・学園の有料化と支払い、14歳の職選び（childFirstJob）、家の手伝いを経験につなぐ。行動は主な20種（1,3,5,6,7,10,13,19,27,28,30,32,33,34,36,46,54,59,60,69〜72,75,76） | 開発部 | childhood.js 約700行、本体の差し込み約20行 |
| 第2段 | 残りの行動（3-A〜3-E すべて）、危険と出来事E1〜E8、貧しくても上がれる道、冒険者の職業への上乗せ | 開発部 | ＋約600行 |
| 第3段 | ドット絵の動き（新規約20、使い回し約40） | グラフィック部（人の担当） | anim_kids.js 約800行 |
| 第4段 | 民族の里（89〜93）、人物欄「子ども時代」、会話の話題 | 開発部・物語部 | ＋約300行 |

試験の目安（開発部がヘッドレスで確かめる）：
- 40日（1年）×5回し。13歳以下の子の行動の内訳が、段階ごとに5-2の表に近いこと。
- 14歳になった子の職のうち、親の職を継ぐ割合が4〜5割。経験が主の理由で選ばれた職が3割以上。
- 困窮の子の1割以上が、奨学・拾い上げ・冒険者などで「上の道」に進む。
- 月謝の合計＝受け取った側の増えた分（お金の出どころと行き先が合うこと）。
- 子どもが一人も学校に行かない町、全員が同じ遊びをしている町がないこと。
