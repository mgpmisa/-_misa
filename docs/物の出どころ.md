- 調べ方：tools/catalog/origin.mjs（seed 12345、2日回して、実在する地形・建物・生き物・職業を数えてから判定）
- 全5599品のうち、今の仕組みで手に入る（〇）4654品、手に入らない（×）945品。2日の試験で実際に誰かが手に入れた品は452品。
- 季節：目録に季節の項目はない。畑の収穫は季節で量が変わり（春0.9・夏1.3・秋2.4・冬0.25倍）、薬草園も冬はほとんど採れない（0.15倍）。
- 町の中の決まり（今回の直し）：町の中（建物の中・通り・広場・町の囲いの内）では、野に自生する草・花・虫・小さな獣を摘まない。町で拾えるのは井戸水・雨水・くず鉄・石ころ・ぼろ布などだけ。薬草は、薬草摘みが町の外の森・草原・川辺・沼で摘むか、町の薬草園で園丁が育てて収穫する。

## 直したこと・残りの案

- 直した：町の中で野の草・花・虫を摘む／薬師が店で草を摘む／薬草摘みが町の中でも薬草を得る → 町の外の野山へ出かけて摘む。町に薬草園（園丁が育てて収穫、市場で売って代金を受け取る）。
- 残り：上の「作り手がいない」職（宝石細工師・錬金術師・醸造家・肉屋・絵描き・書記・炭焼き）が世界に1人もいないため、約929品が作られない。職の割り当てか、目録の作り手を今いる職にまとめる（matter.js の MAKER）必要がある。
- 残り：馬・らくだ・となかいを飼う人がいないので乳・たてがみなどが出ない。魔王城・遺跡で「摘む・掘る・切る」物は、宝箱の中身にも入れるか、魔王城の周りの地形で採れるようにする。
- 残り：墓地の苔（grave_moss）は、墓守が墓地で採れるようにすると意味が通る。
