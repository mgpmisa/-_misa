# 物の出どころ（棚卸し）

経済部（素材の担当）がまとめた。目録（js/catalog/*.js）の「出どころ」と、世界で実際に手に入る仕組み（matter.js・creatures.js・sim.js の宝探し・家畜）を、スクリプトで突き合わせた結果。

- 調べ方：tools/catalog/origin.mjs（seed 12345、2日回して、実在する地形・建物・生き物・職業を数えてから判定）
- 全5599品のうち、今の仕組みで手に入る（〇）5599品、手に入らない（×）0品。2日の試験で実際に誰かが手に入れた品は482品。
- 季節：目録に季節の項目はない。畑の収穫は季節で量が変わり（春0.9・夏1.3・秋2.4・冬0.25倍）、薬草園も冬はほとんど採れない（0.15倍）。
- 町の中の決まり：町の中（建物の中・通り・広場・町の囲いの内）では、野に自生する草・花・虫・小さな獣を摘まない。町で拾えるのは井戸水・雨水・くず鉄・石ころ・ぼろ布などだけ。薬草は、薬草摘みが町の外の森・草原・川辺・沼で摘むか、町の薬草園で園丁が育てて収穫する。

- 3つの世界（seed 12345・777・4242、各2日）での × の数：第1段のあと 945品 → 第2段のあと 0・242・0品。seed 777 の242品は粉屋が1人もいない世界の粉ものの品（粉屋・肉屋・酒造りがいなくなる不具合は食べ物の流れの担当が直している）。

### 作れない物（0品）

作り手の職の人が世界にいない（宝石細工師・錬金術師・醸造家・肉屋・絵描き・書記・炭焼きなど）か、材料のどれかが×のもの。


## 直したこと

- 第1段：町の中では野の草・花・虫を摘まない。薬草摘みは町の外の野山へ。町に薬草園（園丁が育てて収穫し、市場で売る）。
- 第2段（js/artisans.js ほか）：
  - 世界にいなかった職人を置いた：王都に宝石職人・錬金術師・書記・画家（人手が空いていれば）、森のそばの町と村に炭焼きと町はずれの炭焼き窯。農夫・漁師は回さない。
  - 人手がなく置けない町のために、近い職が代わりに作る（錬金術師→薬師・魔法使い、書記→司書・学者、画家→陶工・機織り、宝石職人→鍛冶屋、船大工→大工、石工→鉱夫、醸造家→宿屋の主人、肉屋→狩人、香づくり・付与術師・杖職人・紙すき・製本など）。
  - 家畜：王国の馬は馬丁（いなければ御者・牧場主）の家が世話をし、乳・毛・たてがみが出る。砂地の町と里はらくだ、寒い土地はとなかいを2頭ずつ飼う。
  - 魔王城・遺跡・ピラミッドでしか採れない物は、探索の宝箱の中身にも入る。墓の苔は墓守が墓地で集める。猫を飼う家は抜けたひげを拾う。
  - 民族の里の薬草摘みも、里の外の森・草原へ出かけて摘む。
  - 目録の誤り：兎の足のお守りの材料が自分自身だったのを、兎の足（b_rabbit_foot）に直した。

## 残りの案

- 目録に季節の項目がない。旬のある物（山菜・きのこ・果物）に季節を持たせると、市場の値動きに意味が出る。
- 画家の仕事場は広場（画架）。画房を建物として置くかは今後。
