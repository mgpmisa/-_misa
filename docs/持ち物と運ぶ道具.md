# 持ち物と運ぶ道具 ― 人はどれだけ持てたか、袋やかごは誰が作ったか

エルデラント年代記で「持ちきれない宝や獲物をどうするか」を考えるために、中世ヨーロッパと日本の、人と動物が運べた量、運ぶ道具、麻と亜麻、倉庫、職業ごとの道具を調べた読み物です。最後に、ファンタジー作品やゲームでの工夫と、この世界への提案（数字つき）をまとめました。
社長の問い「人々の持ち物は何個まで持てるか？ ポーチや袋やリュックは市場に出回っているか？ 麻などの素材はあるか？」に、この順で答えます。
はっきりした記録がない数字は「推定」と書いてあります。今回は多くの資料ページを直接開けなかったため、検索結果の要約から取った数字には「（要約による）」と添えました。出典は各章の終わりと、最後の一覧にまとめました。

## 0. 今のエルデラントはどうなっているか（部長の確認と調査部の確認）

- 持ち物は**1人24個まで**。同じ素材や薬は1枠に重ねられるが、剣・鎧・宝などは1個で1枠。
- 25個目が入ると、**いちばん古い品が黙って消える**。宝を拾った冒険者は、知らないうちに最初の剣や薬を失っている。これは不具合。
- 袋・かご・リュック・ロープ・麻・亜麻・柳・藁は、品物にも素材にもない。
- 荷車と船は隊商だけのもの。船には「30個まで」の上限があるが、荷車には上限がない。
- 厩舎と、馬・ロバは家畜として**すでにいる**。荷を運ぶ役目はまだない。
- 家の蔵（食料）はあるが、町の倉庫を借りる仕組みはない。
- 住人には「力」の値がない（体力・攻撃・腕前はある）。品物にも重さがない。

つまり答えは「**24個まで。袋もかごも市場にない。麻もない**」です。

## 1. 中世の人は、どれだけ運べたか

### (1) 人が背負える重さ
| 誰が | 重さ | どんな条件で |
|---|---|---|
| ローマの兵士（訓練） | 約20kg | 約30kmを夏の5時間で歩く（要約による） |
| ローマの兵士（行軍の荷） | 約27kg（武器と鎧をのぞく）、全部で30〜45kg | 15日分の食料・鍋・食器・杭などを、棒（フルカ）の先に吊るして肩にかついだ |
| 厳しい将軍の兵 | 最大約67kg | 紀元前143年、スペインでの例。特別に重い |
| 江戸時代の米俵 | 約60kg（四斗） | 「大人なら男女を問わず誰でも運べる重さ」として決めたと、江戸末期の文書にある（要約による）。ただし短い距離の話 |
| ネパールの荷運び | ふつう20〜50kg、調査では平均約73kg | 大きな背負いかご（ドコ）と、額にかける帯（ナムロ）で運ぶ。15秒歩いて45秒休む、夜明けから日暮れまで歩く |
| 日本の歩荷・強力 | 数十kg、100kgを超える者も | 山小屋や山頂へ荷を上げる専門の人 |

**まとめ**：ふつうの大人が**一日じゅう歩いて運べるのは20〜30kg**。鍛えた者で40kg前後。60kgは短い距離なら持てるが、一日は歩けない。
そして大事なのは、**手で持つだけなら10kg前後が限度**で、**袋・かご・背負子があって初めて20〜30kgを運べる**ということです（推定）。道具があるかどうかで、運べる量が2〜3倍変わります。

### (2) 動物の背中
| 動物 | 荷の重さ | 一日に進む距離 |
|---|---|---|
| ロバ | 体重の2〜3割、目安60kg | ゆっくり |
| ラバ | ふつう70〜90kg、最大140kg | — |
| 荷馬（小型の馬） | 約110kg（左右2つのかご「パニエ」に分ける）、最大180kg | 平均約40km。8時間ほど、ほとんど休まず歩く |
| 日本の馬一駄 | 三十六貫＝約135kg（江戸時代の決まり） | — |

- イングランドの山地では、**荷馬を12〜20頭（多いときは40頭）つないだ列**が、18世紀に良い道ができるまで荷運びの主役でした。荷馬を引く者は「ジャガー」と呼ばれました。一頭目の首には鈴がつけられ、細い石橋（荷馬橋）が今も各地に残っています。
- 日本では**馬借（ばしゃく）**が馬の背で年貢や品物を運び、「駄賃」を取りました。11世紀の記録から見え、鎌倉時代の半ばから大きな力を持ちました。港や宿場（敦賀・小浜・大津・坂本・淀など）に集まって住んでいました。

### (3) 荷車と馬車
| 乗り物 | 積める重さ |
|---|---|
| 馬1頭の二輪の荷車 | 約0.5トン（荷の重みの一部が、かじ棒を通して馬の背にかかる） |
| 12世紀の四輪の荷馬車（2頭引き） | 約0.6トン |
| ローマ時代の荷車（1組の馬） | 1〜1.5トン |
| 牛のそり（冬の木材） | 1頭あたり最大10立方メートルの丸太（凍った道で、そりをつないで） |

- 日本の**車借（しゃしゃく）**は牛に車を引かせ、米などを運びました。
- 牛は2頭1組でくびきをかけ、重い荷や悪い道では9〜10組をつなぐこともありました。フランスのモルヴァン地方には、**牛と車ごと雇われて木材を運ぶ**専門の人がいました。

**まとめ**：人1人＝25kg、ロバ＝60kg、荷馬＝110kg、荷車＝500kg。**人と荷車ではおよそ20倍**違います。

## 2. 運ぶ道具 ― 誰が、何で作ったか

中世の人の服には**ポケットがありませんでした**。お金や小物は、帯に結んだ**腰袋（財布）**に入れました。だから「巾着切り（すり）」は、帯から袋を切り取って盗む者でした。

| 道具 | 使い道 | 材料 | 作った職人 |
|---|---|---|---|
| 腰袋・財布 | お金・小物。腎臓の形をした革の腰袋は、中世後期の絵によく出てくる | 革 | 袋作り・財布作りの職人。ロンドンでは袋作り・財布作り・手袋作りが、のちに革の組合にまとまった（1502年に合流） |
| 巡礼の頭陀袋（スクリップ） | 食べ物・椀・杯・お金を入れて腰に下げる | 革・毛織物 | 革職人。出発のとき司祭が袋と杖を清めた |
| 麻袋・穀物袋 | 麦・粉・羊毛 | 麻布・亜麻の粗い布 | 機織り・袋縫い。羊毛の大袋は1340年に「26ストーン＝約165kg」と決められた（240頭分の羊毛） |
| かご（手かご・収穫かご・背負いかご） | 果物・穀物・魚・薪を運ぶ、しまう、小さな動物を入れる。どの家にも大小いくつもあった | 柳の若枝 | かご編み職人。柳は育つのが早く、**その年に伸びた枝だけ**がしなやかで編める。川辺に柳の畑を作って毎年刈った |
| 魚籠・魚のかご | 魚を運ぶ、量る。ニシンは「かご1杯＝約250匹」の決まった大きさのかごで量った（19世紀） | 柳 | かご編み職人（漁師町には魚かご専門の職人も） |
| 背負子（しょいこ）・背負い袋 | 山の産物を町へ。江戸時代の行商人（連雀商人）が背負子で商品を運んだ | 木枠と藁縄 | 自分で作る、または大工 |
| もっこ | 北海道のニシン運び。1杯120〜130匹（30〜34kg）。土運び用の網のもっこもある | 木・縄 | 自分で作る・縄ない |
| 行李・葛籠 | 旅の荷、衣類 | 柳・竹・つづら藤 | かご編み |
| 米俵 | 米4斗（約60kg） | 藁 | 農家が冬に自分で編む |
| 樽 | 酒・麦酒・塩漬けの魚・粉 | 木の板と輪（鉄か木） | 樽職人。水もれしない樽の職人と、粉など乾いた物の樽の職人に分かれた（14世紀の末） |
| 木箱・長持 | 大事な品をしまう。鍵つき | 木・鉄 | 大工・指物師・錠前師 |
| 縄・ロープ | しばる、つなぐ、引く、船の索具 | 麻・亜麻・藁 | 縄ない（綱職人）。長い屋根つきの細長い作業場で撚った |
| そり | 丸太・獲物・石を引く | 木 | 自分で作る・大工 |
| 荷車 | 畑・町・街道 | 木・鉄の輪 | 車大工。鉄の輪つきの荷車は14世紀のイングランドで約4シリング（要約による） |

**ローマ兵の荷物の中身**：革の袋（食料と身の回りの品）、マントの袋、鍋、食器、陣地の杭、食料を入れる網袋。これを棒の先に吊るしました。

## 3. 麻と亜麻 ― 畑から縄と袋になるまで

### (1) 何に使ったか
- **麻（大麻）**：太くて強い。**縄・船の帆・袋・粗い布**。
- **亜麻**：細くてしなやか。**亜麻布（リネン）**＝下着・敷布・上等な布。くずは粗い袋布に。
- **苧麻（からむし）**：日本で古くから使った麻の仲間。越後（新潟）の上布は室町時代から名高く、原料の「青苧」は遠くへ売られた。
- **藁**：麦や稲を刈ったあとに残る。俵・縄・むしろ・草履・屋根。**お金のかからない素材**。

### (2) 国が麻を育てさせた
- 1533年、イングランドのヘンリー8世は「耕す畑**60エーカーごとに4分の1エーカー**は、麻か亜麻を植えよ」と命じました。**新しい海軍の縄と帆**のためです。守らない農家には罰金。エリザベス1世も1563年にくり返しました（1593年に廃止）。
- つまり**麻は国の力（船・軍）を支える品**で、王が面倒を見る作物でした。

### (3) 繊維の取り方（亜麻も麻もほぼ同じ）
1. **育てる**：春にまき、夏に刈る（引き抜く）。
2. **浸す（レッティング）**：茎を水に**8〜15日**つけて腐らせ、繊維と芯をはなす。水につけると早く、白く仕上がる。池や川が臭くなるので、村の外れの決まった池で行うことが多かった（推定）。
3. **干して、たたく**：木の台でたたいて、芯を折る。
4. **しごく**：芯のかすをかき落とす。
5. **くしけずる**：針の並んだくしで、長い良い繊維と、短いくず（トウ）に分ける。長い繊維→糸→布。短いくず→粗い袋布・縄・詰め物。
6. **撚る・織る**：糸にして布に織る（機織り）、または何本も撚り合わせて縄にする（縄ない）。

### (4) 誰が作ったか
- 麻や亜麻を育てて浸すのは**農家**。糸をつむぐのは主に**家の女たち**（冬の仕事）。
- 布に織るのは**機織り**、袋に縫うのは**仕立て屋や袋縫い**。
- 縄は**縄ない（綱職人）**。長い縄を撚るため、**細長い屋根つきの作業場**を持っていた。港町に多い。
- 藁の俵・縄・むしろは、**農家が冬に自分で作る**。

## 4. 保管 ― 家の蔵、町の倉庫、借りる倉

### (1) 家と村
- 農家は穀物を**屋根裏や納屋**にしまい、袋や箱に入れました。
- 刈った麦の束は、**きのこ形の石の台（スタドル・ストーン）**の上に積みました。**ネズミは柱は登れても、笠の裏側は越えられない**。床下を風が通って、かびも防げました。
- 村の教会には**十分の一税の納屋**があり、農家が収穫の1割をそこへ納めました。

### (2) 倉庫を借りる
- イングランドでは1338年、**小麦24クォーターと麦芽24クォーターを13週間あずけるため、穀物倉を2つ借りた**記録があります。倉は**期間を決めて借りる**ものでした。
- ハンザの商人は、ロンドン・ブルッヘ・ベルゲンなどに**自分たちの商館（倉庫つき）**を持ちました。ヴェネツィアのドイツ人商館（1228年〜）は**宿と倉庫を兼ねて**いました。
- 大きな倉庫は、**厚い石の壁**（暑さ寒さをやわらげる）、**階と階のあいだの吊り上げ機**、**品物ごとに分けた場所**を持っていました。
- 日本の中世には、港や町に**問丸（といまる）**がいて、年貢米などを**あずかり、運び、船を手配し、宿も貸しました**。年貢を一時あずける場所を**倉敷地**と呼び、今も倉庫にあずける代金を**倉敷料**といいます（岡山の倉敷の地名も同じ由来）。
- 江戸時代の**土蔵**は、厚い土と漆喰の壁で**火事から品を守る**ためのものでした。蔵を持つことは、守るべき財産がある印でした。

### (3) 倉の敵
| 敵 | 備え |
|---|---|
| ネズミ | 石の台で持ち上げる、猫を飼う、箱や樽に入れる |
| 湿気・かび | 床を上げて風を通す |
| 火事 | 土蔵、石の倉 |
| 盗み | 鍵つきの箱、番人、町の中に置く |

倉庫の賃料そのものの数字は、今回は見つかりませんでした（推定で決める）。

## 7. エルデラントへの提案

### (1) 持てる量の決め方 ― 「力」で重さの上限を決め、「個数」の上限も守る（社長の指示）

社長の決定：**①力の大きさで持てる重さが変わる。重さを超えたら持って歩けない。②最大の所持数を超えては持てない。③いま何を持っているかを見られるようにする。**

#### 力と持てる重さの目安（いちばん大事な表）
昔の記録から、**人が一日じゅう背負って歩ける重さ**は次のとおりです。

| 記録 | 一日背負って歩ける重さ |
|---|---|
| ローマの新兵の訓練 | 約20kg（約30kmを5時間） |
| ローマの兵の行軍の荷（武器・鎧をのぞく） | 約27kg |
| ネパールの荷運び（ふつう） | 20〜50kg |
| 江戸時代の米俵 | 60kg。ただし「誰でも運べる」のは短い距離。一日歩く重さではない |
| 日本の歩荷・強力（専門の者） | 数十kg、ときに100kg超 |

**結論：ふつうの大人が一日歩ける重さは20〜30kg、鍛えた者で40kg前後。**
これをもとに、エルデラントの「力」と「持てる重さ」を次のように決めることを提案します。

| 人 | 力 | 持って歩ける重さ（上限） |
|---|---|---|
| 幼い子ども（〜9歳） | 1 | 5kg |
| 子ども（10〜13歳） | 2 | 10kg |
| 老人（65歳〜）・病人・けが人・身重 | 2 | 10kg |
| 大人の女 | 4 | 20kg |
| 大人の男 | 5 | 25kg |
| 力仕事の者（兵士・騎士・鉱夫・木こり・石工・鍛冶屋・狩人・漁師・農夫・戦士系の冒険者） | 6 | 30kg |
| 鍛えた荷運び・歩荷・荷を担ぐ職を長く続けた者 | 8 | 40kg |

- **持てる重さ＝力×5kg**。力は、年齢・男女・職業・体の調子で決まる。
- 力は、**鍛錬や荷運びの仕事で少しずつ上がり（最大8）**、老い・病気・けが・空腹で下がる。冒険者の位（レベル）が上がると力＋1、など。
- **上限を超えたら歩けない**（その場から動けない）。住人は、超える前に(8)の判断をする。
- 装備している武器・鎧・盾・飾りも重さに入れる（剣3kg、鎧は革8kg・鎖帷子12kg・板金鎧20kg程度。推定）。**重い鎧の騎士は、荷をあまり持てない**＝従者や荷馬が要る、という昔どおりの姿になる。

#### 道具との関係
- **素手（手に持つだけ）で運べるのは10kgまで**。袋・かご・背負い袋などを持つと、その容量ぶん増える。
- ただし道具を足しても、**力で決まる上限は超えられない**。道具は「上限まで持てるようにする物」、力は「上限そのもの」。
- 荷獣・荷車・そりは、**人の上限とは別の入れ物**（人が引く・連れて歩く）。

#### 個数の上限
- 重さとは別に、**持ち物の個数（枠）にも上限**を置く。基本は**12枠**、腰袋＋2、背負い袋＋6、大きな背負い袋＋10（推定）。同じ素材や食べ物は1枠に重ねられる。今の24枠は「大きな背負い袋を持った冒険者」くらいに当たる。
- 枠がいっぱいなら、重さに余裕があっても**それ以上は持てない**。
- **あふれたら黙って消す、は廃止**。入らない物は拾わない、または(8)の判断で入れかえ、捨てた物はその場に置く。

#### いま何を持っているかを見る
- 住人を選ぶと、**持ち物の一覧（品名・個数・重さ）**と、**「重さ 18／25kg」「枠 9／12」**のような目盛りを出す。
- 上限に近い者には頭の上に小さな荷の印、上限で歩けない者には「重くて動けない」と吹き出しを出すと、見て分かる。

### (7) 倉庫の貸し借り
- **町の倉庫**：町（または商人）が建てて貸す。**10kg分を5日あずけるごとに1銅貨**（推定）。一度に5日単位で前払い。
- **冒険者ギルドの預かり所**：ダンジョンの入口の町に置く。冒険者だけが使え、同じ値段。宝を一度あずけて、また潜れる。
- **港の倉庫**：商人の荷を船待ちのあいだあずかる。問丸のように、宿と運び手の手配も兼ねる。
- 倉の敵：ネズミ（食べ物が**月に2％**減る。猫を飼う家・石台の倉は0.5％）、火事（まれ）、盗賊（番人のいない倉は狙われる）。**減った食べ物は消えるのではなく、ネズミが増える**（食物連鎖の担当と相談）。

### (8) 持ちきれないときの判断（住人が上から順に考える）
1. **仲間に分ける**：一緒にいる仲間や家族に空きがあれば渡す。
2. **安い物を捨てて入れかえる**：持ち物のうち「1kgあたりの値打ち」が一番低い物と比べ、新しい物のほうが高ければ入れかえる。捨てた物は**その場に置かれ**、ほかの人が拾える（黙って消えない）。
3. **近くに家・倉庫・預かり所があれば一度戻る**：歩いて半日以内なら戻ってあずけ、また出かける。
4. **荷運びを雇う**：お金があり、町にいれば荷運びを雇う（下の値段）。
5. **置いていく**：目印をつけて隠し、あとで取りに来る（盗まれることもある）。
6. どれも無理なら**あきらめる**。そのときは「持ちきれず○○を置いてきた」と記憶に残し、次はリュックや荷運びを求める。

### (9) ダンジョンの宝を持ち帰る工夫
- **宝は軽くて高い物を中心に**：金貨・宝石・魔石・魔核（ほぼ0kg）。重い鎧や大きな骨は「持ち帰れたら高く売れる」おまけ。
- **荷運びを連れて潜る**：荷運びは戦わず、パーティの後ろで荷を持つ。**入口で待つ**だけの安い契約もある。
- **入口の野営地に荷をあずける**：ギルドの預かり所または仲間の見張り番。
- **帰りの判断**：荷が体の上限の**8割**を超えたら、奥へ進まず引き返す。
- **倒れたら荷を落とす**：死んだり気絶したりすると荷はその場に落ち、ほかの冒険者や魔物のものになる。
- **魔法の袋**はダンジョンの深い所の宝箱からまれに出る。これを持つ冒険者は評判になる。

### (10) お金の出どころと行き先
| お金の動き | 払う人 | 受け取る人 |
|---|---|---|
| 道具（袋・かご・リュック・縄・樽・荷車）の代金 | 買い手の家計 | 作った職人の家計（商人が間に入れば、その分は商人へ） |
| 素材（麻・柳・藁・革）の代金 | 職人の家計 | 農民・かご材を刈る者・革なめしの家計 |
| 荷獣の代金 | 買い手の家計 | 牧場主の家計 |
| 荷獣の餌代 | 持ち主の家計 | 干し草や燕麦を売った農民の家計 |
| 倉庫代 | 借り手の家計 | 倉庫の持ち主（町の倉なら町の蓄え、商人の倉ならその家計） |
| ギルドの預かり代 | 冒険者の家計 | 冒険者ギルドの蓄え |
| 荷運びの賃金 | 雇った人の家計 | 荷運びの家計（**1日5銅貨**＝人夫と同じ。ダンジョンの中は危ないので**1日8銅貨**、宝の分け前は1割） |
| 荷車・荷馬の貸し賃（馬借・車借） | 借り手の家計 | 持ち主の家計（荷馬1日3銅貨、荷車と牛1日6銅貨、推定） |
| 捨てた品・落とした品 | お金は動かない | 拾った人の持ち物になる |
| 魔法の袋 | ダンジョンの宝箱から（外から入る分） | 拾った人 → 売れば買い手の家計から売り手へ |

### (11) 最初に手をつける順番（案）
1. **あふれたら古い物が消える不具合を直す**（捨てるときは、1kgあたりの値打ちが一番低い物を、その場に置く）。
2. 品物に重さをつけ、**体の上限と、袋・かご・リュック**を入れる。まずは既存の職人（機織り・靴屋・大工）に作らせる。
3. **麻・柳・藁**の素材と、**かご編み・縄ない**の職人を足す。
4. **荷運び・荷獣・町の倉庫・ギルドの預かり所**を足す。
5. 樽と塩漬け、そり、手押し車、魔法の袋。
