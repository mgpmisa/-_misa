# 建物の持ち主と商売の費用 ― 店は誰のものか、店主は何にお金を払っていたか

エルデラント年代記の「店・店主・収入・家賃」の仕組みを作り直すために、中世ヨーロッパと、比べるために日本の中世〜江戸の町と村を調べた読み物です。
社長の問いは3つでした。

1. 店の店主や収入や家賃などの仕組みは整っているか？
2. この時代の建物の持ち主はどんな人か？
3. 家賃とは別に、商売をするのに別のお金もかかるのか？

この順ではなく、先に歴史（2と3）を書き、最後に今のゲームの点検（1）と提案をまとめます。
はっきりした記録が見つからなかった数字には「推定」と書きました。出典は各章の終わりと、最後の一覧にあります。
ほとんどのページは直接開けなかったため、検索結果の要約から取りました。数字はおおよその目安と考えてください。

**お金の換算の目安**（この読み物の中だけの約束）
- 14世紀ごろのイングランドでは、ただの働き手の日給がおよそ**2ペンス**、腕のよい大工が**3ペンス**、石工の親方が**4ペンス**でした。
- エルデラントのふつうの働き手の日給は**8〜10銅貨**です。そこで、この読み物では**1ペンス ≒ 4〜5銅貨**と見なして数字を移します。

## 1. 建物と土地の持ち主は誰だったか

### (1) 結論を先に：土地の「本当の持ち主」と、建物を「使う人」は、たいてい別だった
中世ヨーロッパでは、土地はおおもとをたどると**王**のもので、それを**領主（貴族）**や**教会・修道院**が預かり、さらにその下の人に貸す、という重なった形でした。
今の「この家は私のもの」という、きっぱりした持ち方は少なく、たいていの人は「**誰かから借りて、代わりに毎年なにかを払う**」立場でした。
払うものは、お金・作物・働く日数（畑仕事の手伝い）などです。

### (2) 村：農民の家と畑

| 立場 | 家と畑は誰のものか | 何を払うか |
|---|---|---|
| **農奴**（自由のない農民） | 家と畑は**領主のもの**。親から子へ受け継いで使える。勝手に村を出られない | 週に**2〜3日**、領主の畑で働く。刈り入れ・畑おこしの時期はさらに手伝い。死ぬと**いちばんよい家畜**を領主に納める。娘を嫁がせるときにも許し料 |
| **自由農民** | 畑を領主から借りているが、身は自由 | 働く代わりに、**決まった額のお金**（安い地代）を払う。領主の畑で働く義務はない |
| **小作** | 地主の畑を借りて耕す | 収穫の一部を地主へ |
| （後の時代）**帳簿の写しで借りる農民** | 領主の記録に名前が載っていて、その写しが「借りている証文」になる | お金の地代。追い出されにくくなった |

- 農奴の畑は、はじめは「領主の気分しだい」で取り上げられましたが、のちには「**村のしきたりどおりなら追い出せない**」と王の裁判所が守るようになりました。
- 農奴ひと家族が使う畑は、およそ**30エーカー（東京ドーム3つ分ほど）**が目安でした。

### (3) 町：町の家は「借りた土地の上の持ち家」が基本

- 中世イングランドの町では、道に面した**間口の狭い、奥に細長い区画**に家が建ちました。
- 土地は**王・領主・町**のもので、住む人は毎年**決まった少しのお金**（土地の借り賃）を払います。これは安く、何十年も変わらない決まった額でした。
- この土地の借り賃さえ払っていれば、**家を売ったり、子に継がせたり、人に貸したりできた**。つまり**「土地は借り物、家は自分のもの」**という形です。
- この「町に家を持ち、土地の借り賃と町の負担を払う人」が、町の正式な住人（町民）でした。

**地代と家賃の違い**
| | 地代（土地の借り賃） | 家賃（家の借り賃） |
|---|---|---|
| 払う人 | 家を持っている人 | 家を借りて住む人 |
| 受け取る人 | 土地の持ち主（王・領主・町・教会） | 家の持ち主（大家） |
| 額 | 安く、昔から決まっている | 高く、場所と広さで決まり、上がり下がりする |
| ゲームでいうと | 税の「地代」（家の値打ちに応じて国へ）に近い | 借家の週の家賃 |

### (4) 大家になったのは誰か
町の家を人に貸して家賃を取った「大家」は、次のような人たちでした。

- **修道院・病院・施し院などの教会の仲間**：中世ロンドンでは、**いちばん大きな大家**のひとつでした。昔の人が死ぬ前に「魂の救いのために」と家を寄付したので、町じゅうに貸家を持っていました。
  - 例：イングランドのヨーク町の「**聖母の長屋**」（1316〜17年）。教会の墓地の一部に、**2階建て・9軒の長屋**を建てて貸し、その家賃を**教会の運営費**にあてました。今も残る、国でいちばん古い長屋のひとつです。
- **同業組合（ギルド）**：寄付された家を貸して、組合の年寄りや病人の助けにあてました。
- **裕福な商人**：もうけで家を買い、貸して家賃を取りました。
- **王・領主**：町の土地そのものの持ち主。
- **町（自治都市）**：町の建物（市場の屋根・計量所・露店）を貸しました。

### (5) 店の建物：1階が店、2階が住まい
- 町の店は、ほとんどが**「店と住まいが一つの建物」**でした。**道に面した1階が店と作業場**、**奥や2階が家族の住まい**、裏庭に井戸や物置。
- 店主はこの建物を**持っていることも、借りていることも**ありました。大きな町の目抜き通りでは、借りている店主のほうが多かったとみられます（推定）。
- ロンドンのいちばんの商店街チープサイドには、1300年ごろには**何百もの店**が並び、さらに「**セルド**」と呼ばれる、屋根の下に小さな売り場がたくさん入った**貸し売り場の建物**もありました。13世紀には**合わせて千人ほど**の商人がセルドの中で商売をしていたといいます。家まるごとを借りられない小さな商人は、売り場の一角だけを借りたのです。

### (6) 宿屋・酒場・パン屋・鍛冶場・水車小屋・かまど
| 建物 | 持ち主 | 使う人・営む人 |
|---|---|---|
| **大きな宿屋** | 巡礼地では**修道院が建てた**ものが多い。例：ロンドン南のタバード亭は、ハイドの修道院長が仕事で町に来たとき泊まるために建てた | 宿の主が営む（修道院から借りて営む形もあった。推定） |
| **酒場（ぶどう酒・ビール）** | ロンドンでは**酒造りやぶどう酒商人が持ち**、自分の酒を売る店にした | 酒場の主 |
| **ビールを出す家** | ふつうの家。台所で造ったビールを売る | その家のおかみさん（多くは女性） |
| **水車小屋・風車（粉ひき）** | **領主のもの**。村人はそこで粉をひく決まり | 領主が**粉屋を雇う**か、粉屋に**年ぎめで貸した**（例：水車1つを12年、年に53シリング4ペンスで。これは大工の日給の約210日分） |
| **パン焼きのかまど（村）** | フランスなどでは**領主のもの**。家で大きなかまどを持つことは禁じられた | **かまど番**が火を起こし、村人のパン生地を預かって焼く |
| **パン屋（町）** | パン屋の主が持つか借りる。自分のかまどを持つ | パン屋 |
| **ぶどう搾り** | 領主のもの | 村人が使うたびに使用料 |
| **鍛冶場** | 町では職人の持ち物か借り物。村では領主の独占の施設になることもあった | 鍛冶屋 |

### (7) 日本の場合
- **中世の京都**：町屋の土地には「**地子（じし）**」という土地の年貢がかかり、お金で払うものを「**地子銭**」と呼びました。受け取るのは土地の持ち主の**寺社や公家**です。
- **戦国〜豊臣**：大名は商人や職人を城下町に呼び集めるため、**地子を免除**しました。明智光秀が京都の地子を免じ、豊臣秀吉もそれを受け継ぎました。
- **江戸の町**は、住む人が3つに分かれていました。
  1. **地主**：土地と建物の持ち主。町の費用（**町入用**）を払い、町の運営に加わる。
  2. **地借り**：土地を借りて、その上に**自分の家を建てた人**（ヨーロッパの町民と同じ形）。
  3. **店子（たなこ）**：家を借りて住む人。**町入用は払わなかった**。
- 表通りの「**表店（おもてだな）**」は店として貸され、その裏の路地の「**裏長屋**」は住まいとして貸されました。どちらも**地主のもの**です。
- 地主は町に住まないことも多く、「**大家（家守）**」が地主に代わって家賃を集め、店子の身元を調べ、旅の手形を書き、結婚の相談にも乗りました。井戸の水代は家賃に入っていて、大家がまとめて払いました。

## 2. 家賃と地代の相場 ― 日給の何日分だったか

### (1) イングランド（14世紀はじめ）
| 住まい | 年の家賃 | 日給で何日分か | 年の稼ぎに対して |
|---|---|---|---|
| **小屋**（いちばん安い住まい） | 5シリング＝60ペンス | ただの働き手（2ペンス）の**約30日分** | およそ**1割強（12〜13％）** |
| **職人の家** | 20シリング＝240ペンス | 大工（3ペンス）の**約80日分** | およそ**3割**（推定。家族の稼ぎを合わせれば軽くなる） |
| **商人の家** | 40シリング＝480ペンス | 石工の親方（4ペンス）の**約120日分** | 店と作業場を兼ねるので高い |
| **ロンドンの小さな家（1490年代）** | 4シリング | 当時の日給で20日分ほど（推定） | |
| **ロンドンのふつうの貸家（1490年代）** | 10シリング〜13シリング4ペンス | | |

- 石工のように腕がよければ、**30〜45日分の稼ぎで1年分の家賃**がまかなえた、という見方もあります。
- 「住んで、働く場所でもある家」は、ただ住むだけの家より**ずっと高かった**。つまり**店は、住まいより家賃が高い**のがふつうでした。
- ロンドンの目抜き通りの店の家賃は、**1400年ごろから1550年ごろまでほとんど変わらなかった**ことがわかっています。

### (2) 江戸
| | 額 | 日給で何日分か |
|---|---|---|
| **裏長屋**（九尺二間、畳4枚半＋台所ほど） | 月に**400〜600文**（ならして500文） | 大工の日給（300〜500文ほど）の**1〜2日分／月** |
| **表店**（通りに面した店） | 裏長屋よりずっと高い（いまのお金で月6万円ほどという見積もり） | |

- 江戸の大工の家賃は**月に日給の1〜2日分**。中世イングランドの小屋（年に日給30日分＝月に2.5日分）とくらべても、ほぼ同じか少し軽いくらいです。
- 家賃は月ごとでしたが、日払いの長屋もありました。

### (3) 払えないとどうなったか
- **ヨーロッパ**：大家は裁判を待たずに、**借り手の家の中の品物を差し押さえ**てよい、という古い決まり（13世紀にはすでにあった）がありました。差し押さえた品は**5日間預かり**、それでも払わなければ**売って家賃にあてた**。
  - ただし、**仕事の道具は取り上げない**という例外がありました（道具を取ると稼げなくなり、よけいに払えなくなるため）。
  - それでも払えなければ追い出されました。
- **江戸**：家賃をためると大家に追い出されますが、大家は店子の身元の保証人でもあり、ある程度は待ってやるのがふつうでした（落語の「大工調べ」は、家賃のかたに大家が大工の道具箱を取り上げてしまい、大工が仕事に行けなくなる話）。

## 3. 家賃のほかに、商売にかかったお金 ― 答え：たくさんあった

店を開いている人は、家賃のほかに、ざっと次のお金を払っていました。**払う相手がばらばら**なのが特徴です。

### (1) 組合に払うお金
| お金 | 中身 | 払い先 |
|---|---|---|
| **入会金** | 組合に入る（＝町で店を開いてよくなる）ためのお金。入り方は3つ：**7年の徒弟奉公**を終える／**親が組合員**／**お金で買う**。お金で買う道がいちばん高い | 組合の箱 |
| **組合費** | 季節ごと（3か月ごと）に払う。例：オックスフォードの酒造りの組合は季節ごとに**8シリング**（大工の日給の約30日分）、ビールとエールの両方を造る者は**2倍**（中世より後の時代の数字と推定） | 組合の箱 |
| **組合の罰金** | 決まりを破ったとき | 組合の箱 |
| **町民になる料金** | ロンドンでは「町の自由民」にならないと商売できない。組合員でないと自由民になれない | 町 |

- 例：オックスフォードでは、地元で奉公していない人が入るには**5ポンド**（大工の日給の約400日分）、1669年には**30ポンド**も取られた人がいました（ずっと後の時代の数字）。
- 組合の箱は、**病気や年を取った組合員、残された家族の助け**、集会所の修理、祭りに使われました。
- 徒弟を取る側は、**徒弟を住まわせ、食べさせる**費用がかかる一方、親から**奉公の礼金**を受け取ることもありました（礼金が高くて、奉公に出せない家も多かった）。

### (2) 町と市に払うお金
| お金 | 中身 | 払い先 |
|---|---|---|
| **露店の場所代** | 市の日に売り場を置く料金 | 市の権利を持つ者（町・領主・修道院） |
| **地面を掘る料金** | 露店の柱を立てるために地面に穴を掘る料金 | 同上 |
| **市場税・入市税** | 町に入る荷、町から出る荷にかかる。町が王に毎年払う「町の上納金」をまかなうため | 町 |
| **はかり料** | 町の公のはかりで量ってもらう料金 | 町 |
| **城壁・道・橋の税** | 城壁の修理（壁の税）、道の石畳（道の税）、橋（橋の税）、波止場の費用。荷や通る人にかける。**王の許しで数年だけ**取れて、たいてい延長された | 町（工事にあてる） |

| **見張りと警備の番** | 町民は**夜の見張り**と**町の守り**の番を務めた。自分で立つか、人を雇って代わりに立たせる | （働く日数で払う） |

### (3) 領主に払うお金（独占の施設の使用料）
| お金 | 割合 | 払い先 |
|---|---|---|
| **粉ひき代** | 麦の**16分の1**（約6％）がよくある。**10分の1**のところも。お金でなく麦（粉）で払う | 水車の持ち主（領主）。水車を借りている粉屋は、そこから領主に借り賃を払う |
| **かまど代**（村の共同かまど） | **16分の1**、または何個かに1個のパン。**6個に1個**という例も | かまどの持ち主（領主）。かまど番の手間賃も |
| **ぶどう搾り代** | 例：ぶどう酒の**20分の1** | 領主 |
| **自分で粉をひいた罰** | 領主は、家の手回しの石うすを使うのを禁じた。スコットランドでは、見つかると**石うすを割られた** | ― |

- こうした施設の使用料は、フランスでは1789年の革命の夜にやっと廃止されました。
- イングランドでも、粉ひきの権利は領主の**よい稼ぎ**だったので、厳しく守らせることが多かった。
- 14世紀の後半には、領主は水車を自分で営むのをやめ、**粉屋に年ぎめで貸す**ようになりました。**粉屋は借り賃を払い、粉ひき代の残りが自分のもうけ**になる形です。

### (4) 酒を売る許し
- イングランドの村では、ビールを造って売るたびに、村の裁判で**罰金**を取られました。しかし実際には、これは毎回決まって取られる**許可料の代わり**でした。
  - 例：あるおかみさんは、造って売った1回につき**2ペンス**（ただの働き手の日給1日分）。7回造った人は14ペンス。
- 毎年選ばれる**ビールの味見役**が、造ったビールを味見し、質が悪いか決まった値段より高く売っていれば、次の裁判で告げました。

## 4. いまのエルデラントを点検した結果 ― 社長の問い1への答え

**答え：住まいの家賃の仕組みはよく整っている。しかし「店の建物」には持ち主も家賃もなく、店主は商売の費用もほとんど払っていない。**

### (1) 住まい（整っている）
世界を作った直後の数字（種12345で数えた）：

| 町の種類 | 家の数 | 持ち家 | 借家 | 週の家賃 |
|---|---|---|---|---|
| 王都 | 53 | 31 | 22 | 9〜14銅貨（ならして9） |
| 港町 | 25 | 20 | 5 | 7銅貨 |
| 村 | 95 | 93 | 2 | 5〜7銅貨 |

- 大家になるのは、町の**貴族・商人・両替商・酒場の主、または裕福な家**。
- 家賃は**週に1度**、借り手の家計（足りなければ家族の財布）から**大家の家計へ**。
- **3週たまると追い出し**。情け深い大家は**一度だけ待ってくれる**。追い出された一家は恨みを覚え、うわさが広がる。
- お金がたまった借り手は、**値打ちの1.15倍**で大家から家を買い取れる。空き家は町から買える（代金は町の蓄えへ）。
- 家・畑・家畜は**相続**される。継ぐ人がいなければ町の蓄えへ。
- 宿住まいの人は毎日1人3銅貨を宿の主へ。払えなければ追い出される。
- 小作は収穫の**3割**を地主へ。お金がたまると**180銅貨**で畑を買って自作農になれる。
- **歴史との比べ**：ふつうの働き手の週の稼ぎはおよそ50銅貨（日給9銅貨×休日を除く5.6日）。村の家賃5〜7銅貨は**稼ぎの1割強**で、中世の小屋（1割強）とぴったり同じ。王都の9〜14銅貨は**2〜3割**で、職人の家（約3割）に近い。**数字はそのままでよい**。
- 一つだけ足りないのは、**差し押さえ**（家賃のかたに品物を取る。ただし仕事の道具は取らない）の段階がないこと。

### (2) 店の建物（整っていない）
- パン屋・鍛冶場・工房・宿屋・酒場・湯屋・よろず屋・仕立て屋・薬屋・水車小屋など、**店や仕事場の建物にはどれも持ち主がいない**（調べた世界では0棟）。
- 「店主」は、**その町でその仕事についた人**がなる、というだけ。店を持つ・借りる・継ぐ・売るということがない。**店の家賃もない**。

### (3) 店主の収入（形はあるが、「店」の形になっていない）
| 店 | 今の収入の入り方 |
|---|---|
| パン屋・鍛冶屋などの職人 | 作った品を**町の市場の箱**に相場の85％で売る（代金は市場の金庫から）。**仕入れ**は、一部の職人が市場から材料を買う（品物の担当の新しい仕組み） |
| 宿の主・湯屋の主 | 客の払った宿代・湯銭を**直接受け取る**。湯屋は薪代を市場に払う（**仕入れのよい例**） |
| よろず屋の主 | 市場の買い物の**手数料（6％）**を日の終わりに受け取る |
| 粉屋 | 市場の小麦を減らしてパンを増やし、**市場の金庫から時間ごとに1.5銅貨**。**農家からは粉ひき代を取っていない**。粉屋が小麦から直接パンを作っていて、パン屋との境があいまい |

### (4) 店主が払っているお金
| お金 | 今あるか | 中身 |
|---|---|---|
| 人頭税 | ある | 大人1人3〜3.5銅貨×税の重さ、5日ごと。国庫へ |
| 地代（家の値打ちへの税） | ある | 持っている**家**の値打ちの約1％、5日ごと。国庫へ。**店の建物には持ち主がいないのでかからない** |
| 売上税 | ある | 職人・商人の家は、前の徴税日から**家計が増えた分の7〜8％**。国庫へ |
| 関税 | ある | よその国から入る荷に6〜15％。国庫へ |
| 十分の一税 | ある | 農家の増えた分の10％。教会と施し箱へ |
| **店の家賃** | **ない** | |
| **組合の入会金・組合費** | **ない**（商人の歴史で提案ずみ、経済部が作業中） | |
| **市の場所代・はかり料** | **ない**（同上） | |
| **粉ひき代・かまど代** | **ない** | |
| **酒を売る許し** | **ない** | |
| **見張りの番・町の負担** | **ない**（見張りは衛兵の仕事になっている） | |

- 名前の注意：ゲームの「**地代**」は、家の持ち主が**国**に払う税です。歴史の「町の家の持ち主が土地の持ち主に払う決まった額（日本の地子銭）」にあたるので、中身はおかしくありません。ただし「家賃」と混ざらないよう、画面の説明に「家を持つ人が国に払う」と一言あるとわかりやすい。

## 5. エルデラントへの提案

### (1) 建物の持ち主の決め方（はじめに世界を作るとき）
| 建物 | 持ち主 | 使う人との関係 | 備考 |
|---|---|---|---|
| **村の家と畑** | 自作農は自分、小作は地主（村長・貴族） | 今のまま | |
| **町の家** | 住む家族（持ち家）か、大家（貴族・商人・両替商・酒場の主）か、**教会** | 今のまま。**教会も大家になれる**ように足す | 教会の貸家の家賃は**施し箱**へ（聖母の長屋と同じ） |
| **パン屋・鍛冶場・工房・仕立て屋・薬屋** | 王都は**半分が店主の持ち物、半分が大家から借りる**。港町は6割、村は8割が持ち物 | 1階が店、2階が店主の家族の住まい（**店に住む家族は、別に家を借りない**） | 住まいと同じ家賃の決め方で週7〜21銅貨 |
| **よろず屋** | 町の商人組合（または大家） | 店主が借りる | 週7銅貨 |
| **宿屋・酒場** | 主の持ち物か、**修道院・領主**の持ち物 | 主が持つか借りる | 大きな宿は週21〜46銅貨の借り賃 |
| **水車小屋・風車** | **領主（その町の貴族。いなければ国）** | 粉屋が**年ぎめで借りる**（請け負い） | 村人はここで粉をひく決まり |
| **村の共同かまど**（新しく作るなら） | 領主 | かまど番が焼く | 町ではパン屋が自前のかまど |
| **湯屋** | 主の持ち物か、町 | | |
| **市場の建物・露店・計量所** | **町** | 露店は日ごと、店は週ごとに貸す | 場所代は町の蓄えへ |
| **教会・墓地・孤児院** | 教会 | | |
| **城・兵舎・詰所・穀物倉・図書館** | 国か町 | 働く人は給金をもらう役人 | |

- 店の値打ちは、今の家と同じ決め方（広さ×町の格）でよい。測ってみると店の借り賃は**週7〜46銅貨**（よろず屋7、パン屋と鍛冶場10〜21、大きな宿46）になり、住まい（5〜14）より高い。**「働く場所を兼ねる家は高い」という歴史とも合う**。
- 店の持ち主が死んだら、住まいと同じく**相続**。継ぐ人が同じ仕事なら店を続け、違えば**店を貸すか売る**。
- 店主が仕事をやめたら、持ち主はその建物を**同じ仕事の別の人に貸す**。借り手がいない店は空き店になり、町の中で店の数が自然に上下する。

### (2) 店主の収入と支出（パン屋の1週間の例）
数字はこの世界の値段（小麦2銅貨、パン3銅貨、ふつうの日給9銅貨）に合わせた**目安（推定）**です。

| | 額（銅貨／週） | 払う側 → 受け取る側 |
|---|---|---|
| **売り上げ** パン100個×3 | **+300** | 町の人の家計 → パン屋の家計（市場の箱を通すなら市場の金庫 → パン屋） |
| 仕入れ 小麦80袋×2 | −160 | パン屋の家計 → 農家の家計（または商人） |
| 粉ひき代（麦の16分の1） | −10 | パン屋の家計 → 粉屋の家計 |
| かまどの薪 | −10 | パン屋の家計 → 市場の金庫（木こり） |
| 店の借り賃（借りている場合） | −15 | パン屋の家計 → 大家の家計（教会なら施し箱） |
| 組合費（季節ごと日給2〜3日分を週に割る） | −3 | パン屋の家計 → 組合の箱 |
| 売上税（もうけの7〜8％） | −6 | パン屋の家計 → 国庫 |
| 人頭税（大人2人） | −9 | パン屋の家計 → 国庫 |
| 町の負担（見張りの番の代わり） | −2 | パン屋の家計 → 町の蓄え |
| 徒弟1人の食事と寝床 | −10 | パン屋の家計 → 市場（食べ物代として） |
| **手取り** | **約75** | 1日およそ**13銅貨**＝ふつうの働き手の**1.4倍** |

- 職人を1人雇えば、給金として**週45〜50銅貨**（日給8〜9銅貨）を払う。その分たくさん焼けるが、手取りの増え方は小さい。**よく売れる店だけが人を雇う**。
- 目安の割合（どの店にも使える）：**仕入れ 50〜60％／家賃 4〜6％／燃料と道具 3〜5％／組合費と場所代 1〜3％／税 4〜6％／雇い人 0〜15％／手取り 20〜30％**（推定）。
- 店を持っている店主は家賃がないぶん楽だが、**国に家の値打ちの税（地代）**を払う。借りている店主は家賃を払うが、その税は大家が払う。

### (3) 家賃以外の商売の費用（新しく足すもの）
| 費用 | 額の目安 | 払う側 | 受け取る側 | 払えないとき |
|---|---|---|---|---|
| **組合の入会金** | 日給の30〜60日分（270〜540銅貨）。親が組合員なら半額。徒弟を終えた人はさらに安い（日給10日分） | 新しく店を開く人 | 組合の箱 | 店を開けない。雇われ職人として働く |
| **組合費** | 季節（10日）ごとに日給2日分（約18銅貨） | 組合員 | 組合の箱 | 2季ためると組合から外される |
| **市の日の場所代** | 露店1つパン1個分（3銅貨）／日 | 露店の主（村の農民・行商人も） | 町の蓄え（市の権利を持つ領主がいれば領主の家計） | 売れない |
| **はかり料** | 量った品の値打ちの1％ | 商人 | 町の蓄え | |
| **粉ひき代** | 麦の16分の1（約6％）を麦で | 農家・パン屋 | 水車を借りている粉屋 | 家の石うすでひく（見つかると罰金。強欲な領主の国だけ厳しく取り締まる） |

| **酒を売る許し** | 仕込み1回につき日給1日分（9銅貨） | 酒場の主・酒を造る家 | 領主か町の蓄え | 見つかると品の取り上げと罰金 |
| **町の負担** | 大人1人週1〜2銅貨、または夜の見張りの番を自分で務める | 家を持つ町民（**借り手は払わない**＝江戸の店子と同じ） | 町の蓄え | 番を務めれば払わなくてよい |
| **徒弟の世話** | 徒弟1人につき週10銅貨ほど（食事と寝床）。代わりに親から奉公の礼金（日給10〜20日分）を受け取る | 親方 | （食べ物として市場へ）／礼金は徒弟の親の家計 → 親方の家計 | |

### (4) 家賃を払えないときの段階（今の追い出しの前に足す）
1. 1週目：待ってもらう（今と同じ）。
2. 2週目：**差し押さえ**。大家が借り手の品物を足りない分だけ取り上げ、**5日間預かる**。**仕事の道具と武器・防具は取らない**。
3. 5日のうちに払えば品物は返る。払えなければ品物は売られ、代金は**大家の家計へ**（売った先の市場・商人から大家へ）。
4. 3週目：それでも足りなければ追い出し（今と同じ）。**店の場合は店を閉じ、空き店になる**。

### (5) お金の出どころと行き先のまとめ
| 流れ | 払う側 | 受け取る側 |
|---|---|---|
| 住まいの家賃 | 借り手の家計（足りなければ家族の財布） | 大家の家計（教会の貸家なら施し箱） |
| 店の借り賃 | 店主の家計 | 店の持ち主の家計 |
| 差し押さえた品の売り代 | 品を買った人・市場 | 大家の家計 |
| 家や店の売り買い | 買い手の家計 | 売り手の家計（町の空き家なら町の蓄え） |
| 家・店の値打ちの税（地代） | 持ち主の家計 | 国庫 |
| 売上税・人頭税 | 店主の家計 | 国庫 |
| 仕入れ | 店主の家計 | 作り手の家計（または市場の金庫） |
| 売り上げ | 客の家計 | 店主の家計（または市場の金庫） |
| 雇い人の給金 | 店主の家計 | 雇われた人の家計と財布 |
| 入会金・組合費 | 店主の家計 | 組合の箱 |
| 組合の助け | 組合の箱 | 病気や年寄りの組合員・残された家族の家計 |
| 場所代・はかり料・町の負担 | 露店の主・商人・町民 | 町の蓄え |
| 粉ひき代 | 農家・パン屋（麦で） | 粉屋 |
| 水車の借り賃 | 粉屋の家計 | 領主の家計（領主がいなければ国庫） |
| かまど代 | 村人（パンで） | 領主（かまど番へ手間賃） |
| 酒を売る許し | 酒場の主 | 領主の家計か町の蓄え |
| 奉公の礼金 | 徒弟の親の家計 | 親方の家計 |
| 十分の一税 | 農家の家計 | 神父の家計（1割）と施し箱（9割） |

どの流れも、**払う側の財布が減った分だけ、受け取る側が増える**。どこからも湧かず、どこへも消えない。

### (6) 物語として見えるようになること
- 「パン屋の○○は、大家の商人に週15銅貨の店賃を払っている」「親の代からの店を継いだ」「店賃が払えず、窯の道具以外を差し押さえられた」といった出来事が、店ごとに起きる。
- 強欲な領主の村では、家で石うすを回した農民が罰金を取られ、恨みが積もる。慈悲深い領主は粉ひき代を安くする。
- 教会の貸家が多い町では、家賃が施し箱をうるおし、貧しい人が助かる。
- 王が「楽市」を命じると、入会金と場所代がなくなって新しい店が増えるが、組合の箱が空になり、年寄りの組合員の助けが止まる。
