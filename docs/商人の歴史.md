# 商人の歴史 ― なぜ商人が必要だったのか、店を開くには許しが要ったのか

エルデラント年代記で「作る → 売る → 買う → 使う」のお金と品物の流れを作り直すために、中世ヨーロッパ・イスラム世界・日本の商人を調べた読み物です。
社長の問い「なぜ商人が必要なのか？」「販売には資格が必要？」「昔の時代の商人は？」に、この順で答えます。
数字のうち、はっきりした記録がないものは「推定」と書いてあります。出典は各章の終わりと、最後の一覧にまとめました。

---

## 1. なぜ商人が必要だったのか

### (1) 作る人と使う人は、場所も時期も合わない
- 漁師が魚をとるのは朝の浜辺。町の人が魚を食べたいのは夕方の台所。
- 農民が小麦を刈るのは秋の一度だけ。町の人は一年じゅう毎日パンを食べる。
- 羊飼いの羊毛は山の村にあり、布を織る職人は町にいる。

作り手が自分で町を一軒ずつ回って売っていたら、**作る時間がなくなります**。漁師が網を置いて一日じゅう魚を売り歩けば、次の日の魚はとれません。
そこで「作り手からまとめて買い、使う人に少しずつ売る」専門の人、つまり商人が生まれました。

### (2) 商人の5つの仕事

| 仕事 | 中身 | もし商人がいなかったら |
|---|---|---|
| **運ぶ** | 浜の魚を町へ、山の羊毛を織り手へ、よその国の塩や香辛料をこの国へ | 作ったものが作った場所で腐る・余る。遠くの品は手に入らない |
| **貯える** | 秋に安い麦を買って蔵に入れ、春に売る。季節の差をならす | 秋は麦が余って値がつかず、春は足りなくて飢える |
| **値段を決める** | 何がどれだけあり、誰が欲しがっているかを一番よく知っているので、値段が決まる | 売り手と買い手がいちいち言い争い、取り引きが進まない |
| **信用で貸す** | 「つけ」で売る、代金を前払いして作ってもらう、漁師に網の代金を貸す | 手元にお金がない人は、何も買えず何も作れない |
| **目利きと保証** | 質の悪い品をはじき、量をきちんと量って売る | 買うたびに、ごまかされていないか自分で調べなければならない |

中世イングランドの麦の値段は、**収穫のすぐ後が一番安く、そこから次の収穫の前まで少しずつ上がり**、1350年より前は収穫と収穫のあいだで**平均およそ2割（21％）**上がりました。14世紀より前の小麦は、年のうちに**3〜4割**上がったとみる研究もあります。この差のうち、蔵の借り賃・ネズミにかじられる分・お金を寝かせる損を埋めたのが、麦を貯えた商人や農家のもうけでした。

### (3) 商人は昔から「嫌われ役」でもあった
便利な一方で、商人は「自分では何も作らずに、右から左へ動かしてもうける」と疑われました。
- **カール大帝の法令（806年、ナイメーヘン）**：「収穫やぶどう摘みのときに、必要もないのに欲張って麦やぶどう酒を買い、たとえば1升を2ドゥニエで買って、4ドゥニエ、6ドゥニエ、それ以上で売れるまで貯めておく者、これを**恥ずべきもうけ**と呼ぶ」。飢饉のさなかに出された決まりでした。
- **トマス・アクィナス（13世紀）**：品物には「正しい値段」があり、買い手にも売り手にも害のない値段で売るべきだと説きました。お金を貸して利息を取ることは「ないものを売ることで、正しくない」とされました。
- イングランドでは、**市へ向かう荷を道の途中で買い占める（先回り買い）**、**市で買った食べ物を同じ市か近くで高く売り直す（転売）**、**大量に買い込んで値段をつり上げる（買い占め）**が、3つの重い罪とされました。この決まりは1844年まで法律に残りました。

つまり昔の人は、**商人は必要だが、放っておくと飢えにつけ込む**と考え、たくさんの決まりで縛ったのです。これが次の章の「資格」の話につながります。

## 2. 販売に資格は必要だったか ― 答え：町の中では、ほぼ必要だった

「誰でも好きな場所で好きに売ってよい」時代は、中世にはほとんどありませんでした。売る権利は、**王 → 領主・教会・町 → 組合 → 一人ひとりの商人**と、上から分け与えられるものでした。

### (1) 市場を開く権利 ― 王の「特許状」
- 市場（週に1〜2回の市）や大市（年に1回、数日〜数週間）は、**王から特許状をもらった領主や町だけが開けました**。特許状には「毎週水曜に市を開いてよい」のように**曜日まで**書かれていました（例：ある町は1276年に水曜、1314年に木曜、1343年ごろに土曜の市を許された）。
- 市を持つ者は、**場所代（露店1つごとの使用料）**と**持ち込み税（売り物の荷にかかる税）**を取れました。市はそれ自体がもうかる財産でした。
- **近すぎる市は開けない**：13世紀の法律家ブラクトンは「人は1日に約32キロ歩ける。行き・売り買い・帰りで3分の1ずつ使うので、市どうしは**約10.7キロ（6と3分の2マイル）**離すべき」と書きました。近くの市は**同じ曜日や前後の日に開いてはいけない**ともされました。この決まりはイギリスの法律に今も残っています。

### (2) 市の日の裁判 ― 「ほこりまみれの足」の裁判所
- 市や大市には、その場で揉めごとを裁く小さな裁判所が付いていました。旅の商人の**ほこりだらけの足**にちなんで「ほこり足の裁判所」と呼ばれました。
- 旅の商人は長く待てないので、**その日のうち（遅くとも1日半以内）**に判決を出しました。裁くのは**商人たち自身**でした。

### (3) 商人組合と同職組合 ― 入らないと町で店を開けない
- **商人組合**：町の商人の組合。組合員は「町で自由に売り買いする権利」を持ち、そのかわりに**入会金**を払いました。入会金は多くの町で高く、組合は**選ばれた者だけの集まり**になりました。エディンバラでは、**町民の証書（組合に入る証）を持たずに商売することは事実上できなかった**といいます。
- **ロンドンの「町の自由民」**になる道は3つ：①親が自由民（相続）、②**徒弟を勤め上げる**、③**お金を払って買う**。自由民でないと、町の中で店を開けませんでした。
- **同職組合（職人の組合）**：パン屋・肉屋・織物屋・鍛冶屋など、職ごとの組合。**徒弟 → 職人 → 親方**の3段階がありました。
  - **徒弟**：親方の家に住み込み、ふつう**7年**（職によって5〜9年。料理人は2年、金細工は10年）。給料はほとんどなく、食事と寝床と修業が報酬。ドイツでは徒弟の側が**修業代を払う**のがふつうでした。
  - **職人**：修業を終え、親方に雇われて**日当をもらう**。自分の店はまだ持てない。ドイツでは**遍歴の職人**として町から町へ修業の旅をしました。
  - **親方**：「**傑作**」（腕前を示す一品）を作り、ほかの親方たちに認められると親方になり、**自分の店を開ける**。傑作の材料代は自分持ちで、落ちても返ってきません。
- **入会金の例**：フランドルのアラスの毛織物の刈り込み職人（1237年）は**親方14シリング、職人5シリング**。パドヴァの羊毛職人組合（1384年）は**10リラ**。
- 入会金は、組合の集会所の維持、事務の費用、病気の組合員の助けなどに使われました。

### (4) よそ者の商人への縛り
- **積み下ろしの権利（ケルン、1259年）**：ライン川や街道を通る商人は、ケルンで**荷を下ろして3日間売りに出さなければならず**、売れ残った分だけを先へ運べました。ケルンの商人は仲買いを独り占めでき、町は大いに潤いました。
- **ヴェネツィアの「ドイツ人商館」（1228年〜）**：ドイツから来た商人は、この商館に泊まり、**ヴェネツィアが誓わせた仲買人を必ず通して**、**ヴェネツィア人にだけ**売らなければなりませんでした。仲買人ははじめ20人、1314年から30人で、帳簿を細かくつけ、ドイツ語ができることが求められました。役人が税の払いを見張りました。
- **ロンドン（1276年）**：よそ者は、自由民でなく、身元の保証人がいなければ、町の中で宿を営めませんでした。
- **ハンザの商館**（ロンドン、ブルッヘ、ベルゲン、ノヴゴロド）：よその国の中に、ハンザの商人だけの**自分たちの決まりで動く居留地**を作りました。はかりの目盛り、品質の検査、揉めごとの裁き方をそろえ、商人から選ばれた**長老**が決まりを守らせました。

### (5) 行商人の許可状
- 町の外を歩いて売る**行商人**は、中世には「浮浪者と紙一重」と見られていました。16世紀イングランドの浮浪者取締法では、**許可のない行商人**は、大道芸人や占い師と並んで「ならず者」とされ、むち打ちや耳を焼く罰の対象でした。
- **1697年、イングランド**：行商人（徒歩）と、馬や荷車で売る行商人に**許可状が義務**になりました。はじめはアイルランド遠征の借金の利息を払うための**税**として作られたものです。
  - 申し込むには、**地元の牧師と住人2人**から「行いが正しい」という証明をもらう必要がありました。
  - **許可状なしで売ると12ポンドの罰金**。半分は**告げ口した人**に、半分は**見つかった教区の貧しい人**に渡りました。役人に見せろと言われて断ると**5ポンドの罰金**。

### (6) 量と質のごまかしへの罰
- **パンとビールの決まり（イングランド、1266年ごろ）**：パンの**重さ**とビールの**値段**を、**その年の小麦と大麦の値段に合わせて**決める法律。小麦が高い年はパン1個が軽く（同じ値段で小さく）、安い年は重くなります。ビールは町の中で「1ペニーで2ガロン」、町の外で「1ペニーで3ガロン」（大麦が安いとき）のように決まっていました（数字は資料の要約による）。
  - **罰は段階的**：初めは罰金や道具の取り上げ。繰り返すと、パン屋は**さらし台**（軽いパンを首に下げて町中に見せられる）、ビール屋は**水責め椅子**。ロンドンでは、パン屋を**そりに乗せて町中を引き回す**罰もありました。
  - 領主は年に数回、この決まりを守らせる裁きを開き、町には**ビールの味見役**がいました。
  - パン屋が重さ不足で罰せられないよう、12個に1個おまけを付けたのが「パン屋の1ダース（13個）」の始まりだという説があります。
- **公のはかり**：ロンドンでは羊毛は**王のはかり**で量らねばならず、**はかり料**を取られました。1382年、ジョン・チャーチマンが羊毛の計量所を建て、一生はかり役を務めました（のち食料品商の組合に引き継がれる）。スコットランドの町には「トロン」という公のはかりが広場に立っていました。

### (7) 日本の「座」と「楽市楽座」
- **座**：中世日本の商人・職人の組合。**朝廷・公家・大きな寺社（本所）**に保護され、**座役（お金や品物）を納めるかわりに、ある品物の仕入れ・製造・販売を独り占めする権利**をもらいました。
  - いちばん大きかったのが**大山崎の油座**。石清水八幡宮に灯明の油を納める務めと引きかえに、**えごま（油の原料）の仕入れから油づくり、販売まで独り占め**しました。1222年には美濃の不破関の関銭を、1311年には淀・兵庫など各地の関の通行料を**免除**され、畿内を中心に広く油を売りました。
- **定期市**：鎌倉時代の中ごろから月3回の「三斎市」、室町時代の後半からは月6回の「**六斎市**」が広まりました。「2と8のつく日（2・8・12・18・22・28日）」のように、**市の立つ日が決まっていました**。
- **楽市楽座**：戦国大名が、自分の城下町では**座の独り占めを認めず、座役や市の税を免除して、誰でも自由に商売してよい**とした政策。最初の例は織田信長より前（近江の六角氏）で、有名なのは**信長の安土城下の掟（1577年）**。**安土に移り住む者の税を免除**し、**街道を通る商人は必ず安土に寄る**よう命じ、町の治安も守ると約束しました。**人とお金を自分の新しい町に集めるための政策**です。
- **株仲間（江戸時代）**：幕府は逆に、商人の組合（株仲間）に**冥加金**（お礼金）を納めさせるかわりに、商売の独り占めを認めました。1841年、老中水野忠邦は「物価が高いのは株仲間の独り占めのせい」と考え、**株仲間を解散**させて自由な売り買いを勧めましたが、**かえって物の流れが乱れて失敗**し、1851年に株仲間の再興が許されました。
  - ここからわかること：**組合をなくせば安くなる、とは限らない。** 組合は独り占めをする一方で、仕入れ先とのつながり・品の保証・つけ払いの信用も支えていた。

## 3. 昔の商人の種類と暮らし

### (1) 商人の種類

| 種類 | 何をするか | 例 |
|---|---|---|
| **市場の小売り** | 市の日に露店を出す。パン・魚・肉・野菜など日々の食べ物 | 市の露店、パン屋の店先 |
| **店を構える商人** | 表通りの店で毎日売る。布・金物・香辛料・雑貨 | 織物商、食料品商 |
| **行商人** | 背負い箱や天秤棒で村を回る。針・糸・リボン・暦・薬など、村で作れない小物を売り、ついでに噂を運ぶ | イングランドの行商人、近江商人の天秤棒 |
| **仲買人** | 売り手と買い手を引き合わせ、手数料を取る。町に誓いを立てた数だけが許された | ヴェネツィアの仲買人（20〜30人） |
| **遠くと取り引きする大商人** | 船や隊商で国をまたいで品を動かす。自分は本店にいて、手紙と帳簿で各地の店を動かす | ハンザ、ヴェネツィア、ダティーニ、ソグド人 |
| **両替商・金貸し** | 国ごとに違う硬貨を両替し、為替手形を組み、貸し付ける（『お金の歴史』を参照） | メディチ家 |

### (2) 遠くと取り引きする商人
- **ハンザ（北ドイツの商業都市の同盟）**：リューベックやダンツィヒで造った丸い底の帆船「コグ船」で、塩漬けのニシン、バルト海の麦、フランドルの布、ロシアの毛皮を運びました。ノルウェーのベルゲンでは**干しダラ**の取り引きを握り、**ノルウェーの漁師に長いつけで品を売った**ので、漁師はいつもハンザに借金を抱え、ハンザに逆らえませんでした。**信用で貸すことは、相手を縛る力にもなる**のです。
- **ヴェネツィアの船団**：1315〜1533年、国が**大型の商用ガレー船**の行き先と出航日を決め、船を**競り**で商人に貸し出しました。船団は春に出て秋に帰り、国の任命した船長が率いました。**国が道と守りを用意し、商人が荷と商売を受け持つ**やり方です。
- **シルクロードの隊商**：隊商宿（キャラバンサライ）は**1日の行程、約32〜40キロごと**に建てられ、盗賊から身を守り、水・飼い葉・食事・修理・売り買いの場を提供しました。ただしラクダ500頭の隊商でも、**ビザンツの商船1隻の3分の1〜半分**しか運べませんでした。**陸は高く遅く、海は安く多く、しかし難破が怖い。**
- **シャンパーニュの大市（12〜13世紀、フランス）**：4つの町で年6回、1回6〜7週間ずつの大市が順に開かれ、**一年じゅうどこかで大市が開いている**しくみでした。シャンパーニュ伯は、大市へ向かう商人に**道中の安全を保証**しました。**領主が商人を守ると、商人が集まり、領主が潤う。**

### (3) 儲け方と損の仕方
- **儲け方**：安い所で買って高い所で売る。季節の差（秋に買って春に売る）。遠くの珍しい品（香辛料・絹・毛皮）。仲介の手数料。つけ売りの上乗せ。
- **損の仕方**：
  - **難破**：大航海時代の遠洋航海でも、7隻に1隻（約14％）が帰らなかった時代があり、18世紀のイギリス東インド会社でも**約5％**の船が失われました。
  - **盗賊と悪い領主**：道には盗賊が出て、領主にも法外な通行料を取る者や、荷を奪う者がいました。だから商人は**隊商を組んで**旅しました。
  - **値崩れ**：同じ品を持った商人が一度に着けば、値段は崩れます（エルデラントの市場もそうなっています）。
  - **踏み倒し**：王や貴族に貸したお金が返らない（『お金の歴史』のバルディ家・ペルッツィ家）。

### (4) 共同出資と保険の始まり
- **共同出資（イタリアの「託し」契約、ヴェネツィアの「組み」契約）**：1回の航海ごとに結ぶ約束。
  - **お金だけ出す人**（町に残る）と、**旅をする商人**の2人で組む。
  - お金を全部出した場合、帰ってきたら**もうけの4分の3が出資者、4分の1が旅の商人**。
  - ヴェネツィア式では、**出資者が3分の2、旅の商人が3分の1**のお金を出し、**もうけは半分ずつ**。
  - 損が出たときは、お金の損は出資者、苦労の損は旅の商人がかぶる。
  - 12〜13世紀のヴェネツィアの記録には、大商人だけでなく**職人・未亡人・聖職者**までが出資した何百もの契約が残っています。**ふつうの人も、遠くの取り引きのもうけに乗れた**のです。
- **保険**：**1347年のジェノヴァ**に、商売と切り離した保険の契約の最古の記録があります。危ない航路ほど保険料が高く、インドのグジャラートの商人は東アフリカへの航海に**荷の値打ちの7〜10％**を払って保険をかけました。プラートの商人ダティーニの記録には**400枚の保険証書**が残っています。

### (5) 商人の地位 ― 貴族・教会との関係
- 中世ヨーロッパでは、商人は「祈る人（聖職者）・戦う人（貴族）・働く人（農民）」の3つの身分のどれにもきれいに当てはまらず、教会からは**利息と欲**を疑われました。
- それでも、町の商人組合は町の政治を握り、**王に大金を貸し**、豊かな商人は土地を買って貴族に近づきました。
- 商人は罪滅ぼしに、**教会や貧しい人に多く寄進**しました。ダティーニは亡くなるとき、**7万フィオリーノ金貨の全財産と家と書類を、町の貧しい人々に遺しました**。
- 日本の江戸時代について、昔の教科書は「士農工商」と教えましたが、今の研究では、**百姓（農民など）と町人（商人・職人）のあいだに上下はなく**、どちらも「平人」という同じ身分だったとされ、2020年までに教科書からこの言葉は消えました。
- 近江商人の心がけ「**売り手よし、買い手よし、世間よし**」（三方よし）は、商人が町に役立ってこそ認められる、という考えをよく表しています（ただし、この言葉そのものは後の時代にまとめられたものです）。

### (6) 暮らしと店の構え
- **店の構え**：表通りに**間口が狭く奥に長い**家が並び、**1階の表が店、奥が作業場や倉、2階から上が住まい**。2階は通りの上に張り出していました（イングランドのサウサンプトンに残る「中世の商人の家」）。
- **店先**：ガラスはなく、**木の雨戸を上下2枚に分け、下の1枚を倒すとそのまま売り台になり、上の1枚を上げると日よけになる**。夜は閉めれば戸締まりになります。地下にはぶどう酒の蔵がありました。
- **1日の暮らし（推定）**：夜明けに雨戸を開け、朝の市で仕入れ、昼は店番と帳簿、市の日は露店、夕方に雨戸を閉め、夜は手紙と帳簿。徒弟が住み込んで店を手伝いました。
- **帳簿**：ダティーニ（1335〜1410年）は、帳簿の1ページ目に必ず「**神と、もうけの名において**」と書きました。残された記録は**帳簿約600冊、手紙15万通**。彼の店では1380年代に、今の複式簿記のもとになるつけ方がすでに使われ、1494年にパチョーリが初めて本にまとめました。

## 4. まとめ ― 社長の3つの問いへの答え

1. **なぜ商人が必要なのか？**
   作る人が作ることに専念できるように、**運ぶ・貯える・値段を決める・つけで貸す・品を保証する**を引き受ける人が要るからです。商人がいないと、品は作った場所で余り、使う場所で足りず、季節の差で飢えが起きます。
2. **販売には資格が必要？**
   **町の中では、ほぼ必要でした。** 市は王の特許状がなければ開けず、店は組合に入らなければ開けず、組合に入るには**徒弟7年**か**入会金**か**親の跡継ぎ**が必要でした。よそ者は決まった宿や仲買人を通さねばならず、行商人にも（のちに）許可状が要りました。ただし、組合の独り占めが強すぎると物価が上がるため、**楽市楽座**のように、あえて自由にして人を集めた為政者もいました。
3. **昔の商人は？**
   市の露店から、村を回る行商人、国をまたぐ大商人まで、いくつもの種類がありました。儲けは大きいが、難破・盗賊・値崩れ・踏み倒しで一夜にして失うこともある。だから**共同出資と保険**が生まれ、**帳簿**が発達しました。教会には疑われながらも、寄進と貸し付けで町と王を支えました。

## 5. エルデラントでの表し方（提案）

### (1) いまのゲームの流れ（調べた結果）
- 作り手（漁師・農民・木こりなど）がとった品は、**町の「市場」という箱にそのまま入り**、代金（相場の85％）は**市場の金庫**から作り手に払われる。
- 町の人が買うときは相場どおりに払い、**94％が市場の金庫、6％が「手数料」**としてたまり、商人が働くとその手数料をまとめて受け取る。
- つまり今は、**商人その人は品を持たず、仕入れもせず、値付けもしない**。市場の箱が商人の役をしていて、商人は手数料を集める係になっている。
- 気になる点（経済部への申し送り）：
  1. 商人が働くと、在庫が目標の2割を切った品が**毎時、目標の1割ずつどこからともなく増える**。「資源は有限」「品にもお金にも出どころがある」という社長の方針に合わない可能性がある。
  2. 暮らしの買い物（はちみつ菓子・薬・贈り物など）で市場の在庫から買うとき、代金は**市場の金庫ではなく町の蓄え**に入り、商人の取り分15％も町の蓄えから払われている。一方、食べ物の買い物は市場の金庫に入る。**同じ「市場で買う」なのに、お金の行き先が2通り**ある。お金は消えていないが、市場の金庫だけがやせていく恐れがある。
  3. 行商人と隊商は、町の市場で仕入れて、よその町の市場の金庫へ売る。これは史実の行商・隊商の形に近く、よくできている。

### (2) 商人を「本物のあいだの人」にする流れ
```
漁師 ─(魚を売る。商人の財布 → 漁師の家計)→ 魚屋（商人）の店の在庫
                                                │
町の人 ─(魚を買う。町の人の家計 → 商人の財布)─┘ → 家で食べる

商人の財布 ─(場所代・組合費)→ 町の蓄え ／ 商人組合の箱
商人の財布 ─(売上税)→ 国庫
```
- **仕入れ値**：相場の **80〜85％**（今の「作り手に払う85％」をそのまま商人が払う形に）。
- **売値**：相場の **100〜115％**。町に同じ品の商人が多いほど低く、1人しかいなければ高い（独り占め）。
- **商人の取り分（上乗せ）**：おおむね **15〜30％**。ここから場所代・組合費・倉の損（ネズミ・腐り）を払い、残りが暮らしのお金になる（数字は推定。史実の小売りの上乗せ率ははっきりした記録が少ない）。
- **腐りやすさ**：魚・肉は**1〜2日**、パンは**3日**、麦・材木・石・布は腐らない（ネズミで月に数％減る）。商人は腐る品を多くは仕入れない → **作りすぎた魚は買い手がつかず値が下がる**（社長方針の「作りすぎると値が下がる」に合う）。
- **季節の差**：麦は秋に安く、春にかけて**約2割**上がる（中世イングランドの平均）。蔵を持つ商人は秋に買い、春に売る。

### (3) 店を開く許可 ― 誰が出し、いくらで、破るとどうなるか
| 決まり | 提案 |
|---|---|
| 許しを出す者 | 町の**商人組合**（組合がない町は町長・村長）。組合は国王の**特許状**で作られる |
| なる道 | ①**徒弟**：商人の家に住み込み、**5〜7年**（ゲームでは季節を年に見立てて短くしてよい）。給料なし・食事と寝床つき ②**跡継ぎ**：親が組合員なら入会金は半額 ③**買う**：入会金を払う |
| 入会金（目安） | **日給のおよそ30〜60日分**。払い先は**商人の家計 → 組合の箱**（組合の箱は、病気や老いた組合員の助け、集会所の修理、祭りに使う。＝老後の備えともつながる） |
| 組合費 | 季節ごとに少し（日給の2〜3日分）。**商人 → 組合の箱** |
| 場所代 | 市の日の露店1つにつき**パン1個分**くらい。**露店を出す人 → 町の蓄え**（市の権利を持つのが領主なら領主の家計へ） |
| もぐりの商売 | 組合に入らず町の中で売ると、見回りの衛兵に見つかれば**品を取り上げ＋罰金**。罰金の**半分は告げた人、半分は施し箱**（1697年の行商人の法律と同じ分け方） |
| 楽市の令 | 王が「楽市」を命じると、その町では**入会金・場所代が無料**になり、よそ者も自由に売れる。人と商人が集まり町が伸びるが、組合の箱が空になり、組合の商人は不満を持つ。つけ払いと品の保証が弱まり、ごまかしが増える（株仲間解散の失敗の再現） |

### (4) 市の日と行商人・よそ者
- **市の日**：町ごとに**週1〜2回**（エルデラントの暦なら「5日に1回の休日」とは別の日）。その日は広場に露店が並び、**村の農民や行商人も場所代を払えば売れる**。ふだんは組合の店だけ。
- **市どうしの距離**：近くの町が**同じ日に市を開くと客を取り合う**。国は近い町の市の日をずらす（ブラクトンの決まり）。
- **行商人の許可状**：国が出す。**年に日給の10日分くらい**。**行商人 → 国庫**。許可状を持たない行商人は「ならず者」扱いで、捕まると罰金。許可状には**地元の神父と住人2人の保証**が要る（信用の低い者は取れない）。
- **よそ者の商人**：よその国の商人は、町に着いたら**商館（宿）に泊まり、組合の仲買人を通して**売る。仲買人は手数料（売り上げの**2〜3％**、推定）を取る。大きな町は「**積み下ろしの権利**」を王からもらえる：通る隊商は**3日間**荷を町で売りに出さねばならない（町は潤うが、隊商はその町を避けて遠回りする道を探す）。
- **市の日の裁き**：市の日の揉めごとは、組合の年寄りの商人が**その日のうちに**裁く。

### (5) ごまかしと取り締まり
- **公のはかり**：大きな町の広場に**計量所**。量ってもらうと**はかり料**（売り上げの1％ほど、推定）。**商人 → 町の蓄え**。
- **ごまかしをする商人**：正直さの低い商人は、**量を1〜2割少なく**して売る。町の人が気づく確率は、計量所があれば高い。
- **罰の段階**（パンとビールの決まりにならう）：
  1. 1回目：罰金（売り上げ数日分）。**商人 → 町の蓄え**
  2. 2回目：品と道具の取り上げ（品は施し箱へ回し、貧しい人に配る）
  3. 3回目：**さらし台**（1日広場に立たされる。町じゅうの評判が大きく下がり、客が減る）
  4. それでも続けると、組合から追放・店を閉じさせる
- **パンの値段の決まり**：パンの値段は変えず、**小麦の値段に合わせてパン1個の大きさを変える**（小麦が高い年はパンが小さい）。暴動を防ぐため、王が命じる。
- **買い占めの罪**：飢饉のとき、麦を大量に買い込む商人は罪になる（カール大帝の「恥ずべきもうけ」）。強欲な王の国ではゆるく、慈悲深い王の国では厳しい。見つかると蔵の麦を**相場で町に売らされる**（代金は商人に払う＝没収ではなく強制の売却）。

### (6) 遠くと取り引きする商人と、みんなの出資
- **共同出資**：隊商を出す商人は、町の人から出資を募れる。帰ってきたら**もうけの4分の3を出資者、4分の1を旅の商人**（全額出資の場合）。**出資者の家計 → 商人の財布 → （航海・旅） → 出資者の家計**。職人や未亡人も出資できる。隊商が盗賊に襲われれば、出資者のお金も消える（盗賊の手に渡る＝盗賊の蓄えへ。消えはしない）。
- **保険**：港町の両替商が、船の荷に保険をかける。保険料は**荷の値打ちの5〜10％**（危ない航路ほど高い）。**商人 → 両替商**。難破したら**両替商 → 商人**に払う。
- **商人の地位**：もうけた商人は教会へ**寄進**して評判を上げる（罪滅ぼし）。大商人は王に貸し付け、ときに爵位をもらう。
- **帳簿**：商人は品物ごと・相手ごとに記録をつける。詳しい画面では「今季のもうけ」「つけの貸し」「借り」が見える。

### (7) お金の出どころと行き先のまとめ
| 流れ | 払う側 | 受け取る側 |
|---|---|---|
| 仕入れ | 商人の家計 | 作り手（漁師・農民・職人）の家計 |
| 売り上げ | 町の人の家計 | 商人の家計 |
| 入会金・組合費 | 商人の家計 | 組合の箱 |
| 組合の助け（病気・老い） | 組合の箱 | 組合員の家計 |
| 場所代・はかり料 | 商人・露店の主 | 町の蓄え（または市の権利を持つ領主） |
| 行商人の許可状 | 行商人の家計 | 国庫 |
| 仲買人の手数料 | よそ者の商人 | 仲買人の家計 |
| 罰金 | 違反した商人 | 半分は告げた人、半分は施し箱（または町の蓄え） |
| 共同出資 | 出資者の家計 → 商人 | もうけとともに出資者へ戻る |
| 保険 | 商人 → 両替商 | 難破のとき 両替商 → 商人 |
