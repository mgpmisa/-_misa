# お金の歴史 ― 昔の世界では、お金はどう生まれ、どう流れたか

エルデラント年代記の「造幣所」と「両替商の館」を作るために、中世ヨーロッパと中世イスラーム世界のお金のしくみを調べた読み物です。
数字のうち、はっきりした記録がないものは「推定」と書いてあります。

---

## 1. お金はどこから生まれるのか ― 王の造幣所

中世のお金は、ほとんどが**銀貨**（ときどき金貨）でした。紙のお金はまだありません。
お金の量は、王の気分で決まるのではなく、**銀がどれだけ手に入るか**で決まりました。

- 鉱山で掘られた銀や、外国の商人が持ち込んだ銀の塊（地金）、古い銀の食器などが、王の造幣所に持ち込まれます。
- 造幣所は、それを溶かして決まった重さの硬貨に打ち直し、持ち込んだ人に返します。
- そのとき、**手間賃**（職人の取り分）と**造幣益**（王の取り分）が差し引かれます。
  - たとえば12〜13世紀のイングランドでは、銀1ポンド（銀貨240枚ぶん）につき、職人の手間賃が6ペンス、王の造幣益が6ペンス、あわせて約5％でした。
- だから「毎年どのくらい発行されるか」は、**その年に造幣所へ持ち込まれた銀の量**しだいです。大きな銀山が見つかれば一気に増え、銀が外国へ流れ出れば減りました。

### 発行量と通貨の量の目安（推定）
イングランドの歴史家たち（マイヒューなど）の推定では、国じゅうに出回っていた硬貨の総額は、おおよそ次のように増えました。

| 年ごろ | 出回っていた硬貨（推定） | ようす |
|---|---|---|
| 1086年 | 約2万5千〜4万ポンド | 土地台帳（ドゥームズデイ・ブック）のころ |
| 1200年ごろ | 約25万ポンド | ドイツの銀山の銀が流れ込む |
| 1300年ごろ | 約90万〜110万ポンド | 羊毛の輸出で外国の銀が入る |

※これは硬貨の見つかり方や造幣所の帳簿から逆算した**推定**で、学者によって幅があります。
1180〜1220年ごろには、銀が急に増えたことで物の値段が2〜3倍になった（「大インフレ」と呼ばれる）と考えられています（通説・推定）。

### 銀が増えすぎると ― 価格革命
16世紀には、アメリカ大陸のポトシ銀山などから大量の銀がヨーロッパへ入り、150年ほどで物の値段が**平均して約6倍**になりました（年に1〜2％ずつ上がり続けた計算）。
反対に15世紀には銀が足りなくなり、「大いなる地金飢饉」と呼ばれる、お金が足りずに商売が止まる時代もありました。

**つまり：お金の量と物の量の釣り合いで、物の値段は上がったり下がったりする。**

---

## 2. お金はどう流れるか

1. **王の支払い**：造幣益や税で国庫に入ったお金は、兵士・騎士・役人の給金、城や道の普請の賃金として世の中に出ていきます。新しい硬貨が民の手に渡る一番大きな道です。
2. **市場と商売**：民は給金で食べ物や道具を買い、職人や商人の手に渡ります。
3. **税**：人頭税・地代・関税・教会の十分の一税として、またお上や教会へ戻ります。
4. **外国との交易**：売るものが多い国には外国の銀が流れ込み、買うものが多い国からは銀が流れ出ました。
5. **しまい込み（退蔵）**：使われずに壺や箱にしまわれたお金は、そのあいだ世の中から消えたのと同じです。

---

## 3. 硬貨の質を落とす ― 悪鋳（あくちゅう）

国庫が苦しい王は、よく**硬貨に混ぜる銀を減らしました**。同じ量の銀から、より多くの硬貨が作れるので、その差がそのまま王のもうけになります。

- 有名なのはイングランドのヘンリー8世の「大悪鋳」（1544〜1551年）です。銀の割合は、もとの92.5％から50％、さらに33％まで下げられ、最後には硬貨の値打ちの4分の1しか銀が入っていませんでした。
- 銀が薄くなって下の銅が見え、王は「銅鼻のじいさん」とあだ名されました。
- 結果、物の値段が大きく上がり、民の暮らしは苦しくなり、王の信用も落ちました。
- 後の王（エリザベス1世）は、国庫の負担で悪い硬貨を鋳つぶし、良い硬貨に戻しました。

### 悪貨は良貨を駆逐する
同じ「1枚」なのに銀の多い硬貨と少ない硬貨が混ざると、人は**良い硬貨をしまい込み、悪い硬貨で払う**ようになります。
14世紀のフランスの学者オレームがすでにこのことを書いていて、のちに「グレシャムの法則」と呼ばれました。

---

## 4. すり減る硬貨・削られる硬貨・打ち直し

- 銀貨は使ううちにすり減り、ふちを削り取る悪い人もいました。重さの足りない硬貨は、両替商に安く見られます。
- ドイツやポーランドなどでは、**毎年（ときには年に2回）古い硬貨を無効にして、新しい硬貨に替えさせる**「定期改鋳」がありました。
  - そのとき「古い硬貨4枚で新しい硬貨3枚」のような手数料を取ったので、実は**お金の持ち主から取る税**でした。
  - 150〜200年ほど、ヨーロッパの広い地域で続いたしくみです。

---

## 5. 両替商と銀行家

国ごと・町ごとに違う硬貨が出回っていたので、**両替商**が欠かせませんでした。
両替商は市場に机（イタリア語で「バンコ」＝銀行の語源）を置き、硬貨の重さと質を見て両替し、手数料を取りました。
やがて両替商は、次のような仕事もするようになります。

- **預金**：お金持ちや商人の硬貨を預かる。家に置くと盗まれるが、預ければ証文だけで済む。
- **振替**：預金者どうしの支払いを、帳簿の書き換えだけで済ませる。
- **貸付**：預かったお金の一部を、商人や貴族、王に貸す。
- **為替手形**：ある町でお金を預け、遠い町で受け取れる証文を出す。

### 利子の禁止と工夫
キリスト教会は、お金を貸して利子を取ること（高利）を罪としていました。イスラーム世界でも利子（リバー）は禁じられていました。
そこで商人たちは工夫しました。

- **為替手形に利子を隠す**：フィレンツェのメディチ家などは、「ここで払って、90日後に遠い町で受け取る」為替手形の**両替の相場に利ざやを入れて**、利子の代わりにしました。「両替は危険を伴う正当な商売」とされたからです。
- **預金への「お礼」**：預金者には利子ではなく、銀行の「気持ち（ディスクレツィオーネ）」として、もうけの一部を分けました。
- **質屋**：品物を預かってお金を貸す店。15世紀のイタリアでは、フランシスコ会の修道士が、貧しい人に低い利子で貸す慈善の質屋「モンテ・ディ・ピエタ」（1462年、ペルージャが最初）を作りました。

---

## 6. 遠くへお金を送る ― テンプル騎士団とイスラームの手形

- **テンプル騎士団**（12世紀〜）は、巡礼者がロンドンやパリの騎士団の館でお金を預け、証文を受け取り、はるか遠いエルサレムでその証文と引き換えにお金を受け取れるしくみを作りました。道中でお金を持ち歩かないので、盗賊に奪われません。
- **イスラーム世界**ではもっと早く、9〜10世紀のアッバース朝で、
  - **サック**（小切手のもと。英語の cheque の語源とも言われる）：両替商あての支払い指図書。
  - **スフタジャ**：ある町で払い、遠い町で受け取る為替手形。バスラで書いた手形を、はるかサマルカンドで受け取れた。
  - **ハワラ**：信頼でつながった両替商の網を使い、現金を運ばずに「値打ちだけ」を送るしくみ。いまも使われています。

---

## 7. 銀行が潰れるとき ― 取り付け騒ぎ

- 銀行は、預かったお金をすべて金庫に置いているわけではなく、一部を貸しています。
- 「あの銀行は危ない」という噂が立つと、預金者が一斉に引き出しに来ます（**取り付け騒ぎ**）。金庫が空になれば、残りの人は払ってもらえません。
- **フィレンツェのバルディ家・ペルッツィ家**は、14世紀のヨーロッパ最大の銀行でしたが、イングランド王エドワード3世に戦費として巨額を貸し、1340年代に王が返さなかったこともあって破綻しました（ただし、それだけが原因ではなかったとする研究もあります）。
- **バルセロナ**では、約束を果たせなかった銀行家は厳しく罰せられ、1360年には銀行家フランセスク・カステリョが自分の両替の机の前で首をはねられました。その後、1401年に町が営む公の銀行（タウラ・デ・カンビ）が作られました。
- 「破産（バンクラプト）」という言葉は、イタリア語の「バンカ・ロッタ（壊れた机）」から来たとも言われます。

---

## 8. 壺に埋めたお金 ― 退蔵と掘り当て

- 銀行を信じない人、戦や盗賊を恐れた人は、硬貨を**壺に入れて地面に埋めました**。
- 埋めた本人が死に、誰も場所を知らなければ、そのまま何百年も眠ります。
- イギリスでは今でも畑や庭から昔の硬貨の壺がたびたび見つかります。昔から、見つかった埋蔵物は**王（国）のもの**とされ、今は博物館が買い取って、見つけた人と土地の持ち主で分ける決まりです。

## 9. エルデラントでの表し方

| 昔の世界 | エルデラント |
|---|---|
| 王の造幣所と造幣益 | 各国の王都に「王立造幣所」。鉱山で掘れた銀と金（鉱脈は有限）を国が買い上げて硬貨にする。代金は鉱夫の家計へ、造幣益（強欲な王ほど高い 5〜10％）は国庫へ、手間賃（3％）は王都の蓄えへ。すべて「発行」として記録 |
| 発行量は銀の供給しだい | 1日の発行量は、その日に掘れた銀と金の量で決まる。鉱脈が尽きれば止まる |
| お金の量と物価 | 国ごとの「物価の水準」。1人あたりの硬貨の量、市場の品物の量、硬貨の質で決まり、市場の値段すべてに掛かる（上限1.4倍、下限0.75倍） |
| 悪鋳 | 国庫が苦しく、良心の薄い王は硬貨の銀を減らす。国庫は一時的に潤うが、物価が上がり、民の不満と王の信用が下がる。豊かで誠実な王は、国庫で悪貨を鋳つぶして良貨に戻す（「回収」として記録） |
| すり減り・定期改鋳 | 硬貨は年に約1.5％すり減る。すり減ったら打ち直し。強欲な王は「10枚に1枚」の手数料を取る |
| 両替・相場 | 国ごとに硬貨の質が違い、両替の相場が決まる。国をまたぐ手形には打歩（両替の手数料）がかかる |
| 両替商の館（銀行） | 王都にある。預金（利子の代わりに、もうけの一部を「お礼」として分ける）、引き出し、商人や職人への貸付（利子は為替の差益の形）、王への貸付 |
| 為替手形 | 隊商の商人が現金の代わりに手形を持てば、盗賊に襲われても奪われない |
| 取り付け騒ぎと破綻 | 王の踏み倒しや貸し倒れの噂で、預金者が押し寄せる（まれ）。金庫が尽きると館は潰れ、預金者は財産を失い、それを覚えて銀行を信じなくなる。残った貸付を取り立てて「破産の配当」を少し返す。20日後に店を開き直す |
| 壺に埋めたお金 | けちな人、銀行を信じない人、悪貨を嫌う人は、硬貨を壺に入れて埋める。本人が死に、場所を誰も知らなければ埋まったまま。畑仕事や開拓で掘り当てられる（正直者は半分を国庫へ届け出る）。この世界の歴史の名残りとして、昔の壺も各地に眠っている |
