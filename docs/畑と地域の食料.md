# 畑と地域の食料（企画部）

企画部 作成（2026年9月27日）。社長の指示「ファンタジー世界の畑の種類を調べてください」「世界に食べ物の流通が少なすぎる」を受けて調べた。
中世ヨーロッパの実際をもとにして、少しだけ魔法の作物を足す。数字はそのまま実装に使える目安で、動かしてから合わせる。

---

## 0. はじめに：今の世界を測った結果

新しい世界（種 12345）を作り、3日分動かして数えた。

| 項目 | 数 |
|---|---|
| 住人 | 741人・18の町と村 |
| 畑のマス／牧草地のマス | 424／52 |
| 農夫・狩人・漁師・薬草摘み | 66・17・34・62人 |
| 粉屋・パン職人・肉屋・酒造り | **1・6・0・0人** |
| 乳を出す家畜（世界全体） | **乳牛2頭・山羊6頭**。卵を産む鶏16羽・アヒル7羽 |
| 3日後に市場に並んでいた食べ物の種類 | 小麦・パン・麦酒・肉・魚・はちみつのほかは、**町ごとに1〜3種類だけ**。18の町の合計で、牛乳9・卵8・野菜1・果物3・チーズ0 |
| 隊商 | 3日で23台出発。ただし運べるのは基本の品20種類だけで、チーズや燻製は運べない |

**わかったこと**：食べ物の一覧（料理や保存食が千種類以上）はそろっている。けれど、作る人・作る建物・運ぶ道がないため、市場まで届いていない。
さらに、乳と卵は家の食卓へ直接入るので、売られることがない。

### 暦の決まり（この文書での「月」）
- 1年は40日、季節は10日ずつ（`DAYS_PER_SEASON = 10`）。
- この文書では、春＝3・4・5月、夏＝6・7・8月、秋＝9・10・11月、冬＝12・1・2月とする。**1か月はおよそ3.3日**。
- 日数は「ゲームの日数」で書く。本当の日数の約0.11倍（40÷365）にした。
- 1年の何日目か（0〜39）で書くときは、季節×10＋季節の中の日。例：秋の3日目＝23。

## 1. 作物の表

- **1区画＝畑1マス**。収量は、1回の収穫で「袋」（今の小麦1つ＝1食分と同じ単位）がいくつ取れるか。
- 合わせ方：今の世界の農夫は、1人あたり年に約1,400袋の小麦を作っていて（畑はおよそ6マス）、1マスあたり年に約220袋になる。三圃制で3分の1を休ませても今と同じ量になるよう、**小麦は1回の収穫で300袋**を基準にした。全体の倍率 `YIELD_SCALE` を1つ置き、足りなければそこで合わせる。
- 連作の害：前の年と同じ作物を同じ区画に植えたとき、収量が何割減るか（2年続けば2倍）。
- 土の栄養（地力）の増減：1回の収穫で地力がどれだけ動くか（次の章）。

## 2. 土の栄養の仕組み（地力・休耕・肥やし・輪作）

### 2-1. 畑1マスごとの記録（新しい状態）
`S.farm.plots[マスの番号] = { f: 地力0〜120, crop: 今の作物, sown: 種をまいた日, last: 前の作物, rep: 同じ作物が続いた回数, fallowFrom: 休ませはじめた日, owner: 世帯 }`
古いセーブで無いときは、最初の日に作る（`S.farm = S.farm || {}`）。

### 2-2. はじめの地力（地形から）
| 畑になる前の地形 | はじめの地力 |
|---|---|
| 川・沼から3マス以内の草原 | 90 |
| 草原 | 70 |
| 森を切り開いた畑（最初の2年は切り株で収量×0.8） | 80 |
| サバンナ | 55 |
| 雪の縁・丘の斜面 | 45 |
| 砂漠（オアシスの近くでだけ畑にできる） | 30 |

### 2-3. 収量の式
収量 ＝ 作物の収量 × 地力の効き × 連作の害 × 季節の天気（今の `harvestMul`）× 農夫の腕 × `YIELD_SCALE`
- 地力の効き ＝ 0.3 ＋ 0.7 ×（地力 ÷ 70）。上限1.4。地力70で1.0、地力0でも0.3は取れる。
- 土地が合わない作物（表の「好む土と気候」の外）は×0.6。まったく合わない（砂漠で小麦など）は植えない。

### 2-4. 地力が動くとき
| できごと | 地力 |
|---|---|
| 収穫 | 表の「地力」の値 |
| 休耕（1季節） | ＋10 |
| 休耕地に家畜を放す（羊・牛のふんが落ちる）（1季節） | さらに＋6 |
| 肥やしを1荷まく | ＋4（1回の作につき3荷まで） |
| 灰・海藻・米糠・骨粉を1荷まく | ＋2 |
| 魔物の灰・スライムの粘液を1荷まく（魔法の肥やし） | ＋6（ただし月光麦の畑にだけ使える、という決まりでもよい） |
| 何もしない（植えずに放っておく） | ＋5／季節（草が生えて少しずつ戻る） |

### 2-5. 肥やし（家畜のふん）の量
| 家畜 | 1日あたりの肥やし | 注 |
|---|---|---|
| 牛・馬 | 0.5荷 | 冬に小屋で飼う間だけ集まる。夏は牧草地に落ちる |
| 豚 | 0.25荷 | |
| 羊・山羊 | 0.1荷 | 夜に休耕地の囲いに入れると、そのまま地力になる |
| 鶏・アヒル | 0.03荷 | 少ないが強い（×1.5） |
- 肥やしは家畜の飼い主の蔵にたまる品（`manure`、目安の値打ち0.3）。自分の畑にまくか、市場で農家に売る。
- お金：**農家の家計 → 家畜の飼い主の家計**（市場で買う。`marketBuy`）。
- 今ある「週に1度、肥やしを買うと実りが2割増える」（`fertUntil`）は、この仕組みに置きかえる。

### 2-6. 輪作の型
| 型 | 順番 | 使う国・地域 |
|---|---|---|
| 三圃制（基本） | 秋まき麦 → 春まき（大麦・燕麦・豆） → 休耕（家畜を放す） | アルデリア・ヴェルムントの村 |
| 二圃制 | 麦 → 休耕 | サハル王国（乾いた土地。休ませないと持たない） |
| 四圃輪作（研究「輪作農法」で解禁） | 小麦 → 蕪 → 大麦 → 牧草（クローバー） | 研究した国。**休耕がなくなり、蕪と牧草で冬の家畜が増え、肥やしも増える** |
| 水田 | 稲を毎年 | 沼・川べり |
| 菜園（家の裏） | 野菜を毎年。家の灰と台所の屑で肥やす | すべての家（1家に1〜2マス） |

- 今の研究「輪作農法」（実り×1.25）は、四圃輪作を使えるようになる効果に置きかえる。
- 農夫の頭の中：区画ごとに「去年は何を植えたか」を見て、表の順番で次を決める。値段が高い作物を少し多めに選ぶ（作りすぎると値が下がるので、町の在庫が目安の1.5倍を超えた作物は選ばない）。

### 2-7. 農夫の1年（季節で仕事が変わる）
| 季節 | 仕事 | 今のコードとの違い |
|---|---|---|
| 春 | 春まき（大麦・燕麦・豆）・畑を耕す（牛か馬がいると2倍速い）・子羊の世話 | |
| 夏 | 干し草刈り・麦の収穫（7〜8月）・脱穀 | |
| 秋 | 秋まき（小麦・黒麦）・蕪の収穫・豚を森に放つ・冬に向けた屠畜と塩漬け | |
| 冬 | **畑では何も取れない**。脱穀の続き・道具の修理・かご編み・肥やし運び | 今は冬も0.25倍で麦が取れる。これをやめ、蔵から出して売る |

## 7. 流通を増やす案

どの案も**お金は取り引きでしか動かさない**。払う側と受け取る側を必ず書いた。

### 案A：乳・卵・菜園を「売る物」にする（すぐできる・小）
- 乳・卵・菜園の野菜・摘んだベリーを家の蔵へ入れ、家族が食べる2日分を残して、**毎朝市場へ売る**。
- お金：**市場の持ち主の札（買った市民の家計）→ 作った家の家計**。今の `marketDeliver` と `marketBuy` をそのまま使う。
- 村の農家すべてに乳牛1頭か山羊2頭、鶏4〜6羽を持たせる（4章）。
- これだけで、市場の食べ物の種類が町ごとに1〜3種類から、6〜10種類になる見込み。

### 案B：定期市（週の市）と年の大市
- **週の市**：どの町も5日に1度（休みの前の日）、広場に市が立つ。周りの村の農家・狩人・薬草摘みが、蔵の余りを背負って町へ歩いて行き、広場の屋台で売る。
  - 売り手の決まり：家の蔵に、その品が「家族の3日分」より多くあれば、多い分を持っていく（背負いかごで20まで・ロバで60まで）。
  - お金：**買い手（町の人の家計・財布）→ 売り手（村の人の家計）**。場所代：**売り手 → 町の蓄え**（1銅貨）。
  - 帰りに、その町でしか買えない物（道具・塩・布）を買って帰る。
- **年の大市**：各王都で年に2回（春の7日目・秋の5日目）、3日間。よその国の商人と隊商が集まり、遠くの品（葡萄酒・香辛料・チーズ・干し魚）が並ぶ。
  - お金：**買い手 → 遠くの商人の財布**。商人は帰り道で自分の町の市場に卸す。

### 案C：行商人を本当に歩かせる
- 今の行商人（3人）を、村から村へ回る仕事にする。5日で3〜4の村を回る道を持つ。
- 仕入れ：安い村で買う（**行商人の財布 → 品の持ち主**）。売る：高い村で売る（**買い手 → 行商人の財布**）。値の差が1.3倍以上の品だけ運ぶ。
- 運べる量：背負い箱20・ロバを連れていれば60。日持ちが短い物（牛乳・生の肉）は運ばない。
- 民族の村とも、行商人だけは物を売り買いする（塩・鉄の針と、珍しい干し肉・薬草を交換）。
- 行商人は各町に1人を目安に増やす（18人ほど）。

### 案D：隊商に食べ物を積めるようにする（いちばん効く）
- 今の隊商は基本の品20種類しか運ばない。これを、**日持ち20日以上の食べ物**（チーズ・燻製・塩漬け・干し魚・干し果物・蜂蜜・葡萄酒・蒸留酒・塩・麦・粉・干し豆）にも広げる。
- 選び方は今のまま（行き先の値段が1.08倍より高い品）。ただし食べ物は、行き先の町で「足りない食べ物」（3章の地域の型の「足りないもの」）を優先。
- お金：今のまま（**商人 → 出発地の品の持ち主、行き先の買い手 → 商人**）。

| 生の魚（2日） | 塩漬け（ニシン）・干す（棒鱈）・燻す | 240・365・60日 |
| ベリー・果物（3日） | 蜂蜜煮・干す | 120・180日 |
| キャベツ（20日） | 酢漬け | 120日 |
| 麦（120日） | 粉（120日）・堅焼きパン（60日）・麦酒（30日） | |
- 保存食を作ると値打ちが1.5〜2倍になり、遠くへ運べる。作る側の決まり：**生の物が町で余って（在庫が目安の1.5倍以上）、値が下がったときに、保存食の職人がまとめて安く買う**。
- 塩が鍵になる：塩漬け1つに塩0.2。**塩の道**（塩田・港 → 内陸の町）を隊商の優先の品にする。

### 案F：食事処を増やす（食べ物を「買って食べる」場を作る）
- 屋台：市の日と祭りの日に広場に出る。町の人の昼飯の半分ほどが屋台で済む。
- 料理屋：王都と港町に1軒ずつ。家にかまどのない貧しい家は、夕飯を料理屋で買う。
- お金はどちらも **客 → 主**、**主 → 材料の持ち主**（6-2の表）。

### 案G：地域どうしの交換（国と国の取引）
| 出す地域 | 送る物 | 受け取る地域 | 返す物 |
|---|---|---|---|
| アルデリア（剣と麦）の穀倉 | 小麦・粉・麦酒 | ヴェルムント（鉄と雪）の鉱山町 | 鉄の道具・武器・毛皮 |
| ヴェルムントの港 | 塩漬け魚・干し魚 | アルデリア・サハルの内陸 | 麦・葡萄酒 |
| サハル（砂と黄金）の南 | 香辛料・オリーブ油・干し棗・砂糖 | 北の二国の王都 | 麦・材木・チーズ |
| 牧畜の村 | チーズ・羊毛・革 | 王都 | 麦・塩・道具 |
| 民族の村（行商人を通して） | 珍しい干し肉・薬草・魔物の素材 | 近くの村 | 塩・鉄の針・布 |
- 国どうしの取引は `diplomacy.js` の協定にのせる：「麦と鉄の協定」を結ぶと、関所の通行料が半分になり、隊商がその品を優先して運ぶ。お金：**隊商の商人 → 関所の国の国庫**（通行料。今のまま）。

## 8. 今のコードとの差

### 今あるもの
- 畑（`FIELD` 424マス）と牧草地（`PASTURE` 52マス）。農夫は小麦だけを作り、季節の倍率（春0.9・夏1.3・秋2.4・冬0.25）と天気（`harvestMul`）で量が変わる（`sim.js` の `doWork`）。
- 研究「輪作農法」（実り×1.25）と「灌漑」。肥やしを買うと7日間実り×1.2（`matter.js` の `useDaily`、`fertUntil`）。
- 食べ物の一覧は大量にある（`catalog/food*.js`：粉・パン・焼き肉・燻製・塩漬け・チーズなど／`catalog/plant2.js`：穀物18・豆11・野菜26・根22・果物48）。
- 家畜の役目（乳・卵・毛・肉・耕す・荷運び）。乳と卵は飼い主の家の食卓へ直接（`fauna.js` 1386行あたり）。羊毛は春に蔵へ。
- 狩りで倒した獣の部位（`matterHunt`）。密猟の考え（`poach`）。
- 粉ひき小屋・パン屋・酒場・宿屋・市場・よろず屋・穀物倉。職場の蔵（`workshop.js`）。
- 隊商（荷車と船、同時に14台まで）。
- 開拓の資源「肥えた土地」「塩田」（`expansion.js`）。

### ないもの
- 区画ごとの作物・地力・連作・休耕・種まきから収穫までの時間。
- 作物ごとの土地と気候の向き不向き。地域の型。
- 乳・卵を売る流れと、乳製品の工房（チーズ・バター）。
- 醸造所・燻製小屋・塩蔵所・塩田・干し場・製糖所・搾油所・菓子屋・氷室。
- 屋台・料理屋。定期市と年の大市。
- 季節ごとの獲物とベリー摘みの決まり。狩猟の許し。

### 直すべき所
1. **農夫が採る作物は、季節も土地も見ずに一覧から無作為に選ばれている**（`matter.js` の `matterWork`：`harvest` の候補をすべて同じ重みで選ぶ）。→ 区画に植えた作物を、収穫の月に採るようにする。
2. **乳と卵が家の食卓へ直接入る**ので、売られず、お金も動かず、チーズの材料にもならない（`fauna.js`）。→ 蔵に入れる。
3. **乳を出す家畜が世界に8頭しかいない**。→ 農家1家に乳牛1頭か山羊2頭。
4. **肉屋・酒造りが0人、粉屋が1人**。→ 町の割り当て（`data.js` の町ごとの職業の数）に入っているのに、世界ではいない。確かめて直す。
5. **隊商が運べるのは基本の品20種類だけ**（`logistics.js`）。→ 日持ちする食べ物を加える。
6. **冬も麦が採れる**（倍率0.25）。→ 冬は採れず、蔵から出して売る。
7. 3日動かすと、市場の食べ物は町ごとに1〜3種類しかない。上の1〜5を直した後に、また測って比べる。
