# 町・村・王都に要る建物の一覧

開発部 作成（2026年9月27日）。社長の指示「宿屋はありますか？」「世界に必要な建物が何かを調べて作成してください」を受けて調べた。

- 「いまの世界」の欄：〇＝ある、△＝ほかの建物が代わりをしている、×＝ない、★＝今回つくった
- 置き場所の目安：王都（人口60〜80人）、港町（15〜30人）、村（10〜25人）。開拓で生まれた町にも、人口と格に応じて建つ。

## 1. 今回つくった建物（js/buildings.js・js/bldnew.js）

### 宿屋（旅籠）★ いちばん大事
- **役目**：旅人・行商人・冒険者・巡礼が泊まる。食事と寝床、馬の世話。酒場とは別の建物にした（これまでは酒場に寝台が1台だけで、多くの旅人は床で寝ていた）。
- **史実**：中世の宿は、旅人に食事と寝床、馬の厩と飼い葉を出した。大きな町には個室のある宿もあったが、村では相部屋がふつうで、見知らぬ人と1つの寝台を分け合うことも多かった。砂漠や街道には、中庭を囲んで客室と厩を並べた隊商宿（キャラバンサライ）が、1日の道のりごとに置かれた。
- **働く人**：宿の主（新しい仕事）。いなければ酒場の主が宿代を受け取る。
- **使う人**：
  - 家のない旅の人（旅人・吟遊詩人・旅芸人）
  - 宿住まいの世帯（流れの冒険者など。宿代は毎日まとめて払う）
  - よその町に来ている人（巡礼・行商など）
- **部屋**：3マス幅の客室が北（大きな宿は南にも）に並び、廊下と帳場・食堂がある。
  - 王都：11部屋・寝台21台（うち夫婦用4台、大部屋に二段寝台3台）
  - 港町：10部屋・寝台14台（うち夫婦用3台）
  - 村：4部屋・寝台6台
  - 寝台は1台に1人。夫婦用の大きな寝台だけは夫婦2人で寝る。
- **満室のとき**：近くの厩舎（なければ宿の馬小屋）のわらの上で寝る（1銅貨）。それも払えなければ軒下で野宿。
- **お金**：宿代は泊まった夜に、客の財布（足りなければ家計）から宿の主の家計へ。王都4銅貨・港町3銅貨・村2銅貨。
- **南の国**：キャラバンサライ（中庭を囲む砂岩の壁と四隅の小塔）の形で建つ。

### 公衆浴場（湯屋。南の国ではハンマーム）★
- **役目**：体を洗い、疲れを取り、近所の人と話す場。
- **史実**：中世ヨーロッパの町には「湯屋（stew）」が多く、1292年のパリには少なくとも26軒あった。湯を沸かすかまどと木の湯桶、蒸し風呂があり、人が集まる娯楽の場でもあった。16世紀に急に減った。イスラムの町では、ハンマームはモスクや市場のそばに置かれ、だれでも入れるように料金が安かった。
- **働く人**：湯屋の主（新しい仕事）
- **使う人**：6歳以上のだれでも。2日に1度くらい、疲れや汚れがたまった人、休みの日の人が行く。
- **効き目**：疲れが取れ、楽しみ・怠けたい気持ち（くつろぎ）が満たされ、体の汚れ（新しく足した「汚れ」）が消える。
- **お金**：入浴料（王都2銅貨・ほか1銅貨）は、入ったときに客から湯屋の主へ。湯屋の主は日の終わりに、その日に焚いた分の薪を市場から買う。

### 図書館 ★（王都）
- **役目**：本を読み、学ぶ。
- **史実**：中世の本はとても貴重で、大事な写本は書見台に鎖でつながれていた（持ち出されないように）。修道院の図書館は、保証金をとって本を貸すこともあった。チェゼーナのマラテスティアーナ図書館（1454年）には、鎖つきの書見台が今も残る。
- **働く人**：司書（新しい仕事）。学者も仕事場の一つとして使う（町の外の展望台で魔物に怯えるばかりだったのを和らげる）。
- **使う人**：学問を好む大人（好奇心が強い人、書記・教師・学者・司祭など）、昼過ぎの子ども。
- **効き目**：学び（skill.study）が伸びる。大人が読むと、国の研究も少し進む。
- **お金**：使うのは無料。司書の給金は給料日（7日ごと）に、町の蓄え（足りなければ国庫）から、働いた日数ぶん払う。

### 劇場（芝居小屋）★（王都）
- **役目**：夕方から芝居を見せる。
- **史実**：中世の町では、組合（ギルド）が聖書の物語を演じる「神秘劇」を、車の付いた舞台（ページェント・ワゴン）で町を回って見せた。のちに宿屋の中庭や、丸い芝居小屋で演じるようになった。
- **働く人**：役者（新しい仕事）。王都にいる旅芸人も舞台に立つ。
- **使う人**：10歳以上。役者が舞台に立っている晩（17時半〜21時半）だけ、客が入る。
- **効き目**：楽しみが大きく満たされる。演目（「竜殺しの騎士」「王妃の涙」など8つ）を見た思い出が残る。
- **お金**：木戸銭（王都3銅貨、子どもは半分）は、入ったときに客から、その晩に舞台に立っている役者たちへ山分け。

### 仕立て屋 ★（王都。人口35人以上の町）
- **役目**：服を仕立てる。
- **史実**：12〜14世紀に、体に合わせて服を裁って縫う技が広まった。仕立て屋は組合をつくり、親方・職人・徒弟の順に修業した（1244年のボローニャの仕立て屋組合の規約など）。
- **働く人**：仕立て屋（今の仕事。仕事場を工房からここへ移す）
- **使う人**：服がすり切れた14歳以上の人（新しく足した「服のすり切れ」。力仕事の人ほど早い）。
- **お金**：服の代金は客から仕立て屋へ。仕立て屋は布を1反、市場から買う（布がなければ作れない）。

### 薬屋 ★（王都・人口25人以上の港町と町）
- **役目**：薬と薬草を売る。
- **史実**：薬屋（アポセカリー）は修道院から始まり、13世紀から組合をつくった。香辛料や薬草を量り売りし、ロンドンでは食料雑貨の組合の中にあった（1345年に薬屋の店の記録）。
- **働く人**：薬師（今の仕事。仕事場を診療所からここへ移す）。錬金術師も半分はここで働く。
- **使う人**：病気の人（寝込むほどではない人）、けがをした人。
- **効き目**：病の重さが下がり、体力が戻る。
- **お金**：薬代は客から薬師へ。薬師は薬（なければ薬草）を市場から仕入れる。

### よろず屋 ★（市場のない村）
- **役目**：村の人が食べ物や日用品を買う店。これまで村の人は、市場の建物がないので「広場で」買い物をしていた。
- **史実**：中世の村には市場がなく、行商人や、町の定期市、何でも少しずつ置く店に頼った。
- **働く人**：よろず屋の主（新しい仕事）
- **使う人**：村で買い物をする人は、みなここへ行く。
- **お金**：品物の売り買いは今までどおり市場の帳面で行い、買い物客が払った手数料は、日の終わりによろず屋の主へ。

### 穀物倉 ★（王都・村・人口20人以上の港町）
- **役目**：実りの秋に小麦を買い入れて蓄え、飢饉のときに安く市場へ出す。
- **史実**：町は周りの農村と市場の小麦に頼っていた。長い凶作に備える蓄えは、王・領主・教会・豪商だけが持てた。1315〜17年の大飢饉のように、1度の凶作が何年も続く危険があった。マルタの地下の穀物倉（イル・フォッソス）のような大きな倉も作られた。
- **働く人**：倉番（新しい仕事）。倉番が見回ると、ねずみと湿気で減る分が少なくなる。
- **お金**：秋や小麦が安いときは、町の蓄えで市場から買い入れる（町の蓄え → 市場の金庫）。飢饉（小麦とパンが足りない、または小麦の値段が元の1.8倍以上）のときは、元の値段で市場へ売り出す（市場の金庫 → 町の蓄え）。倉番の給金は給料日に町の蓄えから。
- 5日動かしたとき、王都では小麦が品薄になり、蓄え55袋ぶんが市場に出された。

### 孤児院 ★（王都。国の子を引き取る）
- **役目**：親を亡くした子を育てる。
- **史実**：フィレンツェの捨て子養育院（オスペダーレ・デッリ・インノチェンティ）は、絹の組合が1294年から捨て子の世話を受け持ち、1419年に最初の孤児院として建てられた。赤子の乳母から、大きくなってからの働き口の世話まで面倒を見た。
- **働く人**：孤児院の院母（新しい仕事。乳母・修道女・産婆のほか、隠居した年寄りにも頼める）
- **使う人**：両親を亡くした14歳未満の子。
  - まず同じ町の身内（祖父母・おじおば・兄姉など）が引き取る。
  - 身内がいなければ、国の王都の孤児院へ。
  - 16歳になったら、孤児院の蓄えから支度金をもらって独り立ちする（はじめは宿住まい）。
- **お金**：
  - 子どもだけの家に残った家計と家財は、孤児院が預かる。
  - 給料日と、新しい子を引き取った日に、教会の施し箱（足りなければ町の蓄え）から1週間分を孤児院へ。
  - 孤児院はそのお金でパンを市場から買い、院母に給料日に給金を払う。

### 墓地 ★（人口8人以上のすべての町）
- **役目**：死者を葬り、墓参りをする。
- **史実**：墓地は教会のそばにあり、何世紀も使われた。新しく墓を掘るときに出た古い骨は、納骨堂に移した。納骨堂の上には、死者のために祈る小さな礼拝堂が置かれることが多かった。
- **働く人**：墓守（今の仕事。仕事場を教会からここへ移す）
- **使う人**：墓参り（これまでは教会へ行っていた）、弔い（これまでは教会で行っていた。今は墓地に集まる）。
- **見た目**：低い石垣に囲まれた芝地に墓石と十字が並ぶ。中の墓石の数は、その町で亡くなった人の数に合わせて増える。

### そのほか今回足した暮らしの仕組み
- **巡礼**：信心深い人（信心0.72以上）が、休みの日に国の王都の大聖堂へ詣でる。2日ほど王都の宿に泊まってから帰る。40日に1度まで。
- **服のすり切れ**：毎日少しずつすり切れる（力仕事は早い）。ひどくすり切れると見栄の欲求が下がる。
- **汚れ**：毎日たまり、湯屋で落ちる。
