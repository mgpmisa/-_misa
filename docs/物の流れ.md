# 物の流れ ― 5599種類の物を、採る・作る・使う・売り買いする

経済部が作った、世界の物の仕組み（js/matter.js）の読み物です。物の一覧は素材管理部の js/catalog/、書き方の決まりは docs/素材の決まり.md にあります。

## 1. 今ある品とのつなぎ方
- パン・麦・魚・肉などの20品（GOODS）と、剣・鎧などの44品（ITEMS）は、今までの仕組みのまま作られる（農夫の麦、鍛冶屋の武具）。
- それ以外の物は、市場の在庫と値段に「その町にある物だけ」並ぶ。売り買いは今の市場（商人の買い取り・露店・預かり）と同じ決まり。
- 身につける物（武器・防具・盾・装身具・頭・手・足・道具）は、装備の仕組み（ITEMS）に登録するので、耐久と強さがそのまま使える。袋や籠は、持ち物の重さと枠の仕組み（carry.js）が受け持つ。重さ w と重ねられる数 stack は、一覧の値をそのまま使う。

## 2. 採る
| 手に入れ方 | だれが・いつ |
|---|---|
| 木を切る・掘る・採掘・摘む・野で探す・畑で収穫・釣り | 木こり・炭焼き・開拓者・道普請・鉱夫・石工・薬草摘み・漁師・船乗り・真珠採り・農夫・養蜂家・庭師などが、仕事の1時間ごとに、仕事場の地形（森・川・岩場・海・畑…）に合う物を1つ |
| 狩る | 狩人・冒険者・兵が獣や魔物を倒したとき、その種族の部位（肉・皮・骨・牙など）。年をとった家畜をつぶしたときも |
| 家畜から | 家畜を飼う家に毎日（乳・卵・毛・羽・糞など） |
| 宝箱・遺跡 | 冒険者がダンジョン・遺跡・魔王城・ピラミッドの探索に勝ったとき |
| 遠い国の商人 | 港と王都の商人が4日に1度、外から仕入れる（代金は世界の外へ出る。帳簿に「遠い国から品を仕入れた」） |

- 手に入れた物は、作り手の家の蔵へ入る。売るのは市場へ行ったとき（お金はそのとき入る）。
- 有限度
  - 鉱脈（vein）・林（grove）：町のまわりごとに残りの量があり、採れば減る。鉱脈はゆっくり、林は早めに戻る。
  - 遺物（relic）：世界に1〜12個しかない。
  - 群れ（herd）：今いる生き物を倒したときだけ。
  - 尽きない（none）：土や砂など。

## 3. 作る
- 一覧の make（材料・職業・時間）で、職人が作る。
- 材料は、自分の蔵か、市場の持ち主から買う。
- ひとりが覚える作り方は、その町でよく売れて材料がそろう物を6つまで選ぶ。週に1度、選び直す。
- 料理と暮らしの品（household・cook）は、手の空いた大人が家で作る。
- 新しい職業名は、今いる近い職業にまとめた。
  - 鎧師・剣鍛冶 → 鍛冶屋
  - 樽職人・車大工・弓師・楽器職人・おもちゃ職人 → 大工
  - なめし職人・革細工・鞍師・毛皮職人 → 靴屋
  - かご編み・縄ない・フェルト職人 → 機織り
  - 染め師・帽子屋 → 仕立て屋
  - 硝子職人 → 陶工
  - 紙すき・製本・地図師 → 書記
  - 蝋燭職人 → 司祭・修道女
  - 魔導具職人・杖職人・魔女・香職人 → 錬金術師
  - 菓子職人 → パン職人
  - チーズ職人 → 牧場主
  - 酒の蒸留・葡萄酒造り → 酒造り

## 4. 使う（まず種類を決め、その町にある品の中から選ぶ）
| 種類 | 使い方 |
|---|---|
| 食べる | 市場の買い物で、いちばん安い1食を選ぶ。蔵の食べ物で自炊する（1食＝food 30） |
| 飲む | 楽しみが増え、少し腹もふくれる |
| 薬 | 病が軽くなり、けががなおる |
| 装備・道具 | 身につける（兵は強い物に買い替える。職人は自分の仕事の道具を買う） |
| 建材 | 家を直す（家の暮らしやすさが上がる） |
| 燃やす | 冬は毎日、ほかの季節もときどき、蔵の燃料か市場で買った燃料を燃やす |
| ぜいたく品・趣味・収集 | 持っていると毎日、楽しみと見栄が少し満たされる。めずらしい物は名声が上がる |
| 贈り物 | 連れ合いや想い人に贈ると好かれる |
| 祈り・供え物 | 信心深い人が供えて祈る |
| 家畜の餌 | 家畜を飼う家が使う（使った日は干し草代を払わない） |
| 肥やし | 農家が週に1度撒く（その週は麦の実りが2割増える） |
| 魔法 | 学者・魔法使いが研究に使う（国の研究が進む） |

- 7つの欲求（楽しみ・見栄・恋・怠惰・生存）と、懐のゆとりから、何を買いに行くかを考える。

## 5. 値段（毎日、町にある物だけ計算する）
- 値段 ＝ 目安の値打ち v × 物価の水準 ×（在庫と需要）×（めずらしいほど値上がりの幅が広い）× 季節（採れる物は冬に高く秋に安い）× 有限な物の残り（減るほど高い）
- 町の人口が多いほど、欲しがられる量も多い。
- 傷む物（keep）は、市場でも蔵でも傷む。

## 6. 地方の差
- 物は採れる土地の近くの町に出回る。
- 王都や港の商人は、近くの村や港で余っている物を買い付けて運ぶ。遠い品は、この買い付けと隊商と遠い国の商人の船でしか届かない。
- 一生手に入らない物もある。

## 7. 図鑑
- 画面の「図鑑」の欄で「物」を押すと、物の一覧が出る。
- 種類・手に入れ方・産地・使い道・名前・手に入れたかどうかで探せる。
- この世界でまだ誰も手に入れていない物は「？？？」で、手に入れた物には★が付く。
- 物を押すと、手に入れ方・材料・使い道・重さ・有限度・目安の値打ち・今の値段（どの町に並んでいるか）・はじめて手に入った日が出る。

## 8. お金
- お金は、市場の売り買い（買い手 → 品の持ち主）と、遠い国からの仕入れ（商人 → 世界の外。帳簿に記録）でしか動かない。
- 採る・作る・使う、そのものではお金は1枚も動かない。
