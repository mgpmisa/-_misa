# デスクトップ版（Windows）の作り方

ゲーム本体（index.html・css・js・vendor）を Electron に詰めて、Windows 用のインストーラー（.exe）にする。

## 作り方（Linux でも作れる）
```bash
cd desktop
npm install                      # electron と electron-builder
node prepare.cjs                 # 本体を desktop/app/ に写す（字体 DotGothic16 を同梱し、ネットなしでも同じ見た目）
npx electron-builder --win dir --x64   # dist/win-unpacked を作る（アイコンと版の情報を exe に書くのに wine64 が要る）
makensis -INPUTCHARSET UTF8 installer.nsi   # dist/Eldeland-Setup-1.0.0.exe（NSIS。Linux の makensis でよい）
```
- electron-builder の nsis ターゲットは Linux だと 32ビットの wine が要るので使わない。インストーラーは installer.nsi を makensis で作る。
- 準備：`apt-get install wine64 nsis`（exe のアイコンを書かないなら wine64 は不要。package.json の signAndEditExecutable を false にする）。
- 版を上げるときは package.json の version と installer.nsi の VERSION を両方変える。

## 仕組み
- desktop/main.cjs：app:// という専用の住所でゲームを読み込む（file:// では ES Modules とセーブの IndexedDB が動かないため）。F11 で全画面、F12 で開発者ツール。
- インストール先は利用者ごとの場所（%LOCALAPPDATA%\Programs\EldelandChronicle）。管理者の許可は要らない。
- セーブは %APPDATA% の中に残り、アンインストールしても消えない。

## 確かめ方
- `xvfb-run` と Playwright の `_electron` で起動し、`window.__world` ができること、ページのエラーがないこと、保存して開き直すと読めることを確かめる（scratchpad/eltest.mjs・elsave.mjs）。

## BOOTH に出すもの
- Eldeland-1.0.0.zip：Eldeland-Setup-1.0.0.exe と「はじめにお読みください.txt」（Windows で読めるよう改行は CRLF）。
- 署名のない exe は Windows の SmartScreen が警告を出す。説明書に「詳細情報→実行」を書いておく。
