# エルデラント 世界の仕組み事典

調査部 作成（2026年9月26日調べ）。対象はコミット `689ca86` の時点の本体。
コードを読み、種 12345 の世界を生成して、4日分をヘッドレスで動かして確かめた。
ほかに 10 通りの種で、地図の作られ方だけを比べた。

> 読み方：各節の終わりの「担当」に、その仕組みを受け持つファイルと関数を書いた。
> 「⚠」は、足りないところやおかしなところ。まとめは最後の「足りないもの・おかしなもの一覧」にある。

## 1. 時間と暦
- 1歩は `sim.step(0.5)` で、0.5分にあたる。1日は1440分、つまり2880歩。
- 1季は10日、1年は40日（春・夏・秋・冬）。
- 7日に1度、休みの日がある（`isRestDay`：日の番号を7で割って6余る日）。
- 秋の最後の日は収穫祭（`isFestival`）。
- 区切りごとの処理
  - 1時間ごと：`newHour`。気分、結婚式、危険地図、犯罪、政治、魔王、天気、家事を動かす。
  - 1日ごと：`newDay`。町の蓄え、誕生日、寿命、妊娠、移住、ギルド、財産、生き物、裁き、政治を動かす。
  - 年の初め：`newYear`。その年の実りの良し悪し（`S.harvest`）を決める。
- 担当：`sim.js` の step、newHour、newDay、newYear。

## 2. 大陸と地形
- 大きさは 160×160 マス。
  - 標高・気温・湿度の3つのノイズから地形を決める。
  - 南へ行くほど暑い。南は砂漠・サバンナ・ジャングル、北は雪原になる。
- 地形は25種類：深い海、海、砂浜、草原、森、森林、ジャングル、砂漠、雪原、岩山、高峰、川、道、畑、石畳、建物、魔界の荒野、橋、柵、サバンナ、桟橋、溶岩、牧草地、城壁、沼地。
- 川：山から海へ、低いほうへ流れる。最大8本。
- 魔界：北東に半径20マス。荒野と溶岩で、中心に魔王城がある。
- 歩きやすさ（`MOVE_COST`）
  - 道・橋・石畳・桟橋がいちばん歩きやすく、1。
  - 森は2.4、岩山は4。
  - 海・川・高峰・建物・柵・溶岩・城壁は通れない。
- 担当：`world.js` の generateWorld、`path.js` の findPath（A*。危険地図を避けることもできる）。

## 3. 国と町
- 国は3つ。
  - アルデリア王国：「剣と麦の国」。北西にある。
  - ヴェルムント王国：「鉄と雪の国」。東にある。
  - サハル王国：「砂と黄金の国」。南にあり、名前は南方風になる。
- 町は国ごとに4つずつ（`data.js` の KINGDOMS）。
  - 王都：半径15。城壁で囲まれる。
  - 村：2つ。半径9で、城壁はない。
  - 港町：半径10。
- 領土：最も近い町の国になる。王都は0.8倍の距離で数える。55マスより遠い所は、どこの国でもない。
- 町の区画
  - 6マスおきの碁盤の目の通りと、中央の石畳の広場がある。
  - 王都は北側に城の専用区画をとる。
- 特別な場所
  - 魔王城
  - 洞窟3つ（古の洞窟、竜の巣穴、嘆きの迷宮）
  - 砂のピラミッド
  - 星見の展望台
  - 盗賊のアジト2つ
  - 各村の鉱山
  - 遺跡2つ（古代都市の遺跡、忘れられた神殿）
- 担当：`world.js` の generateWorld、layoutTown。

## 4. 建物の種類と役割
| 種類 | どこにあるか | 使う人・使いみち |
|---|---|---|
| castle 城 | 王都 | 王家の住まい。宮廷の職の仕事場。王族の屋敷 |
| mansion 貴族の屋敷 | 王都に2軒 | 貴族の住まいと仕事場 |
| church 大聖堂・礼拝堂 | 全部の町 | 祈り・婚礼・弔い。司祭と村長の仕事場。学校や診療所がない町では代わりになる |
| market 市場・魚市場 | 王都と港 | 買い物（在庫と物価は町ごとの抽象的な数字）。商人・両替商・肉屋の仕事場 |
| tavern 宿屋・酒場 | 全部の町 | 飲む、食べる、泊まる（宿住まい）。楽師・踊り子・吟遊詩人の仕事場 |
| guild 冒険者ギルド | 王都 | 依頼の受付と報告。冒険者の鍛錬の場 |
| barracks 兵舎 | 王都だけ | 兵士・騎士・将軍の仕事場と鍛錬の場。泊まる所ではない（⚠ 夜は皆、自分の家に帰る） |
| prison 牢獄 | 王都 | 囚人と看守 |
| magictower 魔法の塔・学術院 | 王都 | 魔法使い・宮廷魔術師・錬金術師・賢者 |
| bakery パン屋 | 王都と港 | パン職人 |
| smithy 鍛冶場 | 王都と村 | 鍛冶屋。武具と道具を並べる店（`S.towns[].shop`） |
| workshop 職人の工房・造船所 | 王都と港 | 大工・仕立て屋・靴屋・陶工など |
| clinic 診療所 | 王都 | 医者・薬師・産婆 |
| school 学校 | 王都 | 6〜13歳が午前に通う。教師の仕事場（⚠ 次の2点を参照） |
| stable 厩舎 | 王都 | 馬丁。馬3頭 |
| well 井戸 | 村 | 水くみ・洗濯（chores.js） |
| mill 風車小屋 | 村 | 粉屋 |
| watchtower 見張り櫓 | 村と港 | ⚠ だれの仕事場でもない。飾り |
| lighthouse 灯台 | 港 | 灯台守 |
| house 家 | 全部の町 | 世帯の数に合わせて、あとから建てる（makeHousePlacer） |
| cave・pyramid・ruins | 野外 | ダンジョン。魔物が住み、探索すると宝が出る |
| hideout 盗賊のアジト | 森 | 盗賊団の住まい |
| mine 鉱山 | 村の近くの岩山 | 鉱夫・石工 |
| observatory 展望台 | 王都の近くの高台 | 学者の仕事場（⚠ 町の外なので怖がって逃げる） |
| demoncastle 魔王城 | 魔界 | 魔王の住まい |

学校についての注意
- 学校（school）は王都にしか作られない。
- しかも建てる場所が見つからずに、欠けることが多い。10通りの種のうち8つで、どこかの王都の学校が欠けた。
- 学校がない町の子どもは、教会へ「登校」する。
- 担当：`world.js` の layoutTown と placeOnStreet（置き場所の決定は tryPlace）、`sim.js` の placeFor（行き先の決定と、代わりの建物）。

## 5. 道と門
道の作り方
- 街道は、町と町を A* で結んで作る（`world.js` の roadPath）。
  - 各国の王都と、その国の村・港を結ぶ。
  - 王都どうしは3本で結ぶ。
- 町の中の道は、碁盤の目の通りと、建物の扉の前の小道。
- 川を渡る所は橋になる。

門
- 門（`s.gates`）は、町の外周と道が交わる所。
- 王都は城壁の東西南北の真ん中に、必ず門を開ける。

特別な場所と道
- ⚠ 特別な場所へ行く道は作られない。
- 種 12345 で、いちばん近い道までの距離を測った。
  - 魔王城は35マス、ピラミッドは26マス、洞窟は3つとも14マス、忘れられた神殿は16マス。
  - ティーフタール鉱山は16マス。

調べた結果（種 12345）
- 道は、つながった大きなかたまり1つと、小さなかたまり4つに分かれていた。
- ⚠ 港町ゼーハーフェン：北から来る街道が、王都アルデンの北門から城の真裏に入り、行き止まりになる。王都の中の通りとつながっていない。
  - 原因：城の専用区画は、街道を引いたあとに芝生で上書きされ、そこに城が建つ。
  - 城の北側の3本の道は、城壁と城のあいだで途切れている。
- ⚠ 港町ノルトブルク：門が1つもない。教会・工房・パン屋も建たなかった（町の中に建てる場所がない）。
- ⚠ 忘れられた神殿：陸続きではなく、歩いては行けない。それなのに、ギルドの依頼に出る。

ほかの10通りの種で比べた結果（`scratchpad/research/seeds.mjs`）
- 道で本線から切れた町があった種は5つ。
  - 例：種99999では、サハル王国の4つの町がまとめて本線から切れていた。
- 門が1つもない町があった種は2つ。
- 担当：`world.js` の roadPath、layoutTown、openGates（古いセーブで門を開ける処理）。

## 6. 人の一生
1. 歴史
   - 280年分の歴史から、現在の住人を作る（`history.js` の generateHistory）。
   - 建国の開拓者の夫婦から、家系が続いていく。
   - 出来事（凶作・疫病・戦争・魔王・勇者）は、年代記と本人の記憶（notes）に残る。
2. 誕生
   - 妊娠の条件
     - 18〜42歳の、夫と同じ世帯に住む妻。
     - 1日ごとに `0.035 × 夫婦の愛情 × 人口の補正` の確率で妊娠する。人口の補正は `1.9 - 人口/330` で、0.1〜1.6の範囲に収める。
   - 10日後に生まれる（`birth`）。
   - 亡くなった祖父母の名前をもらうことがある。
3. 子ども
   - 6歳まで：家の食べ物を食べさせてもらう。
   - 6〜13歳：休みの日以外の午前（8〜12時）に学校へ行く。遊ぶ。
   - 7〜13歳：午後は親の仕事について行く（chores.js の help）。
4. 仕事
   - 14歳の誕生日に見習いになる（`newDay`）。
   - ⚠ 親が品物を作る職なら、その職を継ぐ。そうでなければ、港では漁師、ほかでは農夫になる。自分で職を選ぶ仕組みはない。
   - 16〜24歳で、勇気と野心の強い独身者は、冒険者を志して王都へ出ることがある（guild.js の partiesDaily）。
5. 結婚
   - 会話で「恋心」が生まれ、互いの好感が72と68を超えると婚約する（`maybeEngage`）。
   - 3日後、教会で婚礼を挙げる。
   - 身分が3段以上違うと、家族に反対される。反対されると、駆け落ち（`elope`）することもある。
6. 老い：68歳の誕生日に引退する（王族と貴族は引退しない）。
7. 死
   - 寿命と病：年齢ごとの年間死亡率を40日に割って、毎日くじを引く。飢えていると4倍、薬草学を知っている国は0.7倍。
   - そのほか、戦い・魔物・殺人・処刑で亡くなる。
   - 亡くなると、弔い・相続・周りの人の記憶・年代記への記録が起きる（`die`）。
8. 移住：町の人口が最初の85%を下回ると、よその土地から夫婦が移り住む（`immigration`）。
- 担当：`sim.js` の newDay、birth、marry、die、immigration。`history.js`。

## 7. 7つの欲求と行動の決め方
- 欲求は7つ：生存・睡眠・食欲・性欲・怠惰・楽しみ・承認。それぞれ0〜100。
  - 毎歩、行動に応じて増えたり減ったりする（`step`）。
- 行動の決め方（`decide`）
  - 行動の候補ごとに点数を足す。`add(点数, 種類, 場所, 分数)` の形。
  - 点数には、次のものが加わる。
    - 欲求の足りなさ
    - 性格（O・C・E・A・N）
    - 価値観（信心・野心・家族・勇気）
    - 時刻・天気・休みの日
    - 学習した好み（p.q）
    - 0〜1.2の揺らぎ
  - 最高点の行動をとる。
- 最優先の行動
  1. 牢の中
  2. 任務（行軍・防衛・討伐・逃走）
  3. 集まり（祭り・婚礼・弔い）
  4. 生存欲が35を切ったら逃げる
- 主な行動
  - 眠る、食べる、買う、働く、酒場、広場、散歩、祈る、訪ねる、口説く、学校、遊ぶ、昔語り、鍛錬、休む
  - 依頼、交易、旅、装備を買う、悪事
  - 家事（水くみ・洗濯・料理・子守・保存食・昼寝）
- 気分（mood）：1時間ごとに、次のものから決まる（`newHour`）。
  - 欲求の平均、家計、最近の記憶、家の快適さ、天気
- 担当：`sim.js` の decide、startAction、arrive、doAction、finishAction。`chores.js` の choreOptions。`weather.js` の weatherBias。

## 8. 学習・記憶・会話・噂
- 学習（行動の好み）
  - 行動が終わったら、欲求と気分がどれだけ良くなったかを「ご褒美」とする。
  - そのご褒美で `p.q[行動]` を少しずつ直す（`finishAction`）。
  - 次に決めるとき、`q × 1.5` が点数に加わる。強化学習のような仕組み。
- 危険の学習
  - 襲われたり魔物を見たりした場所（8×8の区画）を `p.danger` に覚える。
  - この記憶は1時間ごとに少しずつ薄れる。
  - 会話で、ほかの人にも伝わる。
- 記憶
  - `{t, txt, emo, imp, k, about}` の形で、最大45件持つ。
  - あふれたら、大事さと新しさで選んで残す（`trimMemories`）。
  - 歴史の出来事や、先祖の武勇伝も記憶として持つ。
- 会話
  - 同じ2マスの区画か、同じ建物にいる2人が、確率で話し始める（`checkEncounters`）。
  - 話題は40以上あり、性格・身分・関係・記憶から選ぶ（`speech.js` の pickTopic）。
  - 口調は身分と性別で変わる（`speechStyle`）。
  - 話すと、好感・承認・楽しみが上がる。口論や恋心が生まれることもある。
  - 口ぐせやことわざが伝わり、町の文化（`S.culture`）として広まる。
- 噂
  - 出来事は `gossip` で目撃者の記憶になる。
  - 会話で人から人へ伝わるたびに、尾ひれがつく（`rumor.js`）。主語を取り違えることもある。
  - 本人や目撃者と話すと、本当の話に戻る。
- 心の声：`innerThought` が、その時の欲求・記憶・情勢からつぶやきを作る。
- 担当：`sim.js`（remember、gossip、startTalk、endTalk）、`speech.js`、`rumor.js`、`kin.js`（続柄）。

## 9. 職業の一覧と実際の働き
職業は `data.js` の JOBS に93種ある。

仕事の時間と場所
- 7〜17時で、1日に9時間まで働く。
- 休みの日は、宿屋・兵・王・召使いだけが働く。
- 働く場所は `placeFor(JOBS[job].place)` で決まる。
- 危ない場所しかない、戦えない職の人は、広場で働く。

仕事の中身は3つの型に分かれる。
- 専用の処理（`doWork` の switch）
- 追加の職業の共通処理（`genericWork`）。ここでは次の組み合わせで動く。
  - goods：品物を作って市場に売る
  - svc：町の人への奉仕
  - pay：国庫から給金をもらう
  - research：国の研究を進める
  - combat：経験値がもらえる

### 9-1. 専用の処理がある職業
| 職業 | 実際にしていること |
|---|---|
| 農夫 | 小麦を作る（季節で秋2.4倍、冬0.08倍）。家の食べ物が足りなければ家に入れ、余れば売る。小作なら3割を地主に納める。⚠ 畑のマスがない世界では、広場や道で「耕して」いる（下の⚠1） |
| 牧場主 | 肉を売る（抽象的な数字。家畜は減らない） |
| 狩人 | 近くの弱い野生動物と戦って、肉を売る。⚠ 海のイルカなども狙い、海の上へ歩いていく様子がある |
| 漁師・船乗り | 魚を売る（冬は半分。航海術で1.3倍） |
| 木こり | 材木を売る |
| 鉱夫 | 鉄鉱石を売る。まれに宝石を掘り当てる |
| パン職人 | 小麦からパンを作る（夜明け前から働く） |
| 鍛冶屋 | 鉱石から鉄を作り、武具や道具を打って店に並べる（`forge`）。⚠ 店が14品でいっぱいになると売れ残り、鉱石代だけ出ていって赤字になる（4日で1人1日−14） |
| 大工 | 材木から家具を作る。1時間1.5銅貨の日当もある |
| 仕立て屋 | 布を売る |
| 宿屋の主人 | 小麦から麦酒を作る（在庫が減っていく。4日で216→32） |
| 商人 | 手数料を集め、市場の品切れを補う（品物がどこからともなく湧く）。よその町へ交易に出る（`doTrade`。一瞬で売り買いする） |
| 司祭・村長・看守・召使い・衛兵・兵士・騎士 | 国庫から給金をもらうだけ。兵士と騎士は少し経験値も得る |
| 学者・魔法使い | 国の研究を進める。1時間2.5銅貨 |
| 王・王族・貴族 | 貴族は1時間4銅貨（⚠ お金がどこからともなく湧く）。王と王族は何もしない（政治は politics.js が別に行う） |

### 9-2. 共通処理の職業（genericWork）

- 肉屋：肉。
- 酒造り：麦酒。
- 靴屋：靴。
- 陶工：陶器。
- 機織り：布。羊毛を使う。
- 宝石職人：装身具。宝石を使う。
- 羊飼い：羊毛。
- 養蜂家：はちみつ。
- 炭焼き：材木。
- 石工：石材。
- 薬草摘み：薬草。
- 真珠採り：宝石。

## 10. 経済（お金・物価・税・蓄え・国庫）
### お金の置き場所
| 置き場所 | 中身 | 担当 |
|---|---|---|
| 家計 `hh.money` | 家族の共有のお金。生成時は平均167 | `sim.js` の formHouseholds |
| 財布 `p.purse` | 一人ひとりのお金。平均18 | `property.js` |
| 町の蓄え `S.towns[].fund` | 最初は200 | `sim.js` の newDay |
| 国庫 `k.treasury` | 最初は600〜1200 | `politics.js` |

### 物価と市場
- 市場は町ごとに、20品目の在庫（stock）と値段（price）を持つ。
- 値段は1時間ごとに、目標の在庫との比で動く（基準値の0.45〜3.5倍。`updatePrices`）。
- 売ると値段の85%が家計に入り、在庫が増える（`sell`）。買うと在庫が減り、6%が手数料になる（`buy`）。

### お金の流れ（誰から誰へ）
- **働く人 ← 市場**：品物を売ったお金。在庫は増えるが、買い手の財布は減らない。⚠ 売るたびにお金がどこからともなく湧く。
- **市場 ← 家計**：食べ物・薬・家具を買う。
- **商人 ← 手数料**：ここは循環している。
- **国庫 → 給金**：兵士・宮廷の職など。国庫が足りなければ、給金の3割がどこからともなく湧く。
- **国庫 ← 税**：1日ごとに、家計の `min(家計,300) × 税率(5%) × 0.2`。さらに基本収入の `30 + 町の数×10` が加わる（⚠ この基本収入もどこからともなく湧く）。
  - 国庫が150を切ったら、王が税を上げる。1600を超えたら下げる。
- **町の蓄え ← 裕福な家**：7日ごとに、家計250を超えた分の5%。
- **町の蓄え → 貧しい家**：家計12未満の家に、最大20を施す。
- **町の蓄え → 普請**：400を超えたら、貧しい人に「道の補修・井戸さらい」の名目で給金を配る。⚠ 実際に道や井戸が直るわけではない。
- **豊かな町 → 同じ国の貧しい村**：120の援助。
- **冒険者 ← 依頼人**：依頼人は報酬の半分だけ払う。王が依頼人なら払わない。⚠ 残りはどこからともなく湧く。
- **冒険者 ← 魔物**：倒すと報酬（loot×Lv）がもらえる。⚠ どこからともなく湧く。
- **国庫 → 勇者**：討伐隊の支度金。
- **国庫 → 災害の復興費**：`weather.js` の relief。

4日動かした結果
- お金の総量は 33141 → 34221 で、3%増えた。
- 湧いてくるお金が多い職：貴族（1人1日25銅貨）、財務大臣、詐欺師（1人1日48銅貨）。
- 担当：`sim.js` の updatePrices、sell、buy、doWork、newDay。`politics.js` の politicsDaily。`property.js`。

## 11. 治安・犯罪・裁き
### 犯罪（`society.js` の tryCrime、crimeArrive）
- 盗み：夜中に、盗賊か、飢えた人か、ずるく野心的な人が、家・屋敷・市場に忍び込む。
  - 見つかると手配される。番犬が吠えると、目撃者が増える。
- 追いはぎ：盗賊団が昼間、アジトから14マス以内の街道で、町の外の人を襲う。
- 復讐：深く恨む相手を襲う。
- スリと詐欺：genericWork の中で起きる。
- 喧嘩：法を守る職でない人どうしの喧嘩は、殺し合いにならない。
- 殺人：目撃者がいれば手配される。いなければ、未解決事件（`S.unsolved`）になる。

### 手配と逮捕
- 手配された人は `S.wanted` に載る。罪の日数と懸賞金を持つ。身分は「お尋ね者」になる。
- 法を守る職の人（衛兵・騎士・兵士・看守・夜警・近衛・将軍・聖騎士）が、10マス以内にいるお尋ね者を捕まえる（`crimeHourly`）。
  - 相手が弱いか臆病なら、そのまま逮捕する。そうでなければ戦う。
- 賞金首の依頼が出ると、冒険者も捕まえる。

### 裁き（`justiceDaily`）
- ⚠ 裁判はない。手配の日数が、そのまま刑期になる。
- 牢獄は王都にしかない。
- 刑期中の出来事
  - 看守がいないと、勇敢な囚人が3%の確率で脱獄する。
  - 刑期が明けると身分が戻る。盗賊は3割5分の確率で農夫に転職する。
- 盗賊のアジトは、追いはぎが2回起きると懸賞金がかかり、ギルドの依頼になる。
- 4日動かした結果
  - 盗みの記録は27件、逮捕は6件、殺人は1件。
  - 4日目の終わりに牢にいた人は15人（大工・書記・鍛冶屋にも囚人がいる）。

## 12. 戦争・魔王・勇者
### 戦争（`politics.js`）
- 国どうしの関係の値は、自然に0へ戻っていく。
- 関係が悪くなる理由
  - 鉱石の不足や食糧の高値。
  - 王が意地悪なこと。
- 宣戦布告の条件
  - 関係が−45未満で、王に野心がある。
  - 軍の大きさ（兵士・騎士・将軍のLvの合計）が、相手の0.8倍以上ある。
  - この条件で、15%の確率で宣戦する。
- 戦いの進み方
  - 兵士・騎士・将軍が前線（両国の王都の中間地点）へ行軍する。
  - 敵の兵が6マス以内にいれば戦う。
- 終わり方
  - 12日たつか、どちらかの兵が3未満になると終わる。
  - 勝った国は、負けた国の国庫の4割（最大400）と、いちばん近い村を得る。

### 魔王（`politics.js`）
- はじめは眠っている。4〜8日目に目覚める（種 12345 では6日目）。
  - 目覚める2日前に、空が赤くなる前ぶれがある。
- 目覚めたあとは、6〜10日おきに魔王軍（インプ・魔族兵・魔将）が近い町へ攻めてくる。
- 守る人がいなくなると、町は占領される。住民は王都へ逃げて難民になる。
- 占領していた魔物を倒すと、町は解放される。

### 勇者
- 脅威が高まると、王が魔王討伐令を出す（`callHeroes`）。
  - 戦える職の人から4人を選び、支度金・回復薬を持たせる。
  - 国が「聖剣の鍛造」を研究済みなら、聖剣も持たせる。
- 30日以内に魔王城で決戦になる。
- 勝った場合
  - 勇者は騎士になる。祝祭が開かれる。
  - 次の魔王が、負けた理由（聖剣）への耐性を得て、より強くなって復活する（進化）。

### 研究
- 学者・魔法使いなどの研究点がたまると、10の技術のうちの1つを発見する。
  - 輪作、鋼、薬草学、望遠鏡、航海術、治癒魔法、結界、活版印刷、聖剣、灌漑。
- 仲の良い国へは技術が伝わる。
- ⚠ 望遠鏡と灌漑は、効き目のコードが見当たらない（名前だけ）。

## 15. 財産・住まい・相続（`property.js`）
- 家の持ち主と借家
  - 村は85%が持ち家。港は60%、王都は50%。
  - 大家は、貴族・商人・両替商・宿屋、または裕福な家。
- 家賃：週に「家の値打ち÷28」。3週滞納すると追い出される。情け深い大家は、1度だけ待ってくれる。
- 家のない家族
  - お金を貯めて、空き家を借りるか買う。空き家がなければ、宿住まいになる。
  - 宿代は1人1日3銅貨。払えないと追い出される。
- 畑（`hh.land`）：抽象的な区画数で表す。
  - 村長と貴族は地主。
  - 小作は、収穫の3割を地主に納める。
  - 小作は260銅貨貯まると、畑を買って自作農になる。
- 家畜：牧場主・羊飼い・農家の持ち物（`c.keeper`）。厩舎の馬は国の持ち物。
- 相続
  - 財布と持ち物を受け継ぐ順番：配偶者 → 年長の子 → きょうだい → 同じ家の人。
  - 世帯がなくなるときは、家・畑・家畜・家計を相続人の世帯へ移す。
  - 相続人がいなければ、町の蓄えに入る。

## 16. 天気・災害・年中行事・家事
### 天気（`weather.js`）
- 大陸を4×4の地域に分け、気候（平野・海沿い・砂漠・雪原・ジャングル・山地・魔界）と季節で、毎日の天気と気温を決める。
- 天気の移り変わり：前の日の天気が続きやすい。前線は西から東へ流れる。
- 天気の影響
  - 外仕事の効率が変わる（吹雪なら0.3倍）。
  - 行動の好みが変わる（雨の日は酒場へ）。
  - 気分も変わる。

## 17. 経験値と腕前（成長の仕組み）
### 仕事の腕前（`p.skill[職業]`）
- 生成時は、年齢で0.2〜0.95になる。
- 働くと、1時間に `0.0008 × (1−腕前) × (0.5+好奇心)` だけ伸びる。
  - 4日で平均+0.008。
  - 0.9になると、「名人」と呼ばれる。
- 腕前が効く所：仕事の効率。鍛冶屋は、腕前で品質が決まる。

### 学び（`p.skill.study`）
- 学校（1時間+0.002）と教師（+0.004）で伸びる。
- ⚠ ただし、学びはどこにも使われていない。
  - 職業の選び方にも、研究にも、会話にも効かない。
  - 4日で0.03ほどにしかならない。

### レベル（`p.lv`、`p.xp`、`levelCheck`）
- 次のレベルに必要な経験値は `20 × Lv²`。
  - 例：Lv6 → 7 には720。
- 経験値の入り方
  - 仕事：兵士・騎士は1時間0.3、戦える職（給金なし）は0.2、将軍は0.4。
  - 鍛錬：1時間1.2×(0.5+まじめさ)。
  - 魔物を倒す：`hp/3 + Lv×5`。
  - 人を倒す：15 + 相手のLv×5。
  - ダンジョン探索：危険度×3。
- ⚠ 4日でレベルが上がった人は0人。兵士は数か月（数百時間）鍛えないと1つも上がらない。
  - 生成時のLvは、職と年齢でほぼ決まる（1〜10）。成長がほとんど見えない。
- レベルが効く所：HP・攻撃・守り（`humanStats`）。依頼の危険の見積もり。危険への慣れ。

### そのほか
- 冒険者ランク（F〜S）：依頼の達成点で上がる。
- 名声（fame）：偉業や討伐で上がる。勇者の選び方に効く。
- 魔物の成長：Lvと進化は別の仕組み（`creatures.js`）。

  - 仕事の腕前（p.skill）は、働くと少しずつ伸び、効率と品質に効きます。
  - レベル（p.lv・p.xp）は、戦い・鍛錬・探索で経験値がたまります。ただ、必要な量が `20×Lv²` と大きく、4日でレベルが上がった人は0人でした。
  - 学校での学び（skill.study）は、伸びても使われていません。
