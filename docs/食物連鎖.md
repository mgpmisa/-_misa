# 食物連鎖と繁殖・満腹度・巣

エルデラントの生き物は、草や木の実から始まる食物連鎖の中で暮らします。
おなかがすくと表どおりに食べ物を探し、満ち足りた雌だけが子を産みます。獲物が減れば食べる側が飢えて減り、獲物が増えれば食べる側も増えます。
仕組みは `js/foodweb.js`（食物連鎖・満腹度・狩りの掟）、`js/breeding.js`（繁殖の表）、`js/nests.js`・`js/nestgfx.js`（巣）にあります。

- 例：ネズミは猫・フクロウ・ワシ・キツネ・ヘビに食べられる。カラスやガンはキツネ・ワシ・フクロウ・ワニに、人はガンや家禽を食べる。トラはクマや、ワイバーン・アラクネ・ドラゴンなど大きな魔物に食われる。
- 不死者（スケルトン・ミイラ・リッチ）、ゴーレム、魔族は食べず、食物連鎖の外にいる。ダンジョンの湧き口・呪い・召喚から現れる。
- 魚は1匹ずつの生き物ではなく、川と海の「魚の群れ」の量として持つ。クマ・ペンギン・ワニ・カモメ・人の漁師がそこからとる。
- 数の目安（広さあたりの密度）も、上の段ほど少なくした。大きな肉食の目安は、オオカミ0.45倍・トラ0.5倍・ホッキョクグマ0.5倍・ワシ0.5倍・クマ0.6倍・ワニ0.7倍・キツネ／フクロウ／ヘビ0.8倍（もとの世界は肉食が多すぎ、20日で大半が飢えていた）。
- 狩る側は、自分より大きすぎる相手（体の大きさが1.25倍を超える相手。群れで狩るオオカミは1.4倍）は、子どもしか狙わない。

## 繁殖（実在の動物を調べ、この世界の暦に直した数字）

- この世界の1年は40日。実在の日数 × 40 ÷ 365 がこの世界の日数になる（例：ウサギの妊娠30日 → 3.3日、シカの230日 → 25日）。
- 人の妊娠は、この世界では10日（1年の4分の1）。ウサギはその3分の1で産み、1年に4回産めるので、人よりずっと早く増える。クマやトラ、クジラは人よりゆっくり増える。
- 卵をたくさん産む種（ワニ・カメ・カエル・サソリ・鶏など）と、子の多くが育たない種（キツネ・オオカミ・ウサギ）は、「育って巣立つ数」を生まれる数にした。犬と猫は、残りの子がよその家へもらわれていく分を引いた。
- 安全弁：野の獣と家畜は、はじめの数の1.5倍（かつ目安の1.3倍）に届くと身ごもらない。家で飼う犬・猫は1軒に2匹まで。
- 世界を作ったときが生まれる季節なら、前の季節に身ごもった母の8割が、その季節のうちに産む（春の出産の波）。
- 身ごもるのは、大人になった満腹の雌（満腹度55以上。家畜は45以上）。草食は足もとの草の多さも見る。やせた母は少なく産み、飢えた母は子を失う。
- 一生つがいの種（オオカミ・キツネ・ワシ・フクロウ・カラス・ガン・ペンギン・カモメ・オウム）はつがいの相手と、ほかは近くの大人の雄と。オオカミは群れの長のつがいだけが産む。
- 生まれる季節が決まっていて、身ごもる時期は「生まれる日がその季節に入るとき」だけ（シカは秋に身ごもり、春に産む）。

## 満腹度（おなかの具合）

- すべての生き物が満腹度（0〜100）を持つ。1時間に、ふだんは1、肉食は1.6ずつ減る。体の小さい種ほど早く減る（体重あたりの代謝が大きいため。大きさ0.6を1として、0.8〜1.25倍）。育ちざかりの子は1.1倍。食べない魔物（不死者・ゴーレム・魔族）は減らない。
- 45を切ると食べ物を探す。
  - 草食：足もとの草・木の実・魚が豊かならその場で食べる（草を食む姿）。乏しければ、16〜32マス先のもっと豊かな所へ移り、そこを新しい行動圏にする（探すのは1頭につき20分に1回）。
  - 肉食：表にある獲物を追って狩る（追う姿 → 攻める姿）。仕留めたら、その場で獲物を食べる（食べる姿。獲物の大きさで20〜60分）。
  - 家畜：牧場では昼に牧草を食み、冬と夜は飼い主の餌を食べる。
  - ひどく飢えた獣は人里へ降り、畑や家畜を荒らす。畑は農家の損になる。近くの人（14歳以上）に見つかると追い払われて逃げる。
- 飢えが続くと体力が減って死ぬ（数の少ない種は、最後の力で食いつなぐ）。満腹だと身ごもりやすい。
- 生き物をクリックすると、「腹ぐあい（満腹度）」と「いま○○を探している／食べている／獲物を追っている／身ごもっている」が出る。

## 巣

- 種ごとに巣の形と置き場所がある。世界を作るときに住みかの地形に沿って置き、群れは群れで1つ、つがいは2頭で1つの巣に住む。子は母の巣で育ち、独り立ちすると新しい土地に自分の巣を作る。住む者がいなくなった巣は4日で崩れて消える。
- 巣穴（ウサギ・キツネ・ヘビ・サソリ・カエル・ワニ・ネズミ）、洞穴（クマ・ホッキョクグマ・トラ・コウモリ）、寝床（オオカミ・シカ・トナカイ・イノシシ・ラクダ・ユニコーン）、木の上の巣（フクロウ・カラス・オウム・リス・サル）、岩山の巣（ワシ・ワイバーン）、水辺の巣（ガン・カモメ・ペンギン・カメ）、野営地（ゴブリン・オーク）、蜘蛛の巣（大蜘蛛・アラクネ）。ダンジョンや遺跡に住む魔物は、その建物が住処。
- 眠る時間になると巣へ帰って眠る。夜行性（フクロウ・オオカミ・キツネ・コウモリ・トラ・サソリ・カエル・ネズミ、魔物では不死者・蜘蛛・ゴブリン）は昼に巣で眠り、夜に出てくる。だから夜の森はオオカミや不死者に出会いやすく、危ない。
- 巣は3Dで描く（形ごとにまとめて1回で描く）。地面の巣をクリックすると、何の巣か・何匹住んでいるか・いま何匹いるかが分かる。

## 人の狩りと漁の掟

- 狩人は、数が目安の7割を切った種を狩らない。子ども・子連れの母・身ごもった雌も狩らない。罠も同じ。
- 禁猟の季節：春はすべての獲物（ネズミなどの害獣は除く）。ゆっくり増える種（年に1回以下しか産まない種）は、その子育ての季節も。
- 漁師と船乗りは、近くの漁場の魚の群れからとる。群れが3割を切った漁場では、とる量を6割に控える。
- 狩った肉や魚は、これまでどおり市場で売り買いする（お金は取り引きでだけ動く）。

## 安全弁（ふだんは食物連鎖で釣り合う）

- 野の獣が目安の1.3倍に達したら、それ以上は身ごもらない。1.6倍を超えたら、弱い個体から病で減る（fauna.js）。
- 目安の35%を切った種は、人の住まない奥地から移り住んでくる（fauna.js）。魔物は、はじめの数の6割を切ると奥地から流れてくる（beasts.js）。数の少ない獲物は、飢えていない獣や魔物に狩られない。
