# 通行料の歴史 ― 道・橋・川を通るとき、昔の人は誰にいくら払ったか

エルデラント年代記で「街道を作った国が関所を置き、通行料を取る」しくみを作るために、中世ヨーロッパ・古代ローマ・シルクロード・日本の通行料と、ファンタジー作品での描かれ方を調べた読み物です。
数字のうち、はっきりした記録がないものは「推定」と書いてあります。出典は各章の終わりと、最後の一覧にまとめました。

---

## 1. 通行料とは何か ― 「そこを通る権利」を売る商売

中世では、**道・橋・川・峠・渡し舟・町の門・市場**など、人と荷が必ず通る「のどもと」を押さえた者が、通る人からお金を取りました。
畑を耕さなくても、地形のおかげでお金持ちになれる。峠や大きな川の渡しを持つ領主は、まさにそうでした。
この「通行料を取る権利」そのものが財産で、土地と同じように親から子へ受け継がれ、売り買いもされました。

| 種類 | どこで | 昔の呼び名の例 |
|---|---|---|
| 道の通行料 | 街道の決まった場所（柵や小屋） | 道銭・関銭 |
| 橋の通行料 | 橋のたもと | ポンテージ（橋の修理のための税） |
| 川の通行料 | 川の狭いところ。鎖で川をふさぐ | ライン川の関税 |
| 峠の通行料 | 山越えの道 | アルプスの峠の関税 |
| 渡し舟の料金 | 渡し場 | 渡し賃（領主が独り占めの権利を持つ） |
| 町の門の税 | 城門 | ミュレージ（城壁の修理のための税） |
| 石だたみの税 | 町の中へ入る荷 | ペイヴィッジ（道の舗装のための税） |
| 港の税 | 船着き場 | キーエッジ（波止場の修理のための税） |
| 市場への持ち込み税 | 市の立つ広場 | 市場税・場所代 |
| 海峡の通行料 | 海の狭いところ | エーレスンド海峡の通行税 |

## 2. 誰が取ったか

- **王・皇帝**：もともと通行料を取る権利は王（神聖ローマ皇帝）のものでした。王は、その権利を家来の領主・教会・町に「分けて与える」ことで味方を増やしました。
- **領主**：峠や渡し、川沿いの城を持つ領主。ライン川沿いに並ぶ城の多くは、実は「関所の城」でした。
- **教会**：大司教や修道院も、川の関所や渡し舟の権利を持っていました（イングランドのサンダーランドの渡しは、12世紀末に司教の持ち物でした）。
- **都市**：王から許しをもらい、城壁や橋や道を直すための税を、門を通る荷から取りました。

## 3. 料金の決め方 ― 具体的な数字

中世の料金は、大きく2つのやり方がありました。

### (1) 「1台いくら・1頭いくら」の決まった料金
荷の中身を調べなくてよいので、取り立てが簡単です。**乗り物が大きいほど高い**のが基本でした。

**イングランドの町シュルーズベリー（1220年）の城壁税の料金表**

| 通るもの | 料金 |
|---|---|
| 舟1艘ぶんの荷 | 4ペンス |
| 荷車1台 | 1ペンス（地元シュロップシャーからなら半ペンス） |
| 売り物を積んだ荷馬1頭ぶん | 4分の1ペンス |
| 馬・牛1頭 | 半ペンス |
| 羊・山羊・豚 10頭 | 1ペンス |

→ **荷馬1頭：荷車1台：舟1艘 ＝ 1：4：16**。地元の人は半額、という割引もありました。

- グロスターの城壁税（1345年）では、麦や麦芽の荷馬1頭ぶんが4分の1ペンス。同じころのダブリンの舗装税でも麦1荷が4分の1ペンスでした。
- 13世紀の橋の通行料では、**歩く人が半ペンス、荷車が1シリング（12ペンス）**という例もあります（通説・資料によって幅あり）。

**物価の目安（推定）**：13世紀イングランドの日雇い職人の日給は1〜2ペンスほど。つまり**荷馬1頭の通行料は日給の数分の1、荷車1台で日給の半分〜1日ぶん**という重さです。

### (2) 「荷の値打ちの何分の一」の割合の料金
高い荷ほど多く払うので公平ですが、荷を調べる手間がかかり、ごまかしも起きます。

- **古代ローマ**：国境や港で「40分の1（2.5％）」や「50分の1（2％）」の関税を取りました。ガリア（今のフランス）の関税は「ガリアの40分の1」と呼ばれました。**旅人の身の回りの品や、荷車・それを引く家畜には税がかからなかった**のが面白い点です。集めたお金は、ライン川を守る軍に回されました。
- **デンマークのエーレスンド海峡（1429〜1857年）**：バルト海へ出入りするすべての船から通行税を取りました。はじめは「船1隻いくら」でしたが、1567年に**積み荷の値打ちの1〜2％**に変えたところ、収入が3倍になりました。
  - 船長が荷の値打ちを安く申告しないよう、**「申告した値段で、王がその荷を買い取ってもよい」**という決まりを作りました。うそをつくと、安値で荷を取り上げられてしまうのです。
  - 16〜17世紀には、この通行税がデンマークの国の収入の**最大3分の2**を占めました。
  - 1857年、ほかの国々が合わせて3350万リグスダラーの「手切れ金」を払い、通行税はなくなりました。

### (3) 通るたびにかかる ― 合計の重さ
- 15世紀末の伊勢（日本）では、松阪から伊勢神宮の内宮まで50キロ足らずのあいだに関所が50あまりもあり、関銭だけで**100文以上**かかりました。1つ1つは小さくても、**数が増えると旅人には大きな負担**になります。

## 4. 集めたお金の使い道

- **道・橋・城壁の修理**：イングランドの橋の税・城壁の税・舗装の税は、名前のとおり「その修理のため」に、王が**期限つきで**（数年ごとに）許したものでした。
- **兵の給料**：ローマの関税はライン川の軍の費用に。シルクロードの隊商宿も、通行料で道を守る兵と宿の維持をまかないました。
- **領主・王の収入**：ライン川の関税は皇帝の大きな財源でした。デンマークの海峡税は国の財布そのものでした。
- **ただし、使い込みも多かった**：修理のためのはずの税が、領主や町の役人のふところに入ってしまう例も記録に残っています。

### 橋の建設と通行料 ― ロンドン橋の例
- ロンドン橋は1282年に「橋の家（ブリッジ・ハウス）」という管理の組織ができ、**通行料で橋を守る**しくみが作られました。
- 収入は、荷車や舟の通行料のほか、**橋の上に建てた家の家賃**、町の人の寄付でした。
- 寄付で集まった土地の家賃がどんどん増え、1381〜82年には収入の約75％、1537〜38年には約87％が家賃になりました。**通行料だけでは橋は保てず、ほかの収入と組み合わせた**のです。
- この組織は今もロンドンで慈善団体として続いています。

## 5. 免除された人たち

| 免除された人 | 理由 |
|---|---|
| 巡礼 | 信仰の旅を守るため。証明の書状を見せれば通れた |
| 聖職者と教会の荷 | 教会は世俗の税からは自由、という考え（11世紀の「神の平和」運動） |
| 王の使者・外交使節 | 書状を見せれば通れた |
| 町の市民 | 王が町に与える特許状（町の特権）に「通行料を免除する」と書かれることが多かった。王の町なら、王の持つほかの町でも免除 |
| 特別な働きをした人 | 手柄のごほうび、またはお金を払って「免除の権利」を買った |
| 条約を結んだ相手 | 1163年、ザクセン公ハインリヒはゴトランド島の商人に「通行料なし」を約束し、そのかわりドイツ商人も島の町で同じ扱いを受けることにした（**おたがいさま**の条約） |
| ハンザ同盟の商人 | 外国の港で関税や橋の税を免除され、イングランドの商人より安い税で商売できた |
| ローマの旅人の身の回りの品 | 売り物でない物・荷車・家畜には税がかからなかった |

**要点**：免除は「えらい人だから」だけでなく、**おかえしの約束（条約）**や、**お金で買う権利**でもありました。

## 6. 弊害 ― 取りすぎると何が起きるか

### ライン川 ― 関所だらけの大河
- ライン川の関所は、12世紀の終わりに19、13世紀の終わりに44、14世紀の終わりには**62**にまで増えました。
- マインツからケルンまでの約200キロでは、**6〜7キロごとに船を止めて払う**ほどでした。
- 1250〜73年、皇帝がいない「大空位時代」には、たった4年で関所の数が倍になりました。許しなく関所を作ったり、決まりより高く取ったりする者が現れ、これを**「不当な関税」**と呼びました。
- 経済学者の研究（ガードナーら）は、これを「1本の道に関所の持ち主がたくさんいると、みんなが自分の取り分だけ考えて高く取り、**合計では1人の持ち主が取るよりずっと高くなり、通る船が減って、結局みんなの収入も減る**」という問題として説明しています。

### 盗賊騎士
- 城を持つ騎士が、許しなく通行料を取ったり、払わない商人を襲ったりしました。「盗賊騎士」と呼ばれます。
- 1254年、100ほどの都市と諸侯が**「ライン都市同盟」**を作り、盗賊騎士の城を攻めて壊しました。1254〜57年のあいだに、少なくとも10の城を働けなくしました。

### 鎖と牢屋 ― 払わない者への罰
- ライン川のカウプにある川の中の島の城「プファルツグラーフェンシュタイン」（1326〜27年建築）は、**川に鎖を張って船を止め**、払わずに逃げようとした者を城の地下牢に入れました。この城は1867年まで通行料を取り続けました。

### 市場への強制 ― ケルンの「荷下ろしの権利」
- 1259年、ケルンは大司教から「通る船に荷を下ろさせ、**3日間**町の市場で売りに出させる」権利を得ました。通り抜けたいだけの商人にとっては大迷惑ですが、ケルンは何百年も豊かになりました。

### 抜け道と密輸
- 高い関所があると、商人は山道や夜の川を使って避けようとします。
- 日本の江戸時代では、関所をこっそり避けて山を越える「関所破り」は**死罪**でした。

### 関所をなくすと ― 織田信長
- 戦国時代の日本では、大名・寺社・公家がそれぞれ関所を作り、関銭を取っていました。淀川の河口から京都までのあいだだけで約**380**の関所があったともいわれます。
- 1568年ごろから、織田信長は自分の国（尾張・美濃・南近江など）の関所をなくし、**楽市楽座**（だれでも自由に商売してよい市場）を広めました。人と荷が自由に動くようになり、人々に大いに喜ばれ、信長の国は豊かになりました。
  - ただし、信長の関所廃止は自分の領地の中だけで、京都のまわり全部ではなかった、という見方もあります。
- **教訓**：通行料をやめると一時は収入が減るが、商売が増えて、**売上の税や市場の活気で取り戻せる**こともある。

### モンゴル ― 安く・わかりやすく
- モンゴル帝国は通行料や税を**下げて、国じゅうでそろえ**、道を兵で守りました。商人は「いくらかかるか」が前もってわかるので、安心して長い旅に出られました。

## 7. 世界の見本

### 古代ローマの道
- 国境や港に関所を置き、荷の値打ちの2〜2.5％を取る。身の回りの品は無料。集めたお金は国境の軍へ。

### シルクロードの隊商宿
- 道のりの1日ごとに、城のような宿（隊商宿）が並びました。
- イスラームの王たち（セルジューク朝・オスマン朝）は、寄付の財産で宿を建て、**3日まではただで泊まれる**ようにして商人を呼びこみました。そのかわり、通る荷には通行料や関税をかけ、道と宿と守りの兵の費用にしました。

### ハンザ同盟
- 北ドイツの商人の町の連合。王が1人もいないのに、各地の王と交渉して**関税の免除や引き下げ**を勝ち取りました。ロンドン・ブルッヘ・ベルゲン・ノヴゴロドには、自分たちの決まりで動く「商館」を持っていました。

### アルプスの峠
- ゴッタルド峠は13世紀から使われるようになりました。峠のふもとのウーリの人々は、**橋・船着き場・道の通行料と、峠を越える荷への関税**で暮らしを立てていました。

### 日本の関所
| 時代 | 関所の目的 | 通行料 |
|---|---|---|
| 戦国時代 | お金を取ること＋見張り | 関銭を取る。数が多すぎて旅人の大きな負担に |
| 織田信長 | 関所をなくす | 無料（楽市楽座） |
| 江戸時代 | 見張り（「入り鉄砲に出女」＝江戸へ入る武器と、江戸から逃げる大名の妻を見張る） | ほぼ無料。そのかわり**通行手形**（村の名主やお寺が出す身分証）が必要 |

→ 関所には「**お金を取るための関所**」と「**人を見張るための関所**」の2種類がある。

## 8. ファンタジー作品・ゲームでの描かれ方

- **トロルの橋**：ノルウェーの昔話『三びきのやぎのがらがらどん』（1840年代にアスビョルンセンとモーが集めた）。橋の下のトロルが通る者を食べようとし、いちばん大きなやぎに川へ落とされる。「橋にはトロルが住んでいて、通るには何か払わないといけない」というお約束は、ここから広まったといわれます。ゲームでは「お金を払う」「なぞなぞに答える」「戦う」のどれかで通るのが定番です。
- **盗賊の関所**：『ウィッチャー3』には、盗賊が橋を占領して勝手に通行料（50クラウン）を取る話があります。払う・魔法でだます・戦う、を選べます。
- **兵士が勝手に取る関所**：『キングダムカム・デリバランス2』には、兵士たちが町と町のあいだの道に居座り、商人から通行料を取る話があります（宿の主人が困って主人公に頼む）。力ずくでも、話し合いでも解決できます。
- **よくある型**
  - 関所の番兵に**わいろ**を渡して通る。
  - **ギルドの通行証**や**王の書状**を見せると無料で通れる。
  - 冒険者は魔物退治の依頼中なら免除、というような「身分による免除」。
  - 関所を避けて**危険な森や山の抜け道**を通ると、魔物や山賊に出会う。

## 9. エルデラントでの提案

### 9-1. 今の物価（ゲームの中）
| もの | 値段・稼ぎ |
|---|---|
| パン1個 | 3銅貨（基準） |
| 小麦1 | 2銅貨 |
| 武器1 | 30銅貨 |
| 宝石1 | 80銅貨 |
| 宿代 | 1人1日3銅貨 |
| 兵士・衛兵の給金 | 1時間1銅貨（騎士は1.4） |
| 1人1日の稼ぎ | パン職人+9、漁師+10、船乗り+11、農夫+4 ほど |
| 道を1マス敷く費用 | 2.5銅貨（橋は1マス10銅貨） |
| 荷車の積み荷 | 最大10個、船は20〜30個 |

→ **ふつうの働き手の1日の稼ぎ ＝ およそ8〜10銅貨**とみなす。歴史では「荷馬1頭ぶんの通行料＝日給の数分の1、荷車1台＝日給の半分」なので、これに合わせます。

### 9-2. 料金表（案）

**(A) 決まった料金（関所・橋・渡しで1回払う）**

| 通るもの | 街道の関所 | 橋・渡し・峠 | 根拠 |
|---|---|---|---|
| 歩く旅人（荷なし・身の回りの品だけ） | 無料 | 1銅貨 | ローマは身の回りの品は無料。橋は歩く人も半ペンス |
| 背負いの荷（行商人など） | 1銅貨 | 1銅貨 | |
| 荷馬・ろば1頭ぶんの荷 | 1銅貨 | 2銅貨 | シュルーズベリーの4分の1ペンス |
| 荷車1台 | 4銅貨 | 6銅貨 | 荷馬の4倍（シュルーズベリーの比） |
| 船1艘（川の関所・港） | 16銅貨 | ― | 荷車の4倍 |
| 牛・馬1頭（売り物） | 1銅貨 | 1銅貨 | 半ペンス |
| 羊・山羊・豚10頭 | 2銅貨 | 2銅貨 | |
| 地元（その国の町の住民） | 上の半額 | 上の半額 | シュルーズベリーの地元割引 |

**(B) よその国の荷にかける関税（国境の関所）**
- 荷の値打ちの **3％**（標準）。王が欲張りなら最大 **8％**、気前がよければ **1〜2％**。
  - ローマ 2〜2.5％、デンマーク 1〜2％ が歴史上の「うまくいった」水準。
- 仲の悪い国（関係 −30 未満）には1.5倍、戦争中の国には2倍、または通さない。
- **うその申告を防ぐ決まり**：申告より実際の値打ちが高いと見つかったら、関所がその荷を「申告した値段」で買い取る（デンマーク方式）。買い取った荷は町の市場に出す（お金は国庫→商人、荷は商人→市場）。

**(C) 上限（取りすぎを防ぐ）**
- 1回の旅（出発の町→着いた町）で払う通行料・関税の**合計は、荷の値打ちの15％まで**。これを超える分は取らない（ライン川の教訓）。
- 1本の街道に置ける関所は、**国ごとに1つ（国境）＋大きな橋・峠に1つ**まで。
- 同じ日に同じ国の関所を2回通っても、2回目は無料（**手形**を受け取る）。

### 9-3. 免除と条約のルール（案）
| 免除される人・もの | 条件 |
|---|---|
| 巡礼・聖職者（司祭） | 常に無料。ただし売り物を積んでいれば (B) はかかる |
| 王の使者・役人・公務中の兵士と騎士 | 無料 |
| 冒険者 | ギルドの依頼（魔物退治・護衛）で動いているあいだは無料。ふだんは歩く旅人と同じ |
| 開拓民・開拓団 | 開拓地へ向かうあいだは無料（国が開拓を後押しする） |
| 飢饉・災害の救援の食べ物 | 無料（町の蓄えや施し箱から送る荷） |
| 自国の町の市民 | (A) が半額。王が「市民の特権」を出せば無料 |
| 通商条約を結んだ国の商人 | (B) の関税が半分、または無料。**おたがいに同じ扱い**（ゴトランドの例）。どちらかが破れば、相手も元に戻す |
| 同盟国 | (B) 無料、(A) は地元と同じ半額 |
| お金で買う「免除の権利」 | 大商人が国庫に一度に払えば、1年（数十日）無料。払ったお金は国庫へ |

### 9-4. 高すぎるとどうなるか（案）
1. **抜け道**：通行料が荷の値打ちの 5％ を超えると、商人は抜け道（森・山・夜道）を選び始める。選ぶ確率の目安 ＝ （料金の割合 − 5％）× 4。たとえば 10％ で 2割、20％ で 6割。抜け道では魔物・山賊に出会いやすく、見つかれば罰金。
2. **密輸**：密輸人や、まじめさの低い商人は関所を避ける（今のしくみにすでにある）。見つかれば罰金（料金の3倍＋10銅貨）は国庫へ。
3. **わいろ**：番兵に料金の半分を渡すと見逃してもらえることがある。わいろは**番兵の財布**へ（国庫には入らない）。見つかれば番兵が罰せられる。
4. **商人の不満**：高い関税を払った商人は、王への不満がたまる。不満が大きいと、その国へ行く交易をやめ、ほかの国を選ぶ。
5. **交易の減少と値上がり**：荷が届かなくなると、その国の町の品物が値上がりする（希少なものは高い、の決まりどおり）。
6. **盗賊騎士**：国が弱い・王がいない・内乱のときは、騎士や山賊が勝手に関所を作って取る。王は討伐隊を出す（ライン都市同盟の例）。
7. **争い**：通行料の取り合い・高すぎる関税は、国どうしの関係を下げ、戦争の理由の1つになる。

逆に、**関所をなくす王**（信長型）がいてもよい。通行料の収入は減るが、商人が集まり、売上の税と市場の活気が増える。

### 9-5. 通行料の使い道（案）
関所に集まったお金は、次の3つに分けます。

| 行き先 | 割合（案） | 使い道 |
|---|---|---|
| 街道の蓄え（国ごと） | 4割 | 道と橋の修理。修理のときは人夫（道普請の人）に給金として払う |
| 関所の番兵の給金 | 3割 | 番兵1人あたり1日およそ8〜10銅貨。足りない分は国庫から |
| 国庫 | 3割 | 王の自由に使えるお金 |

- 街道の蓄えが多すぎる（たとえば 500銅貨を超える）ときは、あふれた分を国庫へ回す。
- 道を1マス敷くのに2.5銅貨、橋は10銅貨なので、荷車1台4銅貨の通行料なら、**荷車1台の通行で道1マス半ぶん**の修理ができる計算です。
- 橋を新しく架けたときは、「建てた費用を回収するまで」橋の料金を取り、回収し終わったら半額にする、という決まりにすると、ロンドン橋のように筋が通ります。

### 9-6. お金の出どころと行き先
```
払う人の財布（家計）
   │  通行料・関税
   ▼
関所の箱
   ├─→ 街道の蓄え ─→ 修理の人夫の給金（家計へ）
   ├─→ 番兵の給金（番兵の家計へ）
   └─→ 国庫 ─→ 王の支払い（給金・普請など）

罰金（密輸・関所破り）：違反者の財布 → 国庫
わいろ：商人の財布 → 番兵の財布（国庫には入らない）
免除の権利を買うお金：大商人の財布 → 国庫
申告のうそで荷を買い取る：国庫 → 商人の財布、荷は商人 → 町の市場
```
**どこからも湧かず、どこへも消えない**ように、払う人と受け取る人が必ずいます。

### 9-7. 今の作りとのちがい（部長への参考）
- 今の世界にはすでに「他国の町に荷を運ぶと、行き先の国が売値の一部を取る関税」と「密輸」があります。
- 今の関税は **売値の6％＋港1つにつき3％** で、税の重さしだいでさらに上がります。港が多い国では10％を超えることもあり、歴史上うまくいった水準（1〜3％）より高めです。
- 今は「関所」という場所がなく、町に着いた瞬間に払っています。国内の道・橋の通行料や、免除・条約・上限はまだありません。
