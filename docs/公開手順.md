# 一般公開の手順（Cloudflare Pages）

社長の決定により、一般公開には **Cloudflare Pages** を使います。無料で使え、商用利用（将来の広告）も認められています。

この作業は社長のアカウントで行う必要があります（部長からはアカウントの操作ができないため）。
ビルドは不要です。リポジトリのファイルがそのまま公開されます。

## 手順
1. https://dash.cloudflare.com/sign-up で無料アカウントを作る（メールアドレスとパスワードだけで作れます）。
2. 左のメニューの「Workers & Pages」から「作成」を押し、「Pages」タブの「Git に接続」を選ぶ。
3. GitHub と連携し、リポジトリ `mgpmisa/-_misa` を選ぶ。
4. 設定は次のとおりにする。
   - 本番ブランチ：公開したいブランチ（開発中は `claude/bold-fermat-qqbrbp`。整ったら main にまとめて、そちらを指定）
   - フレームワークのプリセット：なし（None）
   - ビルドコマンド：空欄のまま
   - ビルド出力ディレクトリ：`/`（空欄またはスラッシュ）
5. 「保存してデプロイ」を押す。1〜2分で `https://（プロジェクト名）.pages.dev` という住所で公開される。
6. 以後は、部長が変更をプッシュするたびに自動で最新版に更新される。

## 公開の前に部長がやること（収益の第1段階とは別の、最低限の準備）
- 起動画面に「暴力的な出来事が起こります」という注意書きを出す。
- Three.js とフォントの権利表記を、メニューから見られるようにする。

## 注意
- セーブは遊ぶ人のブラウザ内に保存されます。サーバーは不要です。
- 独自ドメイン・広告・来訪者数の測定は、収益の第2段階で改めて決めます（社長の決定で保留中）。
