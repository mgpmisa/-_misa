# お金の流れ ― だれが、だれから、何と引き換えに、いつ受け取るか

経済部がまとめた、エルデラントのお金の決まりと、すべての職業のお金の流れの一覧です。
新しい仕組みを足す社員は、書く前にかならずこの紙を読んでください。

---

## 1. 決まり（社長の指示）

1. **お金は取り引きでしか動かない。** 働いている最中にお金が入る仕組みは作らない。
2. **作り手は、売ったときに受け取る。** 漁師・農夫・職人は、作った品をまず家の蔵にためる。市場で売れたときに、買い手（商人・町の人・宿屋・パン屋など）からお金を受け取る。
3. **雇われる人は、給料日に受け取る。** 兵士・役人・司祭などは、働いた分が「未払いの給金」としてたまり、5日ごとの給料日に雇い主（国庫・町の蓄え・教会）からまとめて受け取る。雇い主のお金が足りなければ未払いのまま残り、不満がたまる。
4. **品物は「作る → 持つ → 売る → 買う → 使う（食べる）」と回る。** 人は食べるために買い、買うために働く。
5. **お金には必ず出どころと行き先がある。** どこからも湧かず、どこへも消えない。例外は次の「外から入る・外へ出る」だけで、帳簿に理由つきで記録する。
   - 入る：造幣所が打った硬貨・ダンジョンの宝箱・竜の巣の宝・黄金の鉱脈・昔の人が埋めた壺・よそから移り住んだ人の持ち金・偽金
   - 出る：よその国からの資材や家畜の取り寄せ・改鋳で鋳つぶした硬貨・火事で焼けた銅貨・見破られた偽金
6. **毎日、世界じゅうのお金を数える。** 外との出入りを除いて1銅貨でもずれたら、記録に残る（「暮らし」の欄の「帳簿のずれ」）。

## 2. お金の置き場所

| 置き場所 | だれのお金か |
|---|---|
| 家計 | 家族みんなのお金 |
| 財布 | ひとりひとりの小遣いと稼ぎ |
| 夢の貯え・へそくり | ひとりの夢や老後のための貯え |
| 町の蓄え | 町（村）のお金。村では「村の蔵」の元手にもなる |
| 施し箱 | 教会のお金。十分の一税と寄進がたまり、施しと司祭の給金に使う |
| 組合の箱 | 町の商人と職人の組合のお金。入会金と組合費がたまり、病気や老いた組合員を助ける |
| 国庫 | 国のお金 |
| 両替商の館の金庫・土に埋めた壺 | 銀行に預けたお金・隠したお金 |
| 老後の組合の箱・救貧院の箱 | 年金にあたるお金 |
| 街道の蓄え・関所の箱・荷車の箱 | 街道の普請と通行料・運んでいる現金 |

**市場の金庫（どこでもない財布）はなくしました。** 市場の品にはかならず持ち主（商人・作り手・町・国）がいて、売れた代金はその持ち主へ入ります。

## 3. 市場と商人（販売の決まり）

- **作り手は、資格なしで次の3つから、自分で考えて選ぶ**（性格・家計の苦しさ・品の量・市の日かどうか）。
  1. **市の日の露店**：町ごとに3日に1度。場所代（パン1個分）を町の蓄えに払い、町の人に相場どおりで直接売る。半日つぶれる。売れ残りは持ち帰る。
  2. **町の商人に売る**：いつでも。商人は相場の8割で買い取る（商人の家計 → 作り手の家計）。商人の手元が細いときは、店に置いてもらい、売れたときに受け取る（店番の手間賃1割）。商人のいない村では、村長が村の蓄えで同じ値で買い取り、村の蔵に置く。
  3. **家で食べる**（自炊）。家族の食べる分は売らずに取っておく。
- **町で店を構えて売れるのは、組合に入った商人と職人だけ。** 入会金は日給（9銅貨）の30〜60日分（親が組合員なら半額）、組合費は季節（10日）ごとに日給2日分。どちらも組合の箱へ。組合費を2季ためると組合から外される。
- **商人のもうけ**：買い取った値と売った値の差、預かり品の手間賃。はかり料（買い取った値の1%）を町の蓄えへ払う。
- **買い付け**：王都や港町の商人は、品の余っている近くの村・港の市場で品の持ち主から買い、荷車の手間賃を御者・行商人に払って、次の日に自分の店に並べる。
- **罪**：露店で量をごまかす、市場の外で作り手の家を回って先回りして買い占める。見つかると罰金（半分は告げた人へ、半分は施し箱へ）。
- 値段は今までどおり、在庫が多ければ下がり、少なければ上がる。作りすぎた品は売れず、家の蔵で傷む（魚・肉・パン）。

## 4. 店と水車の持ち主

- 店（パン屋・鍛冶場・工房・仕立て屋・薬屋・よろず屋・宿屋・酒場・湯屋）は、持ち主と店主が別のことがある。店主の持ち物になる割合は、王都は半分、港町は6割、そのほかは8割。残りは貴族・商人・教会から借りる。
- 借り賃は住まいと同じ計算で週ごと（店主の家計 → 持ち主の家計。教会なら施し箱、国なら国庫）。
- 払えないとき：1週目は待ってもらう、2週目は差し押さえ（仕事の道具と武器・防具・身につけている物は取らない。5日以内に払えば返す。払えなければ品は売られ、代金は大家へ）、3週目は追い出し（店なら閉めて空き店）。住まいの家賃も同じ段階。
- 店主がやめたら、同じ仕事の別の人に貸す。店に住む家族は別に家を借りない。
- 水車（風車小屋）は領主（いなければ国）のもの。粉屋は週18銅貨で借り、麦をひくたびに麦の16分の1を粉ひき代として受け取る（農家・パン屋 → 粉屋、麦で）。
- 酒を売る許し：その週に麦酒を仕込んだ家は、週に1度、日給1日分（9銅貨）を町の蓄えへ。
- 町の負担：町に家を持つ家は、週に大人1人1銅貨を町の蓄えへ（借り手は払わない）。

## 7. 新しい仕組みを足すとき（社員向け）

- 市場で買う：`marketBuy(sim, 町id, 品, 数, 払う人)`（market.js）。払う人は世帯、`'k'+国id`（国庫）、`'t'+町id`（町の蓄え）、`'a'+町id`（施し箱）。代金は品の持ち主へ自動で渡る。
- 市場に品を出す：`marketDeliver(sim, 町id, 品, 数, 売る世帯)`。国や町の品は `ownStock(sim, 町id, 品, 'k'+国id, 数)`。
- 作った品：`stash(sim, 人, 品, 数)`（家の蔵へ）。`sim.sell` も同じ動き。
- 給金：`accrueWage(sim, 人, 時間)`、決まった額は `owe(sim, 人, 払い手, 額, 理由)`（payday.js）。
- 外との出入り：`moneyIn(sim, 額, 理由)`・`moneyOut(sim, 額, 理由)`・`newcomerMoney(sim, 世帯, 人々)`（ledger.js）。
- `m.stock[品] -= 数` と書いて代金を払わないのは禁止（持ち主の品がただで消える）。`hh.money += 数` と書くときは、同じ額をどこから減らしたか、同じ行に書く。
- 新しいお金の置き場所を作ったら、ledger.js の `moneyTotal` に足す。
