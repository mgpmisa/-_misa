# 戦闘の研究 ― 本当の戦い、物語とゲームの戦い、そしてエルデラントの戦い

社長の指示「ファンタジー世界の戦闘について徹底的に調べてください。調べつくして、必要な情報を取り入れてください。」に答えるため、調査部が
（1）中世の本当の戦い、（2）ファンタジー作品とゲームの戦いの決まり、（3）冒険者のランクと釣り合い、を調べた読み物です。
最後の第4部に、エルデラントの戦いに足すべき決まりを、大事な順に数字つきでまとめました。

- 出典は各章の終わりと、最後の一覧にまとめました。
- 開けなかったページは検索の要約から取りました。はっきりした記録がないもの、調査部が考えた数字は「推定」「案」と書いてあります。

## 第0部 いまのエルデラントの戦い（出発点）

今の戦いは、次のように動いています。

| 仕組み | 今の中身 |
|---|---|
| 一撃 | 1分に1回。ダメージ ＝ 攻め ×（0.7〜1.3のゆらぎ）− 守り × 0.5。最低1 |
| 回避 | 身のこなしで3〜25％。腕の良い攻め手はかわされにくい |
| 盾 | 盾を持っていれば 8％＋盾の腕で、ダメージを45％に減らす |
| 会心 | 武器の腕が上がると最大8％で、1.5倍 |
| 間合い | 弓使い3.6、魔法使い3.2、魔導士3.0、ほかは1.3 |
| 職業の差 | 勇者1.1倍〜僧侶0.85倍。武闘家は二連撃15％、シーフは急所12％で1.5倍、僧侶は一撃ごとに仲間を少し癒す |
| 絆 | 仲間との絆で最大＋15％ |
| 逃げる | 体力25％を切ると、勇気が低いほど逃げやすい。戦えない人は魔物に襲われると早めに逃げる |
| 魔物 | 賢い魔物は、回復・撤退・援軍・弱い者（術者）狙い・かばう、をする |
| 手に負えない相手 | 相手の強さの1.6倍の力がそろわないと近づかない |
| 耐久 | 武器・防具は打ち合うたびに傷み、壊れる |
| 属性 | 魔王に聖剣が1.6倍（耐性がつくと1.1倍）、ほかは0.6倍。これだけ |

**足りないもの**：盾役が敵の気を引く仕組み、前衛が後衛を守る形、武器と鎧の相性、属性の弱点、状態異常、疲れ、士気と潰走、けがと後遺症、大きな魔物の部位、パーティとしての撤退。
今は「1対1の殴り合いを、それぞれが勝手にしている」形に近く、パーティで戦っている感じが出ていません。

## 第1部 中世の本当の戦い

### 1-1 武器ごとの長所と短所

| 武器 | 長所 | 短所 | 鎧への効き |
|---|---|---|---|
| **槍** | 間合いが長く、最初の一撃を先に入れられる。安く、覚えやすい。隊列で使うと突撃を止められる。中世の軍でいちばん多かった武器。騎士も槍の稽古をした | 懐に入られると弱い。狭い所で振り回しにくい | 突きなので、鎖帷子（くさりかたびら）には割とよく効く。板金には隙間を狙う |
| **剣** | 軽く、持ち歩ける。攻めも受けもできる万能の「脇差し」。身分の印 | 高い。間合いは槍より短い。鎧の上から斬っても通らない | 布・革には強い。鎖帷子は斬れない（輪が刃を滑らせる）。板金には、刃を握って突く「半剣」で隙間を狙う |
| **斧** | 重さが刃先に乗るので、一撃が重い。盾を割る・引っかけて引きはがす | 振りが大きく、次の一撃まで遅い。受けに向かない | 鎖帷子の上からでも骨を折る力がある |
| **槌・鎚矛（メイス）** | 鎧を切らずに、衝撃で中の体を壊す。刃こぼれしない | 間合いが短い。重い | **鎧に最も強い**。鎖帷子は衝撃を止められず、骨折・脳しんとうを起こす。板金にも凹みと衝撃を与える |
| **弓（長弓）** | 1分に6〜12本（長く射ると6本ほど）。遠くから、数で浴びせる | 何年もの鍛錬が要る。重い鎧は抜けにくい | 布・綿入れの服には強い。鎖帷子＋綿入れは大きく減らす。焼き入れた鋼の板金はほぼ止める。近くで尖った矢じりなら鉄板を貫くことも |
| **弩（いしゆみ）** | 素人でもすぐ使える。一発が強い | 1分に3〜4発。巻き上げ機付きの強いものは1分に1発 | 弓より鎧を抜きやすい |
| **盾** | 矢を止める。隣の仲間も守れる。相手を押す | 片手がふさがる。重い。割れる | ― |

- 矢の力の目安：強い長弓で、25m先で約109ジュール、至近で100〜175ジュール。16枚重ねの綿入れの服が止められるのは、槍先で50ジュールほど。
  → **綿入れの服だけでは矢を止められないが、鎖帷子と重ねると大きく減る**。
- 鉄の板金に尖った矢を射た試験では、80m先でへこむ、30m先で穴があく、20m先で中の服まで貫いた。板が厚くなると、貫くのに要る力は急に増える。
- 中世の板金の多くは、焼き入れをしていない鉄でした。焼き入れた鋼の鎧はほぼ何でも止めますが、高価で少数でした。

### 1-2 鎧の種類と、どの武器に強いか弱いか

| 鎧 | 斬る（剣・斧） | 突く（槍・細剣） | 叩く（槌） | 矢 | 重さと疲れ |
|---|---|---|---|---|---|
| **布・綿入れの服** | 少し止める | 弱い | よく吸う（衝撃をやわらげる） | 遠くの矢は止める。近くは抜ける | 軽い |
| **革** | 少し止める | 弱い | 少し | 少し | 軽い |
| **鎖帷子** | **とても強い** | ふつう（輪が割れる） | **弱い**（衝撃が通る） | 綿入れと重ねれば強い | 肩にかかる |
| **板金** | **とても強い** | 隙間以外は強い | ふつう（凹み・衝撃） | **とても強い** | 全身に分かれるが、手足が重くなる |

- 板金鎧（約30kg）を着ると、歩くのに**2.3倍**、走るのに**1.9倍**の力を使う（王立武具博物館の再現役4人を、走る台の上で測った研究）。背負うより手足に重さがつくほうが疲れ、胸が締まって息も浅くなる。
- 結論：**鎧は武器を選ぶ**。斬る武器は重い鎧に弱く、叩く武器は重い鎧に強い。だから重い鎧の時代には、槌と斧槍（おのやり）が増えた。

### 1-3 盾の壁、隊列、側面と背面、数の力

- **盾の壁**：一人ひとりが、自分の盾と武器で**隣の人の横も守る**。隣に仲間がいると信じられることが、逃げ出さない心の支えになる。
- **弱点は横と後ろ**。隊列の力は前に集まっているので、横や後ろから攻めると、守りの弱い所に力を集められる。
  カンナエの戦い（紀元前216年）では、ハンニバルが両横から包み込み、ローマ軍を包囲した。
- **数の力**：刀や槍で殴り合う戦いでは、一人が同時に戦える相手の数は限られる。そのため、昔の近接戦の数の力は「**人数に比例**」する（ランチェスターの第1法則）。
  一方、弓や魔法のように遠くから誰でも狙える戦いでは「**人数の2乗**」に効く（第2法則）。
  → 近接で大勢に囲まれても、一度に殴れるのはせいぜい3〜4人。遠くから射る者が多いほど、数の差が大きく効く。
- 地形で前を狭めれば、数の多い敵も一度に全員は戦えない。アジャンクールの戦い（1415年）で、イングランド王は森と森の間の泥の畑を選び、前を約730mに狭めて大軍を迎えた。

### 1-4 士気と潰走

- 19世紀フランスの軍人アルダン・デュ・ピックは「戦いの中心は恐怖であり、戦術の核心は、恐怖の中でまとまりを保つことだ」と書いた。
  **兵を戦わせるのは、上官よりも、横にいる仲間の目である**（まとまりは縦より横でできる）。
- 昔の戦いでは、**負けた側の死者の大半は、心が折れて逃げ出したあと**に出た。追撃する騎兵がいると特に多い。
  勝った側の死者は、長い戦いでもふつう**5％以下**。
- 「相手は踏みとどまらないだろう」と信じて突っ込むと、本当にぶつかる前に相手が崩れることがある。士気はお互いに影響し合う。

### 1-5 疲れ

- 近接の殴り合いは、**数分で両方とも疲れ切って止まる**。そのあと一歩下がって息をつき、また押し合う、を繰り返した。
- 一時間を超える戦いができたのは、疲れた前列を後ろの新しい兵と**入れ替える**ことができたから。予備の兵が大事だったのはこのため。
- 重い鎧はこの疲れを大きく早める（1-2の2.3倍）。

### 1-6 けがの重さと、戦場での手当て

- イングランドのタウトンの戦い（1461年）の集団墓の骨を調べると、**いちばん多い傷は頭**だった。一人で8か所の頭の傷を負った者もいて、最初の5つの刃の傷ではまだ死んでいなかった。
  兜が脱げた・動けなくなったあとにつけられた傷も多い。
- 頭の次に多いのは、**前腕の「受け傷」**（相手の一撃を腕で受けたときの傷）。右腕が多い。
- 骨折・手足の切断・頭蓋骨の割れが多く、刃・突き・打撃のすべてが見られる。
- 手当ての例：1403年、のちのヘンリー5世は、顔に矢を受け、矢じりが頭の奥に残った。外科医ブラッドモアが特製の道具で少しずつ抜き、ワインで洗い、はちみつと大麦粉の軟膏を塗り続け、**20日**で治した。
  → 深手でも、腕の良い手当てがあれば助かる。ただし、傷が膿む（化膿する）ことが大きな死因だった。

### 1-7 待ち伏せ、夜戦、地形の利

- クレシーの戦い（1346年）でイングランド軍は、高台を選び、1〜2日かけて溝と罠を掘った。泥と雨が、突撃してくる敵の足を止めた。
- 待ち伏せは地形しだい。隠れる場所がないと成り立たない。敵を**両横からの矢の十字砲火**に誘い込むのが定石。
- 夜は、同士討ち・道迷い・恐怖が増え、待ち伏せには向くが、大軍の指揮には向かない（推定：一般論として）。

## 第2部 ファンタジー作品とゲームの戦いの決まり

### 2-1 パーティの役割

オンラインゲームの「エバークエスト」（1999年）が、**盾役・回復役・攻撃役**の3本柱を形にし、「ワールド・オブ・ウォークラフト」が広めました。
エバークエストでは、ほかに「敵を眠らせて戦いから外す役（支援役）」も欠かせず、この4つがそろわないと強い敵に勝てませんでした。
逆に、特定の3職だけが必須になり、他の職業が要らなくなるという失敗もありました（次の作品で作り直した）。

| 役割 | 仕事 | 代表 |
|---|---|---|
| 盾役 | 敵の気を引き（挑発）、仲間の代わりに打たれる（かばう）。体力と守りが高い | 騎士・聖騎士・戦士 |
| 攻撃役（近接） | 前で大きな傷を与える | 剣士・武闘家 |
| 攻撃役（遠距離） | 離れて撃つ。狙われると弱い | 弓使い・魔法使い |
| 回復役 | 体力を戻す、毒や呪いを解く。狙われやすい | 僧侶 |
| 支援役 | 味方を強くし（強化）、敵を弱くする（弱体・眠らせる） | 魔導士・吟遊詩人 |
| 斥候 | 罠を外し、待ち伏せを見破り、先手を取る | シーフ |

**教訓**：役割は大事だが、「この職がいないと絶対に勝てない」にしすぎると、職業の幅がなくなる。**そろうと楽になる（2〜3割）**くらいがよい。

### 2-2 敵の「怒り」の向け先（ヘイト）と挑発

- 敵は、自分に**傷を与えた量**に応じて、一人ひとりへの「怒り」をためる。**回復した量は、その半分**の怒りになる（回復役も狙われる）。
- 敵は、いちばん怒りの大きい相手を狙う。ただし、狙いを変えるのは、次の相手の怒りが今の相手の**近接で110％、遠くからで130％**を超えたとき（ワールド・オブ・ウォークラフト）。
  → ちょっと上回ったくらいでは狙いを変えないので、盾役は安定して引きつけられる。
- **挑発**：盾役が、今いちばん怒りの大きい者と同じだけの怒りを一気に得て、**3秒**は必ず自分を狙わせる。そのあとは普通の計算に戻る。
- 「ファイナルファンタジー14」では、盾役は「構え」をとると怒りを大きく集め、挑発は「怒りの一番上に立つ（＋1）」。

### 2-3 陣形（前衛・後衛）

- 前衛が敵と後衛のあいだに立ち、後衛は間合いを保って撃つ・癒す。
- 「ダンジョンズ＆ドラゴンズ」（テーブルで遊ぶ会話型のゲーム、以下 D&D）では、**敵を挟み撃ちにすると命中しやすくなる**（追加ルール）。
- 賢い敵は、前衛を回り込んで後衛を狙う。今のエルデラントの魔物もこれをする（25％の確率で弱い者に狙いを変える）。

### 2-4 属性の弱点と耐性

- 「ポケモン」は、弱点**2倍**、ふつう**1倍**、いまひとつ**0.5倍**、効かない**0倍**。二つの型を持てば掛け算で4倍・0.25倍。
- 「ドラゴンクエスト11」は、効き目を百分率で持つ（50なら半分、150なら1.5倍）。
- 「ファイアーエムブレム」の武器の三すくみ（剣は斧に、斧は槍に、槍は剣に強い）は、有利なら**命中＋10〜15、攻め＋1**という小さな差。ヒーローズでは攻めの20％。
  → **相性は、倍にするより、1.2〜1.5倍くらいの小さな差のほうが、勝ち負けがひっくり返りすぎない**。

### 2-5 状態異常

D&D の決まりが、いちばん整理されています。

| 状態 | 中身 |
|---|---|
| 毒 | 攻めと、ものごとの判定が不利になる（ゲームによっては体力が毎回減る） |
| 麻痺 | 動けず話せない。攻撃は当たりやすくなり、そばからの攻撃はすべて会心 |
| 眠り | 動けない。打たれると目を覚ます（多くのゲーム） |
| 混乱 | 敵味方の区別がつかず、でたらめに動く |
| 石化 | 石になり、動けず、年も取らない。重さ10倍 |
| 恐怖 | 恐れの元が見えると不利。自分からは近づけない |
| 気絶（朦朧） | 動けず、身をかわせない |
| 呪い | ゲームにより様々（能力が下がる、回復が効かない、など） |

### 2-6 魔法の種類、詠唱、魔力

- 魔法には、攻める（火・氷・風など）、癒す、強める、弱める、敵を封じる（眠り・麻痺）、守る（結界）の種類がある。
- 「ファイナルファンタジー11」では、唱えている最中に**打たれる・動く・眠らされる・気絶させられる・吹き飛ばされる**と、詠唱が止まる。止まりにくくする装備や魔法がある。
  → **術者は守られてこそ強い**。前衛の意味がここで生まれる。
- 魔力（MP）は使えば減り、休むと戻る。魔力の薬で戻すゲームも多い。

### 2-7 会心・回避・命中・先手・連携

- D&D の会心は「20面さいころで20」＝**5％**、ダメージのさいころを倍にする（足し算の分は倍にしない）。
- 麻痺・眠りの相手への近くからの攻撃は必ず会心。
- 挟み撃ちで命中しやすく。
- 先手：多くのゲームで、素早さ・待ち伏せ・見張りで「先に動く順番」が決まる。斥候がいると不意打ちを受けにくい。

### 2-8 大型の魔物との戦い

「モンスターハンター」の決まりが参考になります。

- 大きな魔物の体は、**頭・胴・翼・尾・脚**などの部位に分かれ、部位ごとに効き目（0〜100％）がある。45％以上が「弱点」。
- 部位に一定の傷を与えると**壊れ**（角が折れる・翼が裂ける・尾が切れる）、**素材が手に入り**、そこがさらに弱くなることもある。
- 傷がたまると**ひるむ**・**転ぶ**。怒ると効き目が変わる。
  → 大きな魔物は「体力を削り合う」より、**部位を壊して弱らせ、ひるませて隙を作る**戦いになる。

### 2-9 逃げる判断と撤退、全滅を避ける工夫

- 「ダーケストダンジョン」では、体力が0になるとすぐ死なず「**死の扉**」という状態になる。そこでさらに打たれると、**75％**の確率で持ちこたえ、打たれるたびに15％ずつ持ちこたえにくくなる。回復すれば抜けられる。
  → **「一撃で即死」ではなく、「倒れた仲間を助けるか、見捨てて退くか」の場面が生まれる**。
- 同じゲームで、撤退そのものにも心の負担がかかり、撤退の失敗で3〜4人を一度に失うこともある。**撤退は早めに決めないと、撤退自体が危ない**。
- D&D の戦いの難しさの目安：**やさしい・ふつう・難しい・命がけ**の4段階。「命がけ」は、誰かが倒れる本当の危険がある。

## 第3部 ランクと釣り合い

### 3-1 冒険者ギルドのランク制度の例

| 作品 | ランク | 決まり |
|---|---|---|
| 無職転生 | S〜F | **パーティに入れるのは、リーダーのランクの上下1つまで**。パーティのランクは受けた依頼と、仲間の平均で決まる。C より上は昇格試験がある |
| ゴブリンスレイヤー | 白金・金・銀・銅・紅玉・翠玉・青玉・鋼鉄・黒曜・白磁の10段 | 新人の白磁は死ぬ者が多い。黒曜・鋼鉄はまだ駆け出し。青玉〜紅玉が中堅。**銀が現場で依頼を受ける最上位**。金は国の仕事、白金は歴史に数人 |
| 多くのなろう系作品 | S〜F（G） | 依頼をこなして点をため、昇格する。S は魔王や竜と戦う格 |

### 3-2 ランクの差はどこまで安全か（まとめと推定）

- 作品では「**上下1つまで**」が一番多い決まり（無職転生）。
- 理由（推定）：ランクが2つ以上離れると、弱い者が狙われて死ぬ・強い者が守りきれない・報酬の分け方でもめる・弱い者が育たない（戦いの経験が強い者に偏る）。
- D&D でも、パーティのレベルがそろっている前提で難しさを計算する。

### 3-3 依頼の難しさとの釣り合い

- D&D の目安では、パーティ全員の「経験の枠」を足して、敵の強さがどのくらいかで、やさしい・ふつう・難しい・命がけを決める。敵の数が多いと、強さを割り増して数える。
- 今のエルデラントは、パーティのランク ＝ 仲間の平均（3人以上なら＋1）、受けられる依頼は「パーティのランク＋1」まで、竜の縄張りは相手の1.6倍の力が要る。
  → 骨組みはすでによい。足りないのは、**顔ぶれの差の上限**と、**役割がそろっているか**の判断。

## 第4部 エルデラントへの提案（数字つき・案）

以下の数字はすべて**調査部の案**です。試験で動かしてから調整してください。
一撃は今どおり「1分に1回」を基本（1手）とします。

### 4-1 足すべき決まり（大事な順）

#### ① 盾役の「怒り」と挑発・かばう（いちばん大事）
- 魔物は、戦っている人ごとに「怒り」をためる。
  - 傷を与えた量 ×1。回復した量 ×0.5（近くで戦っている魔物全部に分ける）。
  - 盾役（騎士・聖騎士・騎士見習い・近衛・戦士）は、与えた傷の**2倍**の怒りを得る（「構え」にあたる）。
- 狙いを変えるのは、別の人の怒りが今の相手の**110％（そばにいる人）／130％（離れた人）**を超えたとき。
- **挑発**：盾役は、仲間が狙われたら挑発する。今いちばんの怒り＋10％を得て、**3手**は必ず自分を狙わせる。使ったあと**8手**は使えない。
  - 知能の低い魔物（今の知能0.3未満）には必ず効く。賢い魔物ほど効きにくい：効く確率 ＝ 100％ −（知能 × 40％）。竜・魔王・魔将は 60％まで。
  - 挑発が効いているあいだは、今の「賢い魔物が弱い者に狙いを変える（25％）」を **10％** に下げる。
- **かばう**：盾役から **2マス以内**の仲間が打たれるとき、代わりに受ける。聖騎士50％・騎士45％・近衛45％・騎士見習い30％・戦士20％。受けたときは盾受けの判定もする。
  - かばうたびに、その盾役の耐久の傷みは1.5倍（盾が早く傷む → 修理代が回る）。

#### ② 前衛と後衛（陣形）
- パーティ・隊は、前衛（盾役・近接）と後衛（弓・魔法・回復）に分かれる。
- 後衛は、前衛の**2〜3マス後ろ**に立つ。敵が近づいたら**下がって間合いを保つ**（1手の移動に使う）。
- **前衛の守り**：敵が後衛へ行こうとしても、前衛から **1.5マス以内**を通るなら、**70％**で前衛に足止めされる（前衛と戦い始める）。飛ぶ魔物（ワイバーン・竜・インプ）は **30％**。
- 後衛が近くで打たれると、弓・魔法の命中が **−20％**、詠唱が止まる（⑧）。

#### ③ 武器と鎧の相性
武器を「斬る・突く・叩く・射る・魔法」に分け、鎧を「布・革・鎖・板金・鱗」に分けます。
**鎧の守りが、どのくらい効くか**を掛けます（ダメージ ＝ 攻め − 守り × 0.5 × この倍率）。

| 攻め方＼鎧 | 布（服・ローブ） | 革 | 鎖帷子 | 板金 | 竜鱗 |
|---|---|---|---|---|---|
| 斬る（剣・斧・曲刀） | 1.0 | 1.0 | **1.6** | **1.8** | 1.6 |
| 突く（槍・細剣・短剣・鎧通し） | 0.9 | 0.9 | **0.8** | 1.3 | 1.4 |
| 叩く（槌・鎚矛・拳・杖で殴る） | 1.1 | 0.9 | **0.6** | **0.8** | 1.0 |
| 射る（弓） | 0.8 | 1.0 | 1.3 | **2.0** | 1.6 |
| 射る（弩） | 0.6 | 0.7 | 1.0 | 1.4 | 1.3 |
| 魔法 | 0.3 | 0.3 | 0.3 | 0.3 | 0.5 |

- 魔物にも「皮の固さ」を持たせる：スケルトン・ゴーレム・スケルトンナイトは「板金なみ」、ワニ・竜は「鱗」、ほかは「革」か「布」。
- 武器ごとの差（案）：
  - 槍・長柄：間合い **1.8マス**。近づいてくる敵に**先に1回**突ける（先手）。懐（0.8マス以内）に入られると攻め **−20％**。
  - 短剣：1手が速い（**0.8分**）、攻めは低い。背後からは会心が出やすい。
  - 大剣・大斧・戦槌：1手が遅い（**1.3分**）、盾受けされにくい（盾の減り方 45％→ 65％）。
  - 弓：間合い **3.6**。弩：間合い **3.8**、1手 **2.5分**（巻き上げ）、腕が要らない（技能の差が小さい）。
- 盾は矢に強い：矢・弩が相手のときは、盾受けの確率を **2倍**。

#### ④ 属性の弱点と耐性
- 属性は **火・水・風・土・光・闇** の6つ。
- 効き目は **弱点1.5倍・ふつう1倍・耐性0.5倍・無効0倍**（ポケモンの2倍は振れ幅が大きすぎるので1.5倍に抑える）。例外として「不死者に光」だけ **2倍**（物語の定番で、僧侶の見せ場）。
- 属性を持つ攻め：魔法使い（火・風）、魔導士（水・土）、僧侶・聖騎士（光）、聖剣（光）、竜鱗の剣（火）、炎の剣（火）、氷牙の短剣（水）、そのほか魔法の武器。**ふつうの武器は属性なし（物理だけ）**。
- 種族ごとの表は 4-3。

#### ⑤ 状態異常
| 状態 | 誰が与える | 効き目 | 続く長さ | 治し方 |
|---|---|---|---|---|
| 毒 | 大蜘蛛・アラクネ・サソリ・ヘビ・毒の短剣 | 毎手、最大体力の **2％** 減る。攻め −10％ | **30手**（または治るまで） | 解毒薬・僧侶の祈り・薬師。体力（vit）が高いほど早く抜ける |
| 出血 | 斬る武器の会心、魔物の爪と牙の会心 | 毎手 **1％** 減る | **10手** | 手当て（布を巻く1手）・回復薬・僧侶 |
| 麻痺 | アラクネの糸、サソリの尾（会心時） | 動けない。受ける攻撃は会心しやすい（＋20％） | **3手** | 時間・僧侶 |
| 眠り | 魔導士の呪文、ミイラの息（案） | 動けない。**打たれると起きる** | **5手** | 打たれる・仲間が起こす（1手） |
| 混乱 | リッチ・ファラオの亡霊の呪文 | **30％**で近くの誰か（味方も）を狙う | **4手** | 時間・僧侶 |
| 恐怖 | 竜の咆哮、魔王、魔将 | 攻め −20％。勇気で抵抗。近づけない | **5手** | 勇者・聖騎士がそばにいると半分 |
| 呪い | リッチ・ファラオの亡霊 | 回復が **半分**しか効かない。戦いが終わっても残る | 教会で解くまで | 教会の解呪（お布施） |
| 石化 | 今はいない。将来のバジリスク・コカトリス用 | 石になる | 治すまで | 高い薬・大神官 |

- 抵抗：体の状態（毒・麻痺・出血）は **体力**、心の状態（眠り・混乱・恐怖）は **精神** が高いほどかかりにくい。
  例：かかる確率 ＝ 基本 −（能力 − 10）× 3％。
- 不死者（スケルトン系・ミイラ系・リッチ）とゴーレムは、毒・眠り・混乱・出血が効かない。

#### ⑥ 疲れ（スタミナ）
- 戦う人は「息」を **100** 持つ。
  - 1手ごとに −3。重い武器（大剣・大斧・戦槌・長柄）は −4。
  - 鎧の重さで掛ける：布×1、革×1.1、鎖×1.3、**板金×1.6**（研究の2.3倍を、鍛えた兵なのでやわらげた）。
  - 打ち合っていない手（移動・待つ）は +6、戦いの外では1分に +10。
- 息が **30 未満**：攻め **−20％**、回避 **半分**。**10 未満**：攻撃できず、一歩下がって息をつく（2手）。
- **入れ替え**：前衛の息が30を切ったら、後ろに元気な前衛がいれば入れ替わる（本当の戦いの「前列の交代」）。**予備がいるパーティ・隊が強い**、という形が自然に出る。
- 体力（vit）が高いほど減りが少ない：減り ×（1 −（vit − 10）× 2％）。

#### ⑦ 士気と潰走
- 群れ・隊・パーティごとに「士気」**100**。
  - 仲間が倒れる −15、長（リーダー）が倒れる **−40**、囲まれた（横・後ろから打たれた）−10、敵の数が2倍以上 −10、体力の平均が半分以下 −10。
  - 長が生きてそばにいる +10、敵の長を倒した +20、勇者・聖騎士がいる +10（人の側）。
- 士気 **30 未満** で **潰走**：全員が逃げ出す。逃げる者は背中を見せるので、追う側の攻めは **1.3倍**、回避なし。
  - 本当の戦いと同じく、**負けた側の死者の多くは逃げるときに出る**。
- 人ひとりの勇気（values.courage）と、パーティの絆は、士気の下がり方を和らげる：下がり ×（1.3 − 勇気 × 0.6）×（1 − 絆 ÷ 400）。
- 竜・魔王など「親玉」は潰走しない（今どおり）。

#### ⑧ 魔法：魔力と詠唱
- 魔力 ＝ 10 ＋ 知力 × 2 ＋ レベル × 1（僧侶は 知力の代わりに精神）。
- 攻めの魔法：魔力 **4**、詠唱 **1手**。強い魔法：魔力 **10**、詠唱 **2手**、範囲（2マス以内の敵すべて）。回復：魔力 **5**、最大体力の **25％**。解毒・解呪：魔力 **4**。
- **詠唱中に打たれると 50％で止まる**（魔導士・熟練は −(攻撃魔法の腕 ÷ 4)％）。魔力は失う。
- 魔力は休むと戻る（1時間に 10）。魔力が切れた術者は杖で殴る（叩く・弱い）。
- 魔力の薬を作るなら、錬金術師が作り、術者が店で買う（お金：術者の財布 → 店）。

#### ⑨ けがと後遺症（死の扉）
- 殺し合いで体力が0になったら、すぐには死なず「**瀕死**」になる。
  - 瀕死の人は倒れて動けない。出血で **20手** のうちに手当てされないと死ぬ。
  - 瀕死でさらに打たれると、**70％**（鎧で＋、体力で＋、最大90％）で持ちこたえ、打たれるたびに −15％。
  - 仲間が回復薬・僧侶の祈り・手当て（2手）をすれば、体力1で起き上がり、戦いから退く。
  - 魔物は瀕死の人より立っている人を狙う（賢い魔物・残酷な魔物は例外。案：オーク・魔族は止めを刺しに行く）。
- **大けが**：一撃で最大体力の **30％以上** を受けたら、**20％**で大けがを負う（部位は頭・腕・脚・胴で、本当の骨の記録にならい **頭35％・腕30％・脚20％・胴15％**）。
  | けが | 効き目 | 治るまで |
  |---|---|---|
  | 頭の傷 | 1手気絶。のち数日、判断がにぶる | 5〜10日 |
  | 腕の骨折 | 攻め −30％、盾が使えない | 30〜50日 |
  | 脚の骨折 | 歩く速さ −40％、逃げにくい | 30〜60日 |
  | 深い切り傷 | 出血。膿む（今の「傷の膿み」につなぐ）ことがある | 7〜20日 |
- **後遺症**：大けがのうち **10％**（医者にかかれば5％）が一生残る。片目（弓・魔法の命中 −15％）、足を引きずる（速さ −15％）、指を失う（器用 −2）、古傷（天気の悪い日に痛む）。
  - 後遺症で戦えなくなった者は、引退・転職・年金（老後の備え）へつながる。
- **手当てのお金**：医者・薬師・教会に払う（けが人の財布 → 医者の家計／教会）。依頼中のけがは、ギルドの見舞金（ギルドの蓄え → けが人）を案として出せる。

#### ⑩ 大きな魔物の部位
- 対象：竜・ワイバーン・ゴーレム・キングスライム・オークキング・ゴブリンロード・アラクネ・リッチ・ファラオの亡霊・魔将・魔王・クマ・ホッキョクグマ・クジラ。
- 部位と、効き目：
  | 部位 | 当たりやすさ | ダメージ | 壊すと |
  |---|---|---|---|
  | 頭 | −15％ | **1.3倍** | 3手ひるむ。息・咆哮が弱まる |
  | 翼（飛ぶもの） | −10％（弓は0） | 1.0倍 | **飛べなくなる**。近接で届くようになる |
  | 脚 | 0 | 0.9倍 | **転ぶ**：3手動けず、受けるダメージ1.5倍 |
  | 尾 | −5％ | 0.9倍 | 尾の薙ぎ払いがなくなる。**素材が取れる** |
  | 胴 | +10％ | 0.8倍 | ― |
- 壊れる量：その部位に最大体力の **15〜20％** のダメージ。
- **ひるみ**：どの部位でも、最大体力の **10％** 分たまるごとに、1手何もできない。
- 狙い方：弓使いは翼、剣士・戦士は脚、武闘家・槌は頭、など職業ごとに好みを持たせる。
- 壊した部位の素材（竜の角・尾・鱗）は、市場で売れる（お金：買い手 → 冒険者）。

#### ⑪ 横と後ろ、囲み（数の力）
- 一人を同時に近接で殴れるのは **最大4人**（それ以上は待つ）。近接は人数に比例、遠くからは比例以上、が自然に出る。
- 2人以上に近接で囲まれると、2人目以降の攻めは命中 **+10％**。
- **背後から**（相手が別の者と戦っているとき、その反対側から）：回避なし、盾受けなし、ダメージ **1.25倍**。シーフ・盗賊は **1.5倍**、急所の確率も倍。

#### ⑫ 逃げる判断と撤退（パーティとして）
- 5手ごとに、パーティのリーダーが形勢を見る：
  - **いまの力の比**（こちらの力 ÷ 敵の力。力は今の deadly.js と同じ「攻め × √体力」）が **0.6 未満**、
  - または、瀕死の仲間がいて、回復役も薬もない、
  - または、回復役の魔力が切れて、みんなの体力の平均が40％以下、
  - または、士気30未満、
  → **撤退**を決める。
- 撤退のしかた：**盾役がしんがり**（最後まで残る）、後衛・けが人から先に下がる。瀕死の仲間は、絆が50以上ならだれかが背負う（その人は1手遅くなる）。
- 早めの撤退を覚える：撤退した戦いは、記憶に「〇〇に負けて退いた」と残り、次からその相手には1.6倍より多くの力（**2倍**）がそろうまで挑まない。
- 魔物は **8マス** まで追う（群れの長が倒れていれば追わない）。

#### ⑬ 待ち伏せ・夜・地形（あとまわしでよい）
- 待ち伏せ：森・洞窟で、魔物が見つかる前に襲ってきたら、最初の **1手** はこちらが動けない。**シーフ・狩人がいると、70％で見破る**（逆にこちらが先手）。
- 夜：命中 **−10％**（松明・月明かりで ±）、魔物（ゴブリン・アンデッド・コウモリ）は夜に強い。
- 地形：高い所から撃つと命中 **+10％**、ぬかるみ・雪では息の減り **1.3倍**。

### 4-4 パーティの組み方（ランクの差と役割）

1. **ランクの差**：仲間はリーダーのランクの **上下1つまで**（無職転生の決まり）。
   - 例外「**指導**」：B 以上の者が、**2つ下まで**の新人1人を連れて行ける。ただし受けられる依頼は新人のランク＋1まで、報酬は均等に分ける。弟子入り・育成の物語が生まれる。
   - 3つ以上離れた者どうしは組まない。
2. **役割のそろえ方**（4人パーティを基本、2〜6人）：
   - 必ず **前衛1人以上**（盾役がいればなおよい）。
   - **回復役（僧侶・聖騎士）か、人数分の回復薬**。
   - あとは攻撃役（近接か遠距離）。4人目に斥候か支援役。
   - 例：騎士見習い・剣士・弓使い・僧侶／聖騎士・戦士・魔法使い・シーフ。
   - 前衛ばかり・後衛ばかりのパーティは、依頼の難しさを1ランク上に見る（受けにくくする）。
3. **パーティのランク**：今どおり平均（3人以上で＋1）。ただし「**盾役・回復役・攻撃役がそろっている**」ときだけ＋1にする案。
4. **依頼との釣り合い**（D&D の4段階をまねる。力 ＝ 攻め × √体力）：
   | 敵の力 ÷ パーティの力 | 難しさ | 受けるか |
   |---|---|---|
   | 0.5以下 | やさしい | 新人の練習に |
   | 0.5〜0.8 | ふつう | 積極的に受ける |
   | 0.8〜1.1 | 難しい | 役割がそろい、全員元気なら |
   | 1.1〜1.6 | 命がけ | 報酬が高く、勇気のある者だけ。撤退を早めに |
   | 1.6以上 | 無理 | 受けない（今の竜の決まりと同じ向き） |
   - 群れの数が多いときは割り増す：敵が2体で×1.5、3〜6体で×2（D&D の考え方）。

### 4-5 住人が「自分で考えて戦う」ための判断の順番

一手ごとに、上から順に当てはまるものを1つだけ行います。

1. **生き延びる**
   - 自分の体力が25％を切った：回復薬があれば飲む → 回復役が近くにいれば寄る → 勇気と士気しだいで退く。
   - 息が10を切った：一歩下がって息をつく（入れ替え）。
2. **仲間の危機**
   - 回復役：体力50％を切った仲間、瀕死の仲間、毒・呪いの仲間を治す。
   - 盾役：後衛が狙われている → 挑発（使えるなら）→ かばえる距離へ寄る。
   - 誰でも：瀕死の仲間がそばにいて、薬を持っていれば手当てする（絆が高いほど優先）。
3. **パーティの判断**（5手ごと、リーダーだけ）：撤退の条件（4-1⑫）を見て、全員に「退け」を出す。
4. **役割の位置取り**：前衛は敵と後衛のあいだへ、後衛は間合いを保つ、盗賊・シーフは背後へ回る。
5. **狙いを選ぶ**（賢さと性格で重みを変える）
   - 盾役：いちばん多くの仲間を狙っている敵。
   - 攻撃役：①いまにも倒れそうな敵 ②術者・回復役の魔物 ③弱点を突ける敵 ④長（倒せば敵の士気 −40）。
   - 弓使い・魔法使い：飛ぶ敵、群れの密集（範囲魔法）。
   - 仕返しの気持ち：仲間を倒した敵を優先する人もいる（人柄：協調性が低く、神経質な人）。
6. **攻め方を選ぶ**：弱点の属性、鎧に合う武器（持ち替えられる予備があれば）、大きな魔物なら壊しやすい部位。
7. **ふつうに攻める**。

これは魔物にもほぼ同じ順で使えます（今の monsterTactics の「回復 → 撤退 → 援軍 → 弱い者狙い → かばう」に、怒りの計算と士気を足す形）。

### 4-6 お金の出どころと行き先（新しく動くお金）

社長の決まり「お金は取り引きでしか動かない」「出どころと行き先を必ず書く」に合わせました。

| 場面 | 払う側 → 受け取る側 |
|---|---|
| 回復薬・解毒薬・魔力の薬を買う | 冒険者・兵の財布 → 店（作った錬金術師・薬師） |
| けがの治療 | けが人の家計 → 医者の家計／薬師 |
| 呪いを解く | 呪われた人 → 教会（お布施） |
| かばって傷んだ盾の修理 | 持ち主（兵は国庫の待遇から） → 鍛冶屋 |
| 部位を壊して取った素材を売る | 商人・職人 → 冒険者 |
| 依頼中のけがの見舞金（案） | ギルドの蓄え → けが人 |
| 後遺症で引退した兵の手当て（案） | 国庫 → 元兵（老後の備えの仕組みにつなぐ） |

### 4-7 作る順番の案（開発部へ）

1. ① 怒り・挑発・かばう ／ ② 前衛・後衛（今作っている「騎士の挑発」の続き。いちばん効き目が大きい）
2. ③ 武器と鎧の相性 ／ ④ 属性（表を data.js か新しいファイルに置くだけで、一撃の計算に掛け算を1つ足す）
3. ⑦ 士気と潰走 ／ ⑫ パーティの撤退（全滅を減らす）
4. ⑨ 瀕死とけが・後遺症（health.js の「傷の膿み」、老後の備えとつなぐ）
5. ⑤ 状態異常 ／ ⑧ 魔力と詠唱
6. ⑥ 疲れ ／ ⑩ 大きな魔物の部位 ／ ⑪ 囲み ／ ⑬ 待ち伏せ・夜・地形

**試験で見るべき数字**（案）：
- 冒険者の1年あたりの死者が、今より減るか（瀕死と撤退の効き目）。
- 盾役がいるパーティの後衛の死亡率が、いないパーティの **半分以下** になるか。
- 群れとの戦いで、死者の多くが「潰走のとき」に出ているか。
- どの魔物の種も絶滅していないか。
