# ドット絵の知識

`references/` に、社長から受け取った知識ファイルが入っている。**全部を読み込まない**。まず目次を読み、条件に合う項目だけを引く。

| ファイル | 中身 |
|---|---|
| `references/教訓の目次.md` | 教訓422件の索引。最初にここを読み、軸の値（対象・体型など）で絞り込む |
| `references/造形辞典.md` | シルエットと形の取り方 |
| `references/質感辞典.md` | 金属・布・毛・鱗などの塗り分け |
| `references/人体辞典.md` | 頭身、関節、顔 |
| `references/装備辞典.md` | 武器と防具の描き方 |
| `references/動物魔物辞典.md` | 種ごとの特徴、見分けるための要点 |
| `references/重量辞典.md` | 重さの表現（沈み込み・歩き方） |
| `references/一般常識辞典.md` | 描写の常識（不自然さを避ける） |
| `references/語彙表.json` | 検索に使う語彙 |
| `references/SKILLS.json` | 教訓の本体（大きいので grep で必要な部分だけ引く） |

## このプロジェクトでの使い方
- スプライトは `js/sprites.js` が生成する。
  - `drawPerson(p, {age, dead})` と `drawCreature(c, def)` は、4方向×3コマのシートを返す（VXAce 形式。`userData = {frameW, frameH, cols:3, rows:4, worldH}`）。
  - 同じ id からは、いつも同じ見た目になる。
- 内装は `js/interior.js` のボクセル家具と、`canvasTex` のドット絵テクスチャで作る。
- 見分けやすさを優先する。種・職業・身分がシルエットと色で分かるように描き、同じ種でも個体差（毛色・模様・大きさ）をつける。
- 正面（下向き）の歩行を必ず描く。
