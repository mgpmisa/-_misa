# 装備辞典 — 人が身にまとうものの構造と追従

最終更新 2026-08-10 / 対象 16〜48px / 作成: ドット絵専属Claude
信頼度: **【確】**=出典に明記 / **【推】**=出典の一般則からの導出設計値 / **【実】**=実測 / **【未】**=未確認

> **使い方**: 装備を描く前に「**どこで支えているか**」を決める。支持点が決まらないと、歩いたときの揺れ方が決まらない。
> **依頼主からの指摘**: 全身を覆うローブから手が出ているなら**肩にローブがかかっていないとおかしい**。着ているものの構造を理解して描く。

---

## 0. 三原則

1. **支持点を決める** — 肩／腰／頭頂／額／首下の一点。ここから放射状にしわが出る
2. **追従を決める** — 本体と同時／1コマ遅れ／2〜3コマ遅れ／全く動かない
3. **「布は形が変わり、金属は位置が変わる」** — 布は輪郭が毎コマ変形し、金属は輪郭を保ったまま平行移動＋反射ハイライトの移動だけで動く

## A. 布の衣類

### A-1. チュニック／ローブ（貫頭衣系）

| 項目 | 内容 |
|---|---|
| **構造** | 前身頃・後身頃の**矩形パネル2枚＋袖2枚**のT字型。そこに**ゴア（三角布）を4箇所以上**——中央前・中央後・左右脇——挿入して裾幅を出す。ゴアは**バイアス（斜め）に裁つ** 【確】 |
| **支持** | **肩の縫い目**。全重量が肩から吊り下がる。**ベルトは支持ではなく「たるみを腰で拘束する」役割** 【確】 |
| **追従** | 肩・胸（同時）→ 腰（わずかに遅れ）→ **裾が最も遅れる**。ゴアが4枚以上あると歩行時の動きが増える 【確】 |
| **32pxの最小表現**【推】 | 胴を6〜8px幅、裾を9〜11px幅にして**下端2〜3px分だけ左右に1px張り出す**とAライン裾が読める。16pxでは片側1pxが限界 |
| **外すと** | 裾の張り出しを消すと**円筒（樽・寝袋）**。肩支持を無視して腰でくびれさせすぎると**現代のTシャツ+ズボン** |

**袖の付き方3種** 【確】

| 種類 | 縫い目 | 見え方 | 32pxでの描き分け【推】 |
|---|---|---|---|
| **セットイン** | **肩先**に落ちる | 肩が角張って構築的 | **肩の外側1pxに縦の色境界** |
| **ラグラン** | **襟ぐりから脇下へ斜行**。肩の縫い目がない | **肩線が傾斜** | その1pxを斜めに崩す |
| **キモノ** | 縫い目なし（一体裁ち） | 肩線が非構築的に流れる。脇下のしわは避けられない | **境界を置かず肩から袖まで同色で流す** |

### A-2. マント／クローク

| 項目 | 内容 |
|---|---|
| **構造** | 半円形が代表。後期はより長く豊かに。留め方は**円形ブローチ**が基本、他に紐・レース・留め具（茨・骨・木・角）。マントルは**前面をコード or 2つのブローチ**、または**大型宝石入りブローチ1個**で保持 【確】 |
| **支持** | **両肩＋留め具のある一点**。留め具が支点になり、そこから放射状にしわ |
| **追従** | **本体で最も遅れる部位**。停止時は**足が最初に止まり、マントは限界まで動き続けてから止まる**。柔らかい素材は直線でなく**S字カーブの経路** 【確】 |
| **32pxの最小表現**【推】 | **首の下に1×1pxの留め具（明色1px）**＋背後に本体より左右各1〜2px広い布塊。4コマ中、**布塊の下端だけを1コマ遅らせて1px左右にずらす** |
| **外すと** | 留め具の1pxを外すと**背中に貼り付いた板**。遅延を外すと**硬い翼／甲羅** |

### A-3. ズボン（ホーズ・ブレー・タイツ）

| 時代 | 構造 【確】 |
|---|---|
| 13〜14世紀 | 腰から足まで伸びるタイツ。下に別体のブレー（下着）。**ダブレットに紐で結んで張りを保つ**。ウール製・密着裁断 |
| 15世紀 | 装飾化。**左右の脚で色が違う**（パーティカラー）。足先まで覆う。**左右は別体**。ダブレットが短くなりコッドピースが追加 |
| 16世紀 | アッパーホーズ（ブリーチズ）とネザーホーズ（ストッキング）に分離。トランクホーズ／スロップス／プルーダーホーゼン |

- **支持**: 腰ではなく**ダブレットの裾から紐で吊る**＝最終的な荷重は**肩**にかかる。これがベルト支持の現代ズボンとの決定的な違い 【確】
- **追従**: 密着裁断のため**本体と同時**。布の遅延はほぼゼロ
- **32pxの最小表現**【推】: 脚を各3px幅、**膝位置に1pxの暗色を横一列**入れると関節が読める。**左右色違いは16pxでも成立する唯一の「時代記号」**
- **外すと**: 膝の1pxを外すと**棒／義足**。左右同色で幅を広げると**現代のパンツ**
- 【未】膝・股のしわの発生位置

### A-4. 貴族の服 — 何が「高価」に見せるのか 【確】

| 要素 | 内容 |
|---|---|
| **素材** | 貴族のみ**絹・ベルベット・毛皮**。中産階級は上質ウール。職人・農民は**粗いウールと亜麻** |
| **色（最重要）** | 真の紫は**アッキガイ1gに数千匹**。金糸、ラピスラズリのウルトラマリン、コチニール虫のクリムゾン、緑。下層は**茶・灰・生成り**（高価な染料が買えない） |
| **長さ** | **長い衣服が高位**。理由は「**長い服は肉体労働に不向き＝余暇の象徴**」 |
| **袖** | 貴族は**幅広で装飾的**。農民は作業のため**短くフィット** |
| **法的裏付け** | **1485年ニュルンベルク服装令**「ベルベットと絹は貴族のみ」 |

**★小サイズで効く優先順位**【推】: **色 > 長さ > 袖幅 > 装飾**

1. **色（コスト0）**: 紫・深紅・濃青を主色にする。茶・灰・生成りを使わない。**これだけで16pxでも階級が読める**
2. **長さ（16pxで2px）**: 裾を足首まで。庶民は膝上
3. **袖幅（32pxで2px）**: 袖口を上腕より2px広げる
4. **金の縁取り（32pxで1px）**: 襟・袖口・裾に明黄1pxライン
5. **重ね着（32pxで襟2px）**: 首元に下層の色を1〜2px覗かせる

**外すと**: 色を茶系のまま長さだけ伸ばすと**修道士／農民の礼装**。金縁だけ足して色がくすんでいると**成金・偽貴族**（意図的に使える）

### A-5. ターバン 【確】

| 様式 | 布長 | 巻き方 |
|---|---|---|
| **シク教徒のダスタール** | 綿/モスリン **5〜7m** | **パトカ（三角の下布）を土台**に、平坦な水平の巻きを重ねて上方に**10〜20層**積み上げドーム形。派生: ゴル（丸型・日常）／ノク（円錐・正装）／ドゥマラ（大容積・ニハング戦士） |
| **ラジャスタンのパグリー／サファ** | **4〜7m** | **布の中点を額に当て**、時計回りor反時計回りに巻きつつ**布をひだ状のリッジに畳む**。端を重ねて**後方に扇状の張り出し** |
| **アラブのイマーマ** | 白 **4〜6m** | **スカルキャップを土台に**。正方形を対角に折り三角形にし、**頂点を額に置き**、端をうなじで交差→前方へ耳の上→折り込んで角張ったピーク |
| **オスマンのサルク／カヴク** | 【未】 | **カヴク（硬い帽体）**の上に巻く。セリミ／ムジェッヴェゼなど**身分別の形状** |
| **トゥアレグのタゲルムスト** | **6〜10m** インディゴ綿 | ターバンとヴェールを兼ねる |

- **支持**: **頭頂と側頭**。巻きの摩擦とドームの自己保持。イマーマ・カヴクは**下地の帽子**が支持体
- **見える巻きの本数**: ダスタールは10〜20層でも**外周に露出するのは最上層の数本のみ**。ラジャスタン式は**視覚的な畝が多数**見える
- **追従**: **本体と完全に同時**（頭部剛体）。例外は**垂れ端**（後方の扇・肩に落ちる端）で、これは布として遅れる
- **32pxの最小表現**【推】: 頭部（10〜12px）に対し**高さ5〜8px、幅は頭部+2px**。**水平の巻き線は2〜3本が上限**（これ以上は縞のノイズ）。額の起点に**中央1pxの明色ドット**。円錐形なら上へ1pxずつ絞る。16pxでは高さ3px・幅+1px・巻き線1本まで
- **外すと**: 巻き線を全部外すと**ニット帽／ヘルメット**。幅を頭部と同じにすると**フード**。高さを出さず横に広げると**傘・皿**

## B. 金属の防具

### B-1. 鉄の胸当て（キュイラス／ブレストプレート）

| 項目 | 内容 |
|---|---|
| **構造** | 前胸甲＋背甲の2枚。接合は**肩と側面のレザーストラップ＋バックル**。「**腕の開口部の下で側面を閉じる横ストラップ**で隙間を防ぐ」。イタリア式は片側ヒンジ＋反対側バックル 【確】 |
| **覆う範囲** | 「首または肩からウエストまたは腰まで」だが、史実の多くは**可動域確保のためみぞおちか臍で終わる**。腰まで達する設計は動きを著しく制限 【確】 |
| **可動の分割** | **プラッカート**（15世紀半ば、下部が上部に重なりスライディングリベットで保持）／**フォールド**（関節化された水平の重なりラメがエプロン状のスカートを形成、戦場用は膝上で終わる）／**キュレット**（後方）／**タセット**（フォールド下端からストラップで吊る大腿防具）／**ブザギュー**（肩前面の隙間補完板）／**タプル**（c.1550の中央縦稜） 【確】 |
| **支持** | **肩ストラップ＋ウエストベルト**の2点。脚部装甲は**レンデニエ（頑丈なウエストベルト）**で固定し重量が腰に載る。腕・肩の装甲は**アーミングダブレットの紐で直接結ぶ**＝荷重は着衣に載る 【確】 |
| **追従** | **本体と完全に同時、変形なし**（剛体）。唯一の例外がフォールド／タセットで、**ラメが屋根瓦状に滑って角度を変える** |
| **32pxの最小表現**【推】 | 胸部に**幅6〜7px・高さ5〜6pxの明色ブロック＋上端1pxのハイライト**。**下端を臍位置で水平に切るのが最重要**——ここを切らないと鎧に見えない。肩ストラップは左右各1pxの斜め線。フォールドは腹部下に幅7px・高さ2pxの帯を1〜2本 |
| **外すと** | 下端の水平境界を外すと**シャツ／ベスト**。ハイライトを外すと**革鎧**。肩ストラップを外すと**エプロン** |

### B-2. 兜（ヘルム）

| 種類 | 形状 | 視界開口部 | 32pxの識別記号【推】 |
|---|---|---|---|
| **ノルマン兜** | 円錐/半球のスカルキャップ。8〜13世紀。1枚板鍛造 or **スパンゲンヘルム式**（フレームバンドに三角板4枚を2〜3cm間隔でリベット）。**鼻当ては5〜10cm、T字/Y字** | **顔は全開** | **頭頂を1px尖らせる＋顔中央に縦1pxの暗線** |
| **グレートヘルム** | **平頂の鋼製円筒**。頭部を完全に覆い**肩まで延びる**。1.5〜3kg | **視認スリット幅20〜30mm**。周辺視野と換気が劣悪。最初の槍合わせの後は外すことが多かった | **顔全面を単色で塗り、横1px×幅4pxの暗いスリット1本。目を描かない＝最強の記号** |
| **バシネット** | 頭頂が尖り、後方と側面が首を守るため下方に延びる。ヴァイザー3系統: クラップヴィジール（額中央1点ヒンジ）／**ピッグフェイス**（c.1380、銃口/くちばし状）／1430–40は類人猿状 | **アイスリットはフランジで囲まれ武器の先端を逸らす**。下端に**アヴェンテイル（鎖のカーテン）** | **頭頂1px尖り＋顔面を前に1px突出＋スリット2つを1pxずつ** |
| **サレット** | 側面が目の高さより下まで前方に引き出され頬を守る。**後部がフランジ状に外へ湾曲**。ドイツ式は長いテール | 初期はアイスリット、他は可動ハーフヴァイザー。**ベヴォア**（上胸部から鼻の直下まで）と併用 | **後頭部に2〜4pxのテール（斜め下後方）＋目の高さに横スリット** |
| **アーメット** | **4部品**: スカル／**前方で顎の上でロックする2枚の大型ヒンジ式チークピース**／二重ピボットのヴァイザー／**ロンデル**。「この時代で初めて頭部を完全に密閉しながらコンパクト」 | ヴァイザーの開口。**チークピースが横に開く**（クローズヘルムは可動ベヴォアが縦に開く） | **顔全面を覆い、頬に縦1pxの分割線を左右対称に** |
| **兜（カブト）** | 5要素: **鉢**（ラメラー構造の椀）／**腰巻**（周縁板、構造上最重要）／**𩊱（しころ）**（lacesで結ばれた平行板の連続＝首の防具）／**吹返**（𩊱の最上板がこめかみの高さで側面に外向きに折り返される）／**眉庇** | 顔は開放 | **左右に各2pxの吹返（水平の張り出し）＋後頭部に𩊱として3〜4pxの台形＋前立1〜3px**。16pxでも成立 |

- **支持**: 大半は**頭頂**（内部パッド）。ナサルヘルムは**顎紐で固定**（鼻当ての重みによる前傾を防ぐ）。**グレートヘルムは肩でも支える**。後期バシネットは**プレートゴーゲットで荷重を肩に移す**
- **追従**: **頭部と完全に同時**。ただし**アヴェンテイル／𩊱は布・鎖として遅れる**——「金属だが揺れる」唯一の部位。剛性の兜と併置すると質感差が強く出る
- **外すと**: 目を残したまま兜を描くと**帽子**。スリットを外すと**フルフェイスの仮面**。カブトの吹返を外すと**ただの丸兜**。𩊱を外すと**首なし**

### B-3. 板金鎧の関節部

| 部位 | 構造 【確】 |
|---|---|
| **ポールドロン（肩）** | 肩を覆う**単一の大きなドーム状部品（コップ）に複数のラメ**。肩関節を大きく越え「**脇の下、時には背中と胸の一部を覆う**」。**非対称**——イタリア式は右（槍腕）側にランスレストの切り欠き、反対側は覆いを減らして可動性確保 |
| **クーター（肘）** | **中央の肘カップ（打撃を逸らす円板）**＋**上下のラメ**。ラメは屋根瓦のように動作中スケール。**スライディングリベット**が「屈曲時に前方・外方への遊びを与える」、**固定リベット**が非可動端を留める。ヒンジは**尺骨の自然な軌道に沿わせる**。無負荷なら**180°まで伸展可能** |
| **ポレイン（膝）** | **c.1230年に登場、最初期の板金部品の一つ**。初期はメイル・ショースの上にストラップ留め。15世紀にキュイスとグリーヴに接続する関節構造を獲得。15世紀後期ゴシック式は**膝の側面を守るサイドウィング** |

**★鎧は布と違って追従しない — 動きの表現がどう変わるか**

| 項目 | 実測 【確】 |
|---|---|
| フルハーネス重量 | **20〜25kg**。荷重は「脱中心化」され各鋼片が四肢に個別ストラップ留め |
| 歩行のエネルギーコスト | **素の2.1〜2.3倍**（走行1.9倍）。**同重量のバックパックより高コスト**（脚に約8kgの鋼） |
| 最大歩行速度 | **5.5 ft/s**（非装甲8.8 ft/s）＝**約0.63倍** |

**帰結**【推】: (1) **遅延コマがゼロ**——全パーツが同一コマで動く (2) **歩幅を縮め、コマ数を増やす** (3) **上下動を1px以下に抑える**（重量が沈み込みを殺す） (4) 揺れの代替として**ハイライトの位置を1pxずつ移動**させる (5) 布との対比を作りたければ**アヴェンテイル／フォールド／タセットだけを遅らせる**

**32pxの最小表現**【推】: 肩に**2×2pxの明色ブロック**、肘位置に**1×1pxの明色ドット**、膝位置に**1×1pxの明色ドット**。この「**肩2px・肘1px・膝1px の3点ハイライトだけで板金鎧が読める**」
**外すと**: 肩の2pxを外すと**鎖鎧／革鎧**。肘膝のドットを外すと**全身タイツ**。逆に**遅延コマを付けると鎧がゴムに見える**（最も致命的）

## C. 装身具

### C-1. 王冠 【確】

| 種類 | 構造 |
|---|---|
| **ダイアデム** | 上位概念。ギリシャ語「巻き付ける」由来。**王冠・ティアラ・コロネットはすべてこの範疇** |
| **サークレット** | 「王冠またはコロネットの**基部**」。**アーチのない開冠**もサークレットと呼ぶ。インペリアル・ステート・クラウンは**アーチが着脱式** |
| **オープンクラウン（開冠）** | **完全な円環で頂部が空に開く**。**最古の様式** |
| **クローズド／アーチドクラウン** | **頭上を横切るアーチ**を持つ。高いアーチは「**神以外の誰にも従わない主権の象徴**」 |
| **コロネット** | 貴族用の小型冠。**爵位ごとに異なるデザイン**。紋章上での使用が多い |
| **ティアラ** | 「**開いた半円形で、通常は頭を一周せず頭頂に載る**」。装飾要素は前方の弧に沿う |

**セント・エドワード王冠の実測**: **高さ30cm、重量2.23kg**。**フルール・ド・リス4個とクロス・パテ4個が交互**に基部バンドに立つ。**アーチ2本**、頂部に**モンド（球）とクロス・パテ**。紫のベルベットキャップ＋アーミンの縁取り。**宝石444個**。個々の配置パターンは【未】

- **支持**: **額または頭頂**。開冠・閉冠は頭部を一周するため側頭・後頭でも保持。**ティアラは頭頂に「載る」だけ**で一周しない——構造上の決定的差
- **高さの比率**【算】: 30cm は8頭身175cm人体の頭部（約21.9cm）の**約1.37倍**＝**閉冠の全高は頭部より高い**。開冠・サークレットは**頭高の1割程度**
- **追従**: **頭部と完全に同時**（剛体）。垂れ下がるペンダント宝石のみ遅れる
- **32pxの最小表現**【推】:
  - **サークレット**: 額に**幅6〜7px・高さ1pxの明黄ライン＋中央1pxの宝石色**。**16pxでも成立**、最も安価
  - **オープンクラウン**: 高さ2〜3px、上端に**1px上へ突き出す歯を3個**（左右+中央、間隔1px）
  - **クローズドクラウン**: 高さ4〜5px。開冠の上に**1pxの弧＋頂点に1×1pxのドット**。この**頂点の孤立1pxが閉冠の唯一の識別子**
  - **ティアラ**: 額の上に、幅を頭部より1〜2px狭く、**中央だけ1〜2px高い三角**。**側頭でラインを切る**（後頭部に回さない）ことで一周しないことを示す
  - 宝石は32pxで1px、48pxで2×2px。**数は3個（中央+左右）が上限**
- **外すと**: 歯を外すと**ヘアバンド／鉢巻**。頂点のモンドを外すと開冠と区別できない。頭部より幅を広くすると**帽子**。頭高の半分超だと**司教冠／ピエロ帽**

### C-2. アクセサリー 【確】

| 品目 | 着用位置と構造 |
|---|---|
| **ブローチ／フィビュラ** | 衣服の留め具。マント用は**円形ブローチ**。マントルは前面中央をコード or 2つのブローチ、または大型宝石入り1個。**位置は「首の下・中央」または「片肩」** |
| **ベルト／バックル** | 全階級に共通する必需品。「**鉄のバックル付きの単純な革ベルト**」。用途は衣服の固定と「**ナイフや小袋などの小物の携行**」→ **ベルトには必ず何かが下がっている**のが史実的 |
| 指輪・ネックレス | 日常用の簡素なものと貴金属・宝石の儀礼用の両方。**イヤリングの普及度は【未】** |
| 材質による階級差 | 貴族は金・銀・宝石、庶民は革・鉄・単純な織物。**贅沢禁止法**がアクセスを制限 |

**★小サイズで読ませる技術**【推】——**「形」ではなく「孤立した高輝度1px」として読ませる**

| 品目 | 32pxでの表現 | 可否 |
|---|---|---|
| **ブローチ** | 首下中央に**1×1pxの明色ドット** | **最もコスト効率が高い**。1pxでマントの支点と装飾を同時に示せる |
| **ベルトバックル** | ウエストに幅5〜7px・高さ1〜2pxの暗色帯＋**中央に1×1pxの明色** | **16pxでも成立** |
| 腕輪 | 手首位置に1px幅の横線（明色）。上腕なら肩の下2px | ポールドロンとの混同を避けるため明度を落とす |
| ネックレス | 首の下1px列に1〜3pxの明色＋その下に1×1pxのペンダント | 16pxでは襟と区別不能なので**避ける** |
| イヤリング | — | **48px以下では原則不可**（輪郭のノイズになる） |
| 指輪 | 手の1pxに宝石の色を乗せるのが唯一の手段 | **48pxでも不可** |

**原則**: 周囲を暗くしてコントラストを作らないと消える。アクセサリーには**専用の1色（金＝明黄）**を割り当てる。
**外すと**: ベルトの中央1pxを外すと**帯／サッシュ**。ブローチの1pxを外すとマントが**背中の板**に戻る。ベルトから何も下げないと**装飾ベルト**（冒険者に見えない）

## D. 素肌

| 項目 | 内容 |
|---|---|
| **構造的事実** 【確】 | **フルプレートでは素肌の露出はほぼゼロ**。板金の隙間には**ヴォイダー（脇の下のメイル）＋メイルスカート（股と腰）**。**前腕はヴァンブレイス、脛はグリーヴ**で常に覆われる。**13〜15世紀の平服ではホーズが腰から足まで覆う**ため**脛の露出は平服では標準的でない** |
| **顔が開放される兜** | ノルマン兜／サレット（ベヴォアなし）／カブト（面頬なし） |
| **追従** | **本体と完全に同時、遅延ゼロ**。布とも金属とも異なるのは**変形する**点だが、16〜48pxでは変形は表現不能 |

**32pxの最小表現**【推】

| 部位 | px |
|---|---|
| 顔 | 頭部10〜12px、**目は2×2px＋ハイライト1点**（16pxでは1×1〜1×2px） |
| **首** | **幅2〜3px・高さ1〜2px**。首を0pxにすると胴と頭が直結し**兜／フードと区別できない**。**素肌の首1〜2pxは「防具を着ていない」ことの最小の証拠** |
| 手 | 2×2px（16pxで1×1px） |
| **前腕** | 幅2px・長さ3〜4px。**ここに肌色を置くか布色を置くかで軽装／重装が切り替わる**＝32pxで前腕2×3px=6pxが軽重の識別領域 |
| 脛 | 幅2〜3px・長さ4〜5px |
| 筋肉 | **32px以下では不可**。48pxで上腕の外側に1pxの明色・内側に1pxの暗色が限界。腹筋・胸筋の分割は48pxでも避ける |

**外すと**: 首の1〜2pxを外すと**フルヘルム／頭巾**。前腕の肌色を外すと**長袖／ガントレット**。手の2pxを外すと**袖に手が隠れた状態**（魔法使いには有効、戦士には不可）。**露出を増やしすぎると防具の存在が読めなくなる**——鎧の3点ハイライト（肩2px・肘1px・膝1px）と露出領域は**排他的関係**

【未】肌の露出量が与える印象の実証的記述 / ドット絵における筋肉表現の具体指標
