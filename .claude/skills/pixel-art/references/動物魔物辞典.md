## A. 四足獣の骨格と関節

### A-1. ★前肢／後肢の関節対応（最重要の誤解ポイント）【確】

| 部位 | 四足獣 | ヒト相当 | 骨 |
|---|---|---|---|
| 前肢・上 | 肩 | 肩 | 肩甲骨＋上腕骨 |
| 前肢・中 | **肘** | **肘** | 上腕骨↔橈骨＋尺骨 |
| 前肢・下 | **手根（carpus）＝「膝」に見える所** | **手首** | 手根骨 |
| 前肢・足 | 中手骨＋指骨（＝掌） | 手のひら＋指 | 中手骨・指骨 |
| 後肢・上 | 股 | 股 | 大腿骨 |
| 後肢・中 | **膝（stifle／膝蓋骨あり）** | **膝** | 大腿骨↔脛骨＋腓骨＋膝蓋骨 |
| 後肢・下 | **飛節（hock／tarsus）＝「後ろ向きの膝」に見える所** | **足首＋踵** | 踵骨・距骨・中央足根骨ほか |
| 後肢・足 | 中足骨＋趾骨 | 足の甲＋指 | 中足骨・趾骨 |

**誤解の正体**（複数出典で一致）:
- 飛節は「**ヒト足首の相同器官（anatomical homologue of the ankle）**」。膝ではない
- 「**後ろ向きに曲がる膝を持つ動物は実際には存在しない。アーティストはしばしば足首を膝と誤認する**」
- 「**それらは確かに足首であり、膝は実際には前方に曲がる**」
- **真の膝が見えない理由**: 「**肘と膝は腹のラインに埋まっている**ので、胴の下の空間ではこれらの関節が見えない」

### A-3. 趾行性・蹄行性・蹠行性 【確】

| 型 | 接地部位 | 手首／踵の高さ | 該当動物 |
|---|---|---|---|
| **蹠行性 plantigrade** | 足底全部（踵含む） | 手首＝地面レベル | ヒト、**クマ**、アライグマ、ネズミ、イタチ、サル |
| **趾行性 digitigrade** | 趾＋肉球（踵は空中） | 手首＝地面より少し上 | **イヌ、ネコ**、鳥、ハイエナ、マングース、恐竜 |
| 半趾行性 | — | — | ブタ、カバ、ゾウ、カピバラ |
| **蹄行性 unguligrade** | 爪／蹄の先端のみ | **手首＝肘と蹄の中間** | **ウマ**、シカ、ウシ、ガゼル |

- 趾行性は「**手根骨・足根骨が延長**」して足首が高い位置に上がり「効果的に足を延長」→「**犬脚の特徴的なフック形状**」
- 機能差: 蹠行性は安定性、蹄行性はパワー産生に優れる。趾行性は「**generally move more quickly**」

**★ドット絵での帰結**: **立ち姿の「脚の折れ点の数」が変わる**
- 蹠行性＝2折れ（膝・踵が両方低い、脚が短く見える）
- 趾行性＝3折れ（飛節が中間高、脚が長い）
- 蹄行性＝3折れだが**飛節がさらに高く、下部が長い1本棒**

### A-4. 背骨のしなり 【確】

| 項目 | 数値 |
|---|---|
| 走行時に屈曲する関節数 | 仙骨前椎間関節 **6〜8個** |
| 振幅の分布 | 尾方（仙骨側）へ増大、**最終仙骨前関節(PS1)が最大** |
| PS1の実効角運動（立脚期） | ツパイ・カワリオポッサム **17〜22°**、ナキウサギ 7〜8° |
| 骨盤の実効角運動（立脚期） | **29〜44°** |
| 骨盤の遊脚期振幅 | **40〜51°** |
| 最大屈曲のタイミング | 遊脚期の最後1/3〜接地の間 |
| 最大伸展のタイミング | 離地後、遊脚期の最初1/3 |

**★ギャロップの2種の空中相**（チーター／グレイハウンド、回転ギャロップ）
- **gathered flight（収縮空中相）**: 四肢が体下・正中に寄る＝**背骨は屈曲**
- **extended flight（伸展空中相）**: 四肢が外へ伸びる＝**背骨は伸展**

チーター29 m/s、ストライド頻度最大 **4.0 Hz**。18 m/s時、チーターは**体重の70%を後肢**で支持（グレイハウンド62%）。

## B. 歩容（gait）

### B-1. 接地順（footfall sequence）【確】

`LH=左後 LF=左前 RH=右後 RF=右前`

| 歩容 | 拍数 | 接地順 | 空中相 |
|---|---|---|---|
| **walk（常歩・側対歩列）** | 4 | **LH → LF → RH → RF** | なし |
| walk（対角歩列＝霊長類型） | 4 | LH → RF → RH → LF | なし |
| amble | 4 | LH → LF → RH → RF（タイミング違い） | なし |
| **trot（速歩）** | 2 | **LH+RF → 空中 → RH+LF → 空中** | 2回 |
| **pace（側対速歩）** | 2 | **LH+LF → 空中 → RH+RF → 空中** | 2回 |
| **canter（駆歩・右手前）** | 3 | **LH → (RH+LF) → RF → 空中** | 1回 |
| **transverse gallop** | 4 | **LH → RH → LF → RF** | 1回 |
| **rotary gallop** | 4 | **RH → LH →〈伸展空中相〉→ LF → RF →〈収縮空中相〉** | **2回** |
| bound | 2 | 前肢ペア ↔ 後肢ペア同時 | 有 |

- walkの支持パターン: 1ストライドで**8通りの支持組合せ**＝3本支持4回と2本支持4回が交互
- **回転ギャロップはイヌ／食肉類の最速歩容**で「最も速いが最も疲れる」。斜対襲歩はウマ・ウシの主力
- Hildebrandの指標: **diagonality D**（左後が左前に先行する周期の%）、**duty factor S**（**S>50%=walk / S<50%=run**）
  - 側対歩列 0<D<50 / 対角歩列 50<D<100
  - ウマ・ネコ・イヌ・哺乳類の大半＝**側対歩列walk**、霊長類・樹上性有袋類＝**対角歩列walk**

### B-2. デューティファクターとアニメ用位相 【確】

| 歩容 | duty factor | 同時接地本数 | 位相オフセット（4脚） |
|---|---|---|---|
| **walk** | **0.6〜0.8** | **3本**（一瞬2本） | **0.0 / 0.25 / 0.5 / 0.75** |
| **trot** | **<0.4** | 2本（対角ペア） | **0.0 / 0.5 / 0.5 / 0.0** |
| **pace** | trot同程度 | 2本（同側ペア） | **0.0 / 0.0 / 0.5 / 0.5** |
| canter | — | 1→2→1本 | 0.0 / 0.7 / 0.3 / 0.0 |
| transverse gallop | — | 1本ずつ→空中 | 0.0 / 0.5 / 0.1 / 0.6 |
| rotary gallop | — | 1本ずつ→空中×2 | 0.0 / 0.6 / 0.1 / 0.5 |
| bound | — | 前ペア／後ペア | 0.0 / 0.5 / 0.0 / 0.5 |

実測（ハイイログマ）: walk **0.76** / running walk **0.63** / canter **0.37**

### B-3. 動物ごとの得意歩容 【確】

| 動物 | 常用歩容 | 特記 |
|---|---|---|
| **ネコ** | 側対歩列walk、trot、回転ギャロップ | **direct registering**＝後足が同側前足の足跡にほぼ正確に着地。ライオン・トラで顕著 |
| **イヌ／オオカミ** | 側対歩列walk、trot（巡航）、**回転ギャロップ（最速）** | 長脚犬種のみpaceも可 |
| **ウマ** | walk / trot / pace / canter / transverse gallop | trot平均 約13 km/h、繋駕競走で >53 km/h |
| **クマ（蹠行性）** | walk → running walk → canter。**trotしない** | 移行速度: walk→running walk が2.0 m/s超、running walk→canter が約3.0 m/s超。体重配分 **前肢54〜60% / 後肢40〜46%** |
| ラクダ | walk、**pace** | ビクーニャはpaceしない |
| **キリン** | walk、gallop。**paceもtrotもしない** | 通説（キリンは側対歩）と食い違う |
| ゾウ | walk、running walk のみ | ギャロップなし |
| カバ | walk、trot | 重量ゆえギャロップ不可 |
| チーター | 低速でgallop、**高速でbound** | — |
| ウサギ・リス・トビネズミ | **bound専門**（背骨が柔軟） | — |

**trotできる条件**: 「**前後肢の長さがほぼ同じ＋背骨がまっすぐ**」。後肢が極端に発達した種はtrotしない（キリン、ブチハイエナ、クマ、類人猿、サル）

### B-4. ★4〜8コマへの圧縮

4つの基本キーポーズ（人間歩行と同じ）: **contact（最低）→ down → pass（最高）→ up/swing**

コマ数の性質【確】: **4コマ**＝最重要キーのみ／単体ではやや物足りない。**6コマ**＝経済性と滑らかさのちょうど良い中間。**8コマ**＝最も滑らか

**四足への圧縮ルール**【推】

| 歩容 | 推奨コマ | 理由 |
|---|---|---|
| **walk** | **8コマ** | 位相が0/0.25/0.5/0.75で1脚1コマずつ接地イベントが来る。**4コマにすると4本の接地が全部キーになり中間が消える**＝接地順は読めるが弾力が消える |
| **trot** | **4コマで完結** | 対角2ペアしか状態がない。`対角A接地／空中／対角B接地／空中`。**最小コマで最も正しく見える歩容＝trot** |
| **pace** | 4コマ | ただし**左右ロールを1px入れないとtrotと区別できない** |
| **gallop** | **6コマ** | `後肢1／後肢2蹴り／伸展空中（背伸ばし・脚を前後に開く）／前肢1／前肢2／収縮空中（背丸め・脚を体下に集める）`。**2つの空中相を必ず両方入れる**のが識別点 |
| canter | 6コマ | 3拍＋空中を2コマで |

## C. 鳥・爬虫類・蛇・蜘蛛・蝙蝠

### C-1. 鳥 【確】

| 項目 | 内容 |
|---|---|
| **膝** | 大腿骨↔脛足骨の関節。「**前を向いているが羽毛の中に隠れている**」 |
| **外から見える後ろ向き関節** | **足首＝足根／足根間関節**。脛足骨↔足根中足骨 |
| **足根中足骨** | 「**鳥類固有の第3脚セグメント**」。足根骨遠位＋中足骨II/III/IVの融合 |
| 大腿骨 | 体の羽毛内にほぼ隠れる |
| 姿勢 | **趾行性** |

**羽ばたき周期（実測Hz）**: 推定式 `f = 1.08 · (m^0.5 · g^0.5 · b^(−2/3) · S^(−1/4) · ρ^(−1/3))`（32種・20g〜約5kg、相関 r=0.947）

ニシツノメドリ **9.18** / オオハシウミガラス 9.08 / ミドリツバメ 8.72 / オオトウゾクカモメ 3.93 / ミツユビカモメ 3.18 / オオカモメ **2.90** Hz → **小型ほど高頻度**

ハト翼の自由度: **肩3・肘1・手首2**、運動パラメータは flapping / sweeping / twisting / folding / bending の5種

### C-2. 爬虫類の sprawling posture 【確】

四肢が体側に張り出し、**体幹の左右うねりと四肢運動が協調**する。

**トラフサンショウウオの実測**（円平均）

| 項目 | 値 |
|---|---|
| **肘角** | 円平均 **109〜122°**（範囲 60〜209°） |
| **膝角** | 円平均 **237〜238°**（範囲 186〜285°） |
| 体幹曲率 κ（自由） | 0.043〜0.052 |
| **尾の曲率（自由）** | 0.044〜0.054 |
| **尾の曲率（体幹を拘束時）** | **0.064〜0.081** ＝体幹が曲げられないと**尾が代償して大きく振れる** |

→ 爬虫類は「脚の可動域が非常に広い（膝で約100°幅）」かつ「**胴と尾が逆位相にSカーブを描く**」
【未】トカゲ・ゲッコーの体幹側屈の度数

### C-3. 蛇の移動様式（5種）【確】

| 様式 | 力学 | 摩擦 | 筋活動 | 使う場面 |
|---|---|---|---|---|
| **lateral undulation（蛇行）** | 屈曲波が**頭→尾**へ伝播。複数の突起を同時に押す。各体節は**頭が通った軌跡をたどる**（列車の客車のように） | 滑り | 背側筋が**順次・片側性** | 一般的な蛇行 |
| **sidewinding（横這い）** | 蛇行と類似だが①**静止摩擦** ②接地帯の間で**体が浮く** ③**軌跡に対して斜めに進む** | 静止 | — | 砂漠・滑る面 |
| **concertina（蛇腹）** | 体を交互に**束ねて曲げ→そこから前へ伸ばす** | 静止 | 屈曲域の筋ブロックが**同時・片側性** | トンネル・狭所・登攀 |
| **rectilinear（直進）** | 腹板を「**交互にわずかに持ち上げて前へ引き、次に下へ・後ろへ引く**」 | 静止 | **両側性収縮**（蛇行と逆） | 大型クサリヘビ・ボア・ニシキヘビ |
| slide-pushing | 不規則な激しいうねりで滑る | 主に滑り | — | 驚いた蛇の緊急逃走 |

### C-4. 蜘蛛の8脚パターン 【確】

**タランチュラ**: 「**左右対称位置の脚どうし、および前後に隣接する脚どうしは逆位相**」。位相のばらつきが大きく多様な歩容が生じるが、**そのばらつきは概ね速度と相関しない**。昆虫用モデル（交替三脚）は**タランチュラには不適合**

***Cupiennius salei*（走行時）**: 厳密な alternating tetrapod では**ない**。「**metachronal wave（後方から前方への進行波）モデル**」
- 結合度: 第1脚と第2脚 **0.54**、第3脚と第4脚 **0.88**、前群と後群の間は低い
- **duty factor**: 第1・2・4脚は0.5未満／**第3脚はほとんど0.5を下回らない＝第3脚が主要な支持脚**
- ストライド頻度（最大速 約0.6 m/s）: 全体 5〜8 s⁻¹

→ **ドット絵での帰結**: 蜘蛛は「4脚同時パカパカ」ではなく**後ろから前へ波が流れる＋第3脚だけほぼ常時接地**。片側4脚を「**後→前へ1pxずつ順にずらす**」だけでクモらしくなる
【未】脚位相の正確な分数値

## D. 想像上の生物とアンデッド

### D-1. ★6肢問題とドラゴンの骨格 【確】

**脊椎動物の四肢動物ボディプランに6肢の前例は無い。** 鳥・コウモリ・翼竜はすべて**前肢を翼に転用**している。「真の6肢を認めるなら、ドラゴンは脊椎動物とは全く別の生物カテゴリだと受け入れることになる」

| 解法 | 構造 | 整合性 | 元ネタ |
|---|---|---|---|
| **① ワイバーン／コウモリ型（前肢＝翼）** | 翼2＋後肢2の**計4肢**。翼をたたんで手首・中手骨で地面を突き**ナックル歩行** | **最も整合的** | *Dragonslayer*(1981)。**Rhamphorhynchus（翼竜）**の化石を参照して設計 |
| ② 翼竜型・四足歩行 | たたんだ翼が**そのまま前肢として体重を支える** | 化石証拠あり（**基盤的・派生的双方の翼竜に四足陸上歩行のトラックウェイ**） | 翼竜可動域研究 |
| ③ 真の6肢（古典ドラゴン） | 4脚＋独立した翼2 | 脊椎動物では不可。別系統として設定が必要 | Tolkienのスマウグ図 |
| ④ 6肢の進化的説明（思考実験） | **中間の1対を翼に**すると重心近くで空力的に安定 | 仮説 | Furaha |

**翼竜の可動域データ**（中型オルニトケイルス類）【確】

| 部位 | 骨学的可動域 | 代表姿勢 |
|---|---|---|
| 肩帯／上腕骨 | 591,522姿勢中 **20,308が可能** | 外転25°・伸展70°・長軸回転 −135° |
| 骨盤／大腿骨 | 197,174姿勢中 **26,406が可能** | 外転15°・屈曲45°・長軸回転100° |

補足: 筋の40%伸展を許すと両方の離陸シークエンスが完全に可能に。**二足離陸は大腿骨をさらに10°外転**しないと不可。四足離陸は骨学的可動域内で可能

**グリフォン**: ワシ前半＋ライオン後半。**大胸筋が胸部を支配して「深い胸」のシルエット**を作る＝飛行筋の付着部（竜骨突起／胸骨）が必須。首の筋は「ワニ類・獣脚類の頸筋」を参照。【未】グリフォン骨格の一次資料（robots.txtで取得不可）

**設計原則**: ファンタジー要素は1つ（例：火吹き）に絞り、骨・筋・呼吸は「plausible biological rules」で組む

### D-2. ★ゾンビの歩き方 — 病的歩行との対応 【確】

**トロープ**: 「**両腕を前に出してすり足で歩く**」＋「**手はぐったり垂れる**」。腕は前にまっすぐ・硬直し**振れない**。起源は *Das Cabinet des Dr. Caligari*(1920) → Romero *Night of the Living Dead*(1968) → *Thriller*

| ゾンビの特徴 | 対応する病的歩行 | 医学的記述 |
|---|---|---|
| **すり足・小刻み・歩幅が短い** | **パーキンソン歩行** | 「reduced stride length with short steps」。歩幅が漸減する **festinant gait** |
| **腕が振れない／垂れる** | パーキンソン歩行 | 「**reduced arm swing on one or both sides**」＝早期徴候 |
| **前かがみ・首が前に落ちる** | パーキンソン歩行 | 「flexed trunk and neck causing a stooped appearance」 |
| **片側の脚が硬直して引きずられる・半円を描いて回る** | **痙性／片麻痺歩行** | 脚が機能的に長くなるため「**circumduct（分回し）**」。**足首は底屈固定＋膝は伸展固定**。「one stiff leg that drags or swings around in a semicircular motion」 |
| **腕が屈曲して固まる（前に突き出す）** | 痙性上肢／両麻痺歩行 | 「**flexor posturing of the elbows and wrists**、肩と指は内転」。四肢は「typically lack the swinging movements」 |
| **膝がぶつかり脚が交差する** | **はさみ足歩行** | 内転筋の痙性で「knees are forced together → leg overlap when walking」 |
| **つま先が地面を擦る／足がぶらぶら垂れる／不自然に膝を高く上げる** | **下垂足・steppage gait** | 「foot drop and **dragging of the toes during the swing phase**」→「the knee and hip flex excessively, creating a **high stepping gait**」 |
| **ふらつく・広い歩隔・よろめく** | **失調性歩行** | 「**broad-based**」「staggering, slow and unsteady」。**方向転換が特に困難** |
| **腰が左右に落ちて上体が横に振れる** | **トレンデレンブルグ／動揺歩行** | 「pelvis tilts downwards **towards the unsupported side** during swing phase」＋「laterally flexing the torso **away from** the leg in swing phase」 |
| 手足がのたうつ不随意運動 | 舞踏病様歩行 | 「writhing, dance like semi-purposeful movements」 |
| 上体が前後にガクンと揺れる長いストライド | lurching gait | 「slow and long stride」＋「upper body can jerk forward or backward」 |

**★パーキンソン歩行の実測値（患者OFF期 vs 健常）**【確】——「どれだけ縮めるか」の根拠

| 指標 | PD患者 | 健常者 | 比 |
|---|---|---|---|
| **ストライド長** | 0.83〜0.87 m | 1.16〜1.18 m | **約0.72倍** |
| **歩行速度** | 0.70 m/s | 0.94 m/s | 約0.74倍 |
| **ケイデンス** | 50.92 歩/分 | 51.91 歩/分 | **ほぼ同じ** |
| **足首背屈角** | 7.07〜7.45° | 19.85〜19.91° | **約0.37倍** |
| 足のクリアランス | 0.14〜0.17 m | 0.19 m | 約0.79倍 |

> **★重要な設計知見**: ケイデンス（歩数／分）は**ほぼ変わらず、歩幅と足の持ち上げだけが縮む**。
> つまりゾンビは「**コマ数・テンポは普通のまま、移動距離と足上げ量を約0.7〜0.75倍に縮める**」だけで成立する。
> **フレームレートを落とすのではなく振幅を落とす**のが医学的に正しい。

### D-3. 骸骨 — 筋肉なしで動く矛盾 【確】

- **原理的解決**は「必要な機能魔法を降霊術師が使っている」という前提。生理学的説明は放棄されるのが慣習
- **視覚的代替**: 生体系の欠如を**光る眼**で補う
- **構造的整合**: バラバラにされても「**pull themselves back together**」＝再組立て可能な緩い連結

**Harryhausen『アルゴ探検隊の大冒険』1963 の実データ**

| 項目 | 数値 |
|---|---|
| フレームレート | 24 fps |
| 遅い日の進捗 | **1日13フレーム**（約0.5秒分） |
| 1フレーム移動量 | 約0.5 mm |
| 同時同期対象 | 骸骨7体×可動部5＝**35の動きを1フレームごとに同期** |
| 制作期間 | 4.5ヶ月 |
| 狙った質感 | 滑らかなリアリズムではなく「**nightmare quality**」＝超現実 |

→ **慣習の要約**: ストップモーション固有の**ステップした（等速・非イージング）動き**そのものが「筋肉に駆動されていない」記号として機能する。したがって骸骨は**イーズイン／イーズアウトを意図的に外し、等速で動かす**。関節に**1pxの隙間**を空ける

## E. 16〜32pxへの落とし込み

### E-1. コマ数とタイミング 【確】

| サイズ | walk | run | idle | jump | attack | death | hit |
|---|---|---|---|---|---|---|---|
| **16×16** | **4コマ**（最大4〜6） | 4〜6 | 2 | 3 | 3 | 4 | 2 |
| **32×32** | **6〜8コマ** | 6〜8 | 2〜4 | 3〜5 | 3〜6 | 4〜6 | 2〜3 |

- **16×16では4〜6コマが上限**: 「pixel limitations prevent meaningful visual differences」
- 1コマの表示時間: walk **80〜150ms** / run 50〜80 / idle 400〜800 / 攻撃は非等速（溜め120〜200・打撃30〜60・戻り80〜150）
- 鉄則: 「**Four well-timed frames will always look better than twelve frames at uniform speed**」

### E-2. 何を残し、何を捨てるか

**残す**

| 優先 | 要素 | 実装 |
|---|---|---|
| 1 | **飛節（後ろ向きの頂点）の位置** | 蠅行性／趾行性／蹄行性を分ける唯一の輪郭情報。**16pxでも後肢は「Z」、前肢は「く」**。膝と肘は腹のラインに埋めて描かない |
| 2 | **接地脚のペアリング** | trot＝対角ペア／pace＝同側ペア／walk＝4本ずらし。**16pxで歩容を伝える情報の9割はこれ** |
| 3 | **胴の上下1〜2px** | pass時に最高、contact時に最低 |
| 4 | **ギャロップの2つの空中相** | 伸展／収縮。**この2枚が無いとギャロップに見えない** |
| 5 | 蛇＝波の位相、蜘蛛＝後→前の波 | 脚や体節を1pxずつ順にずらすだけ |

**捨てる**: 手根（前脚の「膝」）の屈曲／趾・指の分節／肩甲骨のスライド／背骨の**左右**うねり（爬虫類だけは残す）／関節可動域の度数の忠実さ（上表は**ポーズの限界チェック用**に使い、中間補間はpx単位に丸める）

### E-3. サイズ別レシピ

| サイズ | 四足獣の脚 | 推奨歩容 | コマ |
|---|---|---|---|
| **16×16** | 片側**2本**（前1・後1）のみ描く。奥側は1px暗色で示唆 | **trot（4コマで完結）** or 単純walk | **4** |
| 24×24 | 前2・後2の4本。奥側は1〜2pxずらす | walk / trot / gallop | 6 |
| **32×32** | 4本＋飛節の折れを明示 | walk 8 / trot 4 / gallop 6 / canter 6 | 6〜8 |
| 48×48 | 尾・耳・脊椎の屈曲も可 | 全歩容 | 8〜12 |

### E-4. ゾンビ／骸骨／ドラゴンの実装まとめ

- **ゾンビ**: コマ数・テンポは通常walkと同じ。**歩幅を約0.72倍、足の持ち上げを約0.79倍、足首背屈を約0.37倍**。片側だけ**膝を伸展固定して分回し**（1本の脚を曲げずに弧を描かせる）。腕は**振らない**。前かがみ1〜2px。**足先を常に下向き（底屈）で描く**
- **骸骨**: **イージングを外して等速**。関節に**1pxの隙間**。上下動は1pxのカタカタ。**光る眼を1〜2px**で入れて生体系の欠如を補償
- **ドラゴン**: 16〜32pxで6肢は描けない。**ワイバーン型（翼＝前肢、たたんだ翼の手首で接地）が最も安く、かつ生物学的に最も整合的**
