# 一般常識辞典（現実的イメージの辞典）

ドット絵専属ドッター Claude / 調査日 2026-08-10
対象：32×32 の見下ろし型キャラチップ（本件＝老魔導士・とんがり帽・白い長髭・全身ローブ・**左手**に杖）

---

## §0 なぜ「一般常識」が知識より上位なのか

依頼主の指摘：**「知識だけを付けても一般常識が欠如していたら無意味」**

これは順序の問題である。

| 層 | 内容 | 欠けたときの症状 |
|---|---|---|
| ① 一般常識・現実的イメージ | 帽子は頭に乗る／髭は口の周りに生える／手は向きが変われば位置も変わる | **見た人が「変だ」と即座に感じる。**理由は説明できないが全員が気づく |
| ② 専門知識 | 関節可動域、振り子周期、密度、質感の階調数 | 破綻はしないが「深みがない」 |
| ③ 技法 | 選択的アウトライン、ディザ、ランプ設計 | 「上手いが心に残らない」 |

①の破綻は②③をいくら積んでも救えない。実例（今回の指摘）：

- 後ろ向きで後頭部が真っ白に光っていた → 「後頭部は帽子のつばの下だから見えない」という常識の欠落
- 髭の老人が長髪だった → 「老人＝短髪・薄毛」という一般イメージの欠落
- 横を向いても髭が手前を向いていた → 「髭は口の周りに生えている」という常識の欠落
- 右を向いたら杖が背中から生えていた → 「向きが変われば手の位置も変わる」という常識の欠落

**だから作画の順序は「① 何を着て何を持って何処を向いているかを言葉で説明できる → ② 物理・解剖で裏を取る → ③ 技法で描く」。①を飛ばして③から入ると必ず破綻する。**

## §1 帽子（かぶりもの）の一般常識

### 1-1 部位名称
crown（山）／brim（つば）／sweatband（内側の汗止め＝頭に当たる部分）／hatband（外側の飾りリボン、つばの付け根）／brim binding（つばの縁取り）／pinch・crease（山の折り目。中折れ＝fedora）
出典 https://bernardhats.com/hat-faqs/hat-faqs-parts-of-a-hat/ ／ https://www.gentlemansgazette.com/men-hats-anatomy-vocabulary/

### 1-2 頭のどこに乗るか（実測値）
- 帽子サイズの採寸位置＝**耳の 1/8 inch（3mm）上**、**眉の 1/2 inch（13mm）上**。「ここに帽子が乗る」
- 正しい被り方＝「**眉と耳のすぐ上**、頭の一番幅の広いところに水平に乗る」
- 成人男性 M=56–57cm、L=58–59cm
出典 https://www.dapperfam.com/pages/hat-sizing-guide ／ https://www.lockhatters.com/blogs/news/how-should-a-fedora-hat-fit

→ **32px換算：つばの下端（ハットバンド）は眉の高さ＝顔の最上段。**本件は額 y13、つば y12 で一致。

### 1-3 つばの上げ下げ ─ 現実とゲームは逆になる（重要）

| | 前のつば | 後ろのつば |
|---|---|---|
| **現実の定番（snap brim / front snap）** | **下げる**（目に陰を作る） | **上げる**（後ろ姿をすっきり見せる） |
| **見下ろし型ゲームスプライト** | **上げる／薄くする**（下げると顔が消える） | **下がる**（前を上げた分が後ろに回る） |

現実の定番は「前下げ・後ろ上げ」で、**依頼主の言う向きとは逆**である。
> snap brim = "…the wearer can 'snap' it into multiple positions — most commonly **down in front and up in the back**" / Front snap (classic): "Brim down in front to shade the eyes; up in the back for a clean rear silhouette." 逆の back snap は "unusual but not wrong"
> https://bernardhats.com/hat-knowledge/hat-shapes/snap-brim/

**ただしスプライトでは依頼主の指示が正しい。**理由は2つあり、どちらも動かせない。

1. **顔を消せないという制約**：32pxでは顔は4行しかない。つばを前に下げると顔が0行になる。だから前は必ず上げる／薄くする。これはこのアプリの参考資料（Basic系・Player）でも例外なくそうなっている。
2. **剛体の幾何**：つばは1枚の円盤。前を持ち上げれば後ろは必ず下がる。前だけ上げて後ろも上げるのは物理的に不可能（つばが2枚必要）。

さらに見下ろしカメラ（30–45°）では、水平なつばでも後ろの縁が後頭部の投影より外に出るため、**後頭部は隠れる**（幾何からの導出。明示的にそう書いた出典は見つからなかった）。

**結論（採用ルール）：スプライトのつばは「前＝持ち上げ／後ろ＝沈む」の斜め1枚。現実の帽子屋の定番は逆だと知った上で、ゲーム側の理由で逆をやる。**

### 1-4 つばの実寸と32pxへの圧縮
- 実物のとんがり帽（型紙）：つば外径 **18 inch**／中心穴 **6 inch**／円錐の高さ **15 inch**
  https://charmpatterns.com/witch-hat-tutorial/
- → つばの張り出し＝(18−6)/2 = **6 inch ≒ 15cm**。頭長（男 200.5mm）の約 **0.7倍**が片側にはみ出す＝つば幅は頭幅の約 **2.9倍**（導出値）
- 32pxでは頭＝10px前後なので、canon通りなら つば 25–40px でセルに入らない。**実務上つばは頭幅の1.5–2倍に圧縮する**（本件 頭10px→つば13–14px＝1.35倍。さらに圧縮側）

### 1-5 つばは首を守らない（＝陰にはなるが暗くしすぎない根拠）
広つば帽の実測UV防護係数：**額15+／鼻7／耳6／頬2／首2**（レジオネアハットは首>4）
https://www.arpansa.gov.au/understanding-radiation/radiation-sources/more-radiation-sources/sun-protection-hats
→ つばの陰は額に最も強く、首（襟足）には**ほとんど落ちない**。襟足を真っ暗に塗るのは誤り。1段落とすだけでよい。

## §2 横顔（プロフィール）の一般常識

### 2-1 頭は正方形に収まる
> 「鼻先から後頭部までの幅は、頭頂から顎下までの高さと等しい」
https://bingedrawing.com/portrait/face-proportions/
→ **横顔の頭は縦横ほぼ同寸。**横顔だから細くする、は誤り（細くなるのは肩）。

### 2-2 耳は奥行きの中央
> 耳は「頭の横幅の中央、またはやや後ろ」で頭に付く
→ **頭の奥行きの約50%が耳より後ろ**にある。横顔で顔の造作は前半分に集中する。

### 2-3 高さの基準
- 目線＝頭の高さのちょうど 1/2
- 耳の上端＝眉、耳の下端＝鼻の付け根
- 横顔で「鼻の付け根→耳」＝「鼻の付け根→顎」（等距離）
- 横顔で「顎→耳」＝頭の高さの 1/2
https://anatomymasterclass.com/anatomy-video-lessons/human-head-proportions ／ https://lifedrawing.academy/life-drawing-academy-news/51-portrait-drawing-rules

### 2-4 鼻は必ず額より前に出る（横顔の最前点は鼻先）
- **鼻顔角（facial plane と鼻背の角度）＝男 34–38°／女 32–36°／平均約36°**
  https://www.qoves.com/insights/measurements/nasofacial-angle
- 30°以上あるということは、鼻背と鼻先は「額〜顎を結ぶ面」より**前に出ている**。平均的な成人の横顔で最も前に出ている点は鼻先。
- 鼻先の突出（Goode比）＝鼻背長の **0.55–0.60**
  https://www.otoscape.com/eponyms/goode-method.html

→ **32px換算：横顔は「額より鼻先を1px前へ」が必須。**出さないと平面のお面になる（今回1回目の失敗）。

### 2-5 男の鼻は下を向く。老人はさらに下がる
- 鼻唇角：**男 90–95°／女 95–115°** → 男の鼻先は下向き
- 加齢で軟骨が緩み **tip ptosis（鼻先下垂）**、上顎骨の吸収で支えが失われる → 鼻が長く見える
https://www.rhinologyonline.org/Rhinology_online_issues/manuscript_65.pdf ／ https://carolinafacialplasticsurgery.com/does-your-nose-grow-with-age/

→ 老人の横顔は「鼻先が目線より下に2px、下向き」で描くと年齢が出る。

### 2-6 32px 横顔 実装表（本件）
| 部位 | x | 根拠 |
|---|---|---|
| 鼻先（最前点） | x11（額より1px前） | §2-4 |
| 顔の前縁（額・頬） | x12 | |
| 目 | x14（前縁から2px内側） | 目は前半分 §2-2 |
| 頬〜顎の後縁 | x18 | |
| 襟足の髪 | x19（1px） | §3-7 馬蹄帯は耳の高さ以下 |
| つば後端 | x22 | §1-3 沈む |
| 髭の前縁 | x10（鼻より1px前） | §3-3 顎から前下へ垂れる |

## §3 髭と加齢の一般常識

### 3-1 髭はどこに生えるか（密度の実測：白人男性）
| 部位 | 密度 |
|---|---|
| 上唇（口ヒゲ） | **80–110 本/cm²** |
| 顎の中央 | **70–120 本/cm²** |
| 頬の上部 | 30–80 本/cm² |
| 頬の下部 | **20–40 本/cm²**（最も薄い） |
全体で 6,000–25,000本／約300cm²
https://www.keratin.com/hair-biology/beard-hair-biology-structure-density-growth-rate/

生える順序＝**上唇（口角から内側へ）→ 顎＋もみあげ → 頬 → 首**。最大量になるのは **30歳ごろ**。
https://www.keratin.com/hair-biology/beard-hair-development-an-in-depth-exploration/

### 3-2 だから髭は「口と顎」と一緒に回る（依頼主指示の精密化）
質量が乗っているのは**口ヒゲパッド（上唇）と顎**。頬は薄い。
→ 髭の塊は**下顎に固定**されており、**視覚的重心は顎先を追う**。
→ 顔が右を向けば口も顎も右を向く。**髭も右へ張り出す。**（依頼主の指摘どおり。さらに正確には「口」より「顎」を基準にすると重心がずれない）
→ 背面では髭は見えない。見えるのは**顎の外へはみ出した分のシルエットだけ**（本件は0＝見せない）。

### 3-3 白髭は伸びが2倍以上速い
- 有色の髭 **0.27–0.47 mm/日**、**白い（無色素）髭 1.12 mm/日**
- 髭の太さ 90–230µm（頭髪は80–120µm）＝**髭は頭髪より太い**。最大長 50–300mm
→ **老人の髭が長く・太く・ボリュームがあるのは実際に正しい。**32pxで髭を大きめに取る判断（依頼主に評価された点）はここで裏が取れた。

### 3-4 「禿げているのに髭は豊か」は生理学的に正しい
> アンドロゲンは**髭・腋・陰部の毛を促進**し、**前頭部の頭髪を抑制**する
https://www.ncbi.nlm.nih.gov/books/NBK278957/
→ 同じホルモンが逆方向に働く。**薄毛＋豊かな白髭は矛盾しない。むしろ定番。**

### 3-5 加齢と薄毛（ハミルトン・ノーウッド分類）
- 分類は **stage 1–7 ＋ type A 変種**。進行は「両側前頭部の後退 → 頭頂部のびまん性の薄毛」
  https://en.wikipedia.org/wiki/Hamilton%E2%80%93Norwood_scale
- 年代別（中等度以上）：**18–29歳 16%／30代 20%／40代 37%／50代 53%／60代 65%／70代以上 80%**
  https://www.myhairline.ai/blog/what-percentage-of-men-go-bald-by-what-age-statistics
- 50歳までに男性型脱毛を発症するのは 30–50%。頭頂部の脱毛は 40–55歳で31%、65–69歳で53%
  https://www.ncbi.nlm.nih.gov/books/NBK278957/

### 3-6 馬蹄形（horseshoe）の永久毛帯 ← 32pxで最重要
- 後頭部の毛はアンドロゲンに抵抗性がある（移植しても残る）
- 安全ドナー帯＝**耳から耳へ 25–30cm、高さ約 7cm の馬蹄形の帯**。中後頭部＋側頭下部
  https://charlesmedicalgroup.com/plastic-surgery/hair-transplant-safe-donor-zone-explained/

→ **絶対ルール：老人の髪は「耳の高さから下の帯」からしか生えない。頭頂から生やしたら一発で嘘になる。**
→ 本件の実装：背面は襟足6px（y15）のみ、横顔は襟足1px（x19,y15–16）のみ。頭頂部は帽子に隠れる＝矛盾しない。

### 3-7 白髪の「50-50-50ルール」は実測で誤り
- 通説：「50歳で人口の50%が50%白髪」
  https://donovanmedical.com/hair-blog/2011/12/26/hair-greying-and-the-50-50-50-rule.html
- **実測（Panhard et al., Br J Dermatol 2012, n=4,192, 世界規模）：50歳で50%白髪の人は 6–23% しかいない。45–65歳では74%に白髪があるが、平均の白髪率は 27%。男性は女性より白髪が多い。**
  https://pubmed.ncbi.nlm.nih.gov/22716034/

→ 「真っ白な髪＝老人」は現実の平均より誇張。だが**記号としては有効**（ドット絵は記号）。真っ白を使うなら「白髪率100%＝かなりの高齢」を意識して他の要素（薄毛・背中の丸まり・顔の陰）も高齢側に揃える。

### 3-8 「老人の長髪」について ─ 調査結果は「どちらとも言えない」
男性の平均的な髪の長さや長髪率を年代別に測ったデータは**見つからなかった**（検索結果はSEO記事のみ）。
生物学的には §3-6 の通り**馬蹄帯の毛は永久なので、頭頂が禿げて側頭・後頭だけ長い**という状態は成立する。

→ **結論：「老人＝短髪・薄毛」は一般イメージ（記号）としては依頼主の指摘通り正しく、統計的裏付けは取れていない。ドット絵では記号が優先されるので採用する。ただし守るべき本質は「量」ではなく「生える位置」＝頭頂から生やさないこと（§3-6）。**

## §4 杖を持って歩くときの一般常識

### 4-1 握る高さ
| 道具 | 握り位置 | 数値 |
|---|---|---|
| ステッキ（体重を預ける） | **手首（尺骨茎突）の高さ**。腕を垂らした状態 | 身長の約 **45%**（175cmで約79cm） |
| ハイキングスタッフ（長い杖） | **肘より 15–20cm 上** ＝ 胸〜みぞおち | 全長 115–135cm。柄はどこを握ってもよい |
- ステッキの採寸は「大腿骨大結節法」より「手首のしわ法」が正確（肘20–30°屈曲に入るのが 7.7% 対 **94.3%**）
  https://pubmed.ncbi.nlm.nih.gov/8540797/ ／ https://www.physio-pedia.com/Canes ／ https://www.walkingsticks.co.uk/blog/how-tall-should-a-hiking-staff-be.html

→ **魔導士の長い杖は「胸の高さで握る」が現実。**本件は手を y19–20（肘の高さ）に置いている＝ステッキ寄り。次回の改善候補：握りを1–2px上げて y18–19（胸高）にすると「長い杖を持っている」感が増す。※正面のコマは既に承認済みなので4方向の整合を崩さないこと。

### 4-2 突く側とタイミング
- ステッキは**健側（悪い脚の反対）**に持つ。杖 → 患側の脚 → 健側の脚 の順
- 交互歩調では「**対側の足と同時に突く**（右足＝左ポール）」＝**1歩に1回**。両手同時は急斜面だけ
  https://www.rei.com/learn/expert-advice/how-to-use-trekking-poles.html

→ 歩行3コマの杖は「毎コマ同じ場所で静止」が最も嘘。**接地は1歩1回、腕の前後振りに追従して動く。**

## §5 向きが変われば手の位置も変わる ─ 3系統の原則

物体は必ず次の3つのどれかに属する。**属する先が回れば一緒に回る。例外はない。**

| 系統 | 所属物 | 向きが変わったとき |
|---|---|---|
| **頭に固定** | 目・鼻・口・耳・**髭**・髪・帽子・眼鏡・角・傷 | **すべて頭と一緒に回る** |
| **胴に固定** | 襟・肩・胸当て・ベルト・マントの留め具 | 胴と一緒に回る（頭とは別に回る） |
| **手に持つ** | **杖**・剣・盾・カンテラ | **手に追従する。手の位置は向きで変わる** |

### 5-1 左手に持つ杖の4方向早見表（本件の確定仕様）

| 向き | 左手の位置 | 画面上の杖 | 前後関係 | 実装 |
|---|---|---|---|---|
| **下（正面）** | 画面**右** | 体の右外側 | 手前（体と同じ深度） | 通常トーン |
| **上（背面）** | 画面**左** | 体の左外側 | 手前 | 通常トーン |
| **左向き** | **手前側**（カメラ側） | 顔の前＝本来は顔を隠す位置。ゲームでは顔を隠さないので**位置は動かさず前面レイヤーへ** | **手前** | 体・つば・裾に**重なる**（F3で交差） |
| **右向き** | **奥側**（カメラの反対） | **顔の前（進行方向側）** | **奥** | **1段暗く**＋つばと裾の**後ろに隠れる** |

幾何の根拠：西を向いて立つと左手は南を指す。カメラが南にあるなら左手は**カメラ側**。東を向けば左手は北＝**カメラの反対側**。だから左右の横顔は**反転で流用できない**。

### 5-2 Ambidextrous Sprite（反転流用の罠）
- 名称 **Ambidextrous Sprite**。原因は「3Dモデルと違い、スプライトは回転できないので反転で済ませる」こと
- 影響：武器・アームキャノン・**眼帯**・傷・肩当て・タスキ・入れ墨・**文字（裏返る）**。ロックマンのアームキャノンが左右で持ち手が変わる／ストII のサガットの眼帯が反対側になる
- 対処4種：① **方向ごとに描く**（本件はこれ）② 左右対称のデザインにする ③ **持ち替えモーションを入れる** ④ 設定で正当化する
  https://tvtropes.org/pmwiki/pmwiki.php/Main/AmbidextrousSprite
- ドット絵実務でも同じ：通常は上・下・横1種で横は反転流用。ただし「**非対称のデザインを正しく見せたいなら4方向とも描く**」
  https://www.slynyrd.com/blog/2019/10/21/pixelblog-22-top-down-character-sprites

## §6 規格の一般常識（ツクール）

### 6-1 コマサイズ
| エンジン | 1コマ | 1キャラシート |
|---|---|---|
| **MV / MZ** | **48×48** | 144×192 |
| **VX / VX Ace** | **32×32** | **96×128** |
https://www.xehryn.com/tutorials/spritesheets ／ https://aispritegen.com/blog/rpg-maker-sprite-sheet-guide

→ **本件の 96×128 は VX/VX Ace の規格。**MV/MZ の既定は 48×48 なので「MZ準拠 96×128」という以前の記述は不正確だった（訂正済み）。
→ ただしファイル名を **`$` で始める**と1キャラシート扱いになり、コマサイズは画像サイズ÷(3列,4行) で自動決定されるので、**96×128 のままMV/MZでも動く**（表示は48×48より小さくなる）。
  https://aispritegen.com/blog/rpg-maker-sprite-sheet-guide

### 6-2 行順（固定・変更不可）
**上から 下（正面）・左・右・上（背面）**
エンジン内部は方向定数 **2=下／4=左／6=右／8=上**、行番号＝**(方向−2)/2** → 0,1,2,3
https://katai5plate.github.io/RPGMV-CoreScript-Reference/jsdoc/Game_CharacterBase.html ／ https://omori-modding.gitbook.io/wiki/rpgmaker/common-notetags-and-filename/rpg-maker-sprite-sheet-formats

### 6-3 再生順（ここを間違えると歩行が跳ねる）
**中央 → 右 → 中央 → 左 → 中央**（列 0→1→2→1 の4拍3コマ）。**中央列が立ちポーズ**で、停止時は中央に戻る（straighten）。
https://www.xehryn.com/tutorials/spritesheets

→ **「立ち・歩1・歩2」の順に並べてはいけない。「歩1・立ち・歩2」の順で並べる。**
→ 本件は F1(接地L)・F2(通過＝立ち)・F3(接地R) の順＝正しい。

## §7 納品前チェックリスト（一般常識編）

1. 何を着ているか言葉で言えるか（本件：フード無しの全身ローブ＋とんがり帽。袖から手が出る＝肩にローブが乗っていなければ嘘）
2. 帽子は眉・耳の上に乗っているか。前のつばは上げ、後ろのつばは沈んでいるか
3. 後頭部は隠れているか（背面で顔のような明るい帯が出ていないか）
4. 髪は耳の高さ以下の帯からしか生えていないか。頭頂から生やしていないか
5. 髭は口・顎と同じ方向を向いているか。横顔で手前に残っていないか
6. 横顔で鼻先が額より前に出ているか
7. 持ち物は手に付いているか。向きごとに手の位置を変えたか。左右を反転で済ませていないか
8. 奥の腕・持ち物は1段暗く、体の後ろに隠れているか
9. 4方向でキャラの大きさ・接地線・影が同じか
10. シートの列順は「歩・立ち・歩」か。行順は 下・左・右・上 か

### 検証できなかった項目（正直な申告）
- 水平なつばが見下ろしカメラで後頭部を隠すことを明言した一次資料は見つからず。幾何からの導出。
- 耳より後ろの頭部の奥行き（tragion→後頭部）のmm実測値は取得できず（ANSUR/NISTの表がJS描画・CDC等はアクセス不可）。50%は美術canonによる。
- 男性の平均的な髪の長さ・長髪率の年代別データは存在を確認できず。「老人＝短髪」は記号としての採用であり統計的裏付けはない。
- 肩や頭の高さで握る杖（ファンタジー式）のバイオメカニクス文献はなし。胸高より上は「体重を預ける道具」ではなく「持ち物」になるためステッキ・ポールのデータは適用外。
