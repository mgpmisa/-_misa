# 質感辞典 — ドット絵の材質別グラデーション規則

最終更新 2026-08-10 / 対象サイズ 16〜48px / 作成: ドット絵専属Claude

> **この文書の使い方**: 描く前に対象の材質を決め、該当セクションの「階調」「ハイライト」「輪郭」「固有パターン」を読む。
> 材質を決めずに全体へ同じ密度をかけると質感が死ぬ（実際に一度失敗した。§0-4参照）。
> 信頼度: **【確】**=出典に明記 / **【導】**=一般則からの派生 / **【実】**=参考資料の実測 / **【未】**=未確認

## 0. 全材質に共通する土台

### 0-1. 階調の段数はキャンバスサイズで決まる 【確】

| サイズ | 段数 | 構成 |
|---|---|---|
| 16×16 | 2段 | ベース＋影1 |
| 32×32 | 3段 | ハイライト＋ベース＋影1 |
| 48×48 | 3〜4段 | ＋影2 |
| 64px以上 | 4〜5段 | 強ハイライト＋ハイライト＋ベース＋影1＋影2 |

1パーツ2〜3色、キャラ全体で6〜12色。実制作の色数実測は 32px=20〜26色 / 48px=29〜30色 / 64px=24〜26色（1色に3〜4階調）。

### 0-2. 影色の作り方は3操作 【確】

1. 明度を下げる
2. **彩度をわずかに上げる**（下げると濁る）
3. 色相を寒色側（青紫）へ寄せる

金だけは例外で、影も暖色（深い茶〜暗いオレンジ茶）に保つ。寒色グレーを混ぜると鉄に見える。

### 0-3. 輪郭とselout（選択的輪郭） 【確】

- 輪郭は**常にコントラストを上げるもの**。対象より暗く、かつ背景より暗い色にする。
- 純黒 `#000000` は使わない。**本体最暗色をさらに暗くした色**にする。
- selout 4手順: ①シルエット全体を暗色1pxで囲む ②光の当たる側（上/左）の輪郭を明るい本体色に置換 ③背景と接する側（下/右）は暗線を残す ④必要なら暗線と本体の間に中間色を**1pxだけ**挟む
- 1px輪郭は**斜め接続のみ**でつなぐ。曲線は上下左右で線分を最長にし、中間へ向かって段階的に短くする（1,1,2,3 または 2,1,2 のリズム）。
- 接地・接触している箇所は輪郭を省く。

**実測の反例**: 参考Basicの輪郭は**左上の縁100% / 右下の縁70%** が `#1d1d1c`。つまり「左上を明るくするselout」は使っていない。**輪郭被覆1.000は不正解ではない**。【実】

### 0-4. 材質ごとに密度を変える（最重要） 【実】

全材質に同じ密度をかけると失敗する。指標は**「ゴツゴツ率＝階調が上がって下がる山谷の割合」**を使う。「色が変わる率」では滑らかなグラデーションと斑の区別がつかない（滑らかな階調も毎px色は変わるため）。

| 材質 | ゴツゴツ率の目安 | 理由 |
|---|---|---|
| 肌 | **0%** | 単調な階調のみ。山谷が出た瞬間にゴツゴツする |
| 木（円柱） | **0%** | 節や傷を入れると劣化した木材に見える |
| 布の上部 | **0%** | 平坦で乱れていない面に襞線を入れない |
| フェルト（帽子） | 〜20% | 稜線ハイライトの分だけ |
| 布の裾 | 50%前後 | しわは下へ行くほど増やす |
| 毛の先端 | 50%前後 | 生え際0% → 先端50%の勾配をつける |
| 鱗・鎖・キチン | 50〜70% | 単位が反復する材質のみ高密度が許される |

### 0-5. 凸と凹の判別 — 中央に濃い色を置いてよいのは凹だけ 【実】

**依頼主からの指摘**: 髭の中心に濃い色が入って浮いてしまっていた。**立体感を出したいので各部位の中央値は明るめにすること。中央がくぼんだコインのような凹は中央に濃い色を持ってきていいが、ふくらみを表現する物体は気をつける。**

| 形状 | 中央 | 外周 | 例 |
|---|---|---|---|
| **凸（ふくらみ）** | **最明** | 暗い | 顔・髭・帽子の円錐・杖の柄・宝石・スライム・腕・脚 |
| **凹（くぼみ）** | **最暗** | 明るい | 中央がくぼんだコイン・皿・穴・溝・鱗の境目・布の襞 |

**凸の面に「左右より濃い1px」が入ると、その点が浮いて見える。** 髭の分け目のような中央の暗線は、構造としては正しくても凸の表現とは矛盾する。

**検査法（必達）**: 各部位について「左右より濃い1px＝面に浮く暗点」を列挙する。

- **凸部位（肌・髭・帽子・杖・宝石）は 0件が必達**
- **布は縦に2行以上続く襞だけ許容**。単発の1pxは汚れに見えるのでNG
- **裾の最下行のほつれは免除**（波打つ表現として正しい）

行が下がるにつれて全体を暗くする勾配（髭の生え際→先端）は、**各行の中央を最明に保ったまま行全体の明度を下げる**ことで両立させる。

### 0-6. ディザの使い分け 【確】

- 5段ラダー: 100 / 75:25 / 50:50（市松） / 25:75 / 0
- パターン→材質: **stripe=木目・布・風** / **crosshatch=金属・重い質感** / **random=土・岩・汚れ** / bayer=空・水・光 / 市松=グラデ・影
- **禁止**: 画面全体 / キャラ輪郭の上（シルエットが壊れる） / 16px以下のスプライト / 3色以上同時 / 明度差が大きすぎる2色（ちらつく）
- ディザが最も有効なのは「グラデ」と「質感」の二重の仕事をする時（例: 鎖帷子）

**実測の教訓**: 32pxで `(x+y)%2` の市松ディザを使って密度を上げようとしたら**機械的な網目**になった。参考Basicの階調地図は y14 と y15 が完全同一＝**縦縞**であり、ディザではなく襞・毛筋・木目という**構造**だった。【実】

### 0-7. 共通の禁止事項 【確】

- **均等グラデーション** → ツヤツヤのプラスチックに見える。許されるのは「工業製品でピカピカの新品」のみ
- **ピロー・シェーディング** → 輪郭沿いを一様に暗くする。光源が読めず平坦になる
- **バンディング** → 物体の内側の縁の全周に影色1pxを置く
- **孤立ピクセル** → 同色クラスタに接続しない単独1px。ただし大きな質感の一部として関連していれば許容
- **黒 2×2 の塊** → 視覚的に極めて目立つノイズになる
- **ハイライトの散らしすぎ** → 色のアイデンティティを失う（赤が「光るピンク」になる）。数か所の「スイートスポット」だけ残す

## 1. 無機物

### 1-1. 金属（鉄・鋼）

| 項目 | 規則 |
|---|---|
| 階調 | マット材より**明暗レンジを広く**。遷移は硬く急＝**不等間隔**（明部から暗部へ 1-1-3-2 のように飛ばす）【確】 |
| ハイライト | **細く鋭く、磨いた面ではほぼ純白**。「thin stripe or small shape」。硬貨サイズなら白1px、剣なら2px。円柱では中心でなく**エッジに沿わせる**【確】 |
| 輪郭 | 均一な暗色枠にせず、明るさが光の向きに従う「shaded outline」。上側の輪郭は1段明るい色に置換【確】 |
| 固有パターン | ①**影部の最下端に1段明るい帯**（地面の映り込み）＝非反射材との決定的な差 ②環境の映り込みは「上端＝空(明)／下端＝地面(暗)」 ③**傷は必ず明側と暗側の2本の平行線**（1本線は不可）【確】 |
| 禁止 | ハイライトを柔らかく・広く・暗くする／環境反射を入れない（真空に浮く）／傷を1本線で描く／**中間色を無彩色グレーで作る** |
| 識別点 | 基色は**無彩色グレーではなく青みがかったグレー**。これで初めて銀色に読める。風化した鉄は赤みを少し、銅はオレンジ寄り |

**鉄 vs 石**: 鉄は「不等間隔の急な階調ジャンプ＋幅1〜2pxの近純白鏡面＋下端の反射光バンド」を持つ。石はこの3つを全て持たない。
**鉄 vs 木**: 鉄は方向性のない鏡面、木は方向性のある木目。

### 1-2. 金（真鍮・金貨）

| 項目 | 規則 |
|---|---|
| 階調 | **黄→オレンジ→（深い影で）赤**の色相移動をランプに組み込む。**全域で暖色を保つ**【確】 |
| ハイライト | 金は**銀より暗く、輝きも弱い**。明部は光が最初に当たる面ではなく**反射が視線に返る面**に置く。小サイズでは最終工程で輝きを抑える【確】 |
| 輪郭 | 背景から抜けるための輪郭を追加（コントラスト優先） |
| 固有パターン | 積んだ硬貨を**太い分割線で区切らない**。暗部の内側にだけ影のディテールを足す。金同士が向き合うと多重反射でオレンジのグローが生じる。彩度は 金 > 青銅 |
| 禁止 | 影に寒色グレーを混ぜる／黄色1色＋白ハイライトだけで済ませる（オレンジの中間段がないと平坦なプラスチック） |
| 識別点 | **金 vs 鋼は影の色相で決まる**。鋼＝寒色ミッドグレー基色＋青灰の影／金＝全階調暖色＋暖色茶の影 |

### 1-3. 甲冑（板金・鎖帷子）

| 項目 | 規則 |
|---|---|
| 階調 | 板金は金属のレンジ規則をそのまま使う。**平面（頬当てなど）も単一の均一色にしない**【確】 |
| ハイライト | **面と面の境界に中央を通るはっきりした線**を引き、片面と他面の明るさを分割する。ベベル（縁の面取り）には細い曲線のハイライトを1本。筒状部＝円柱シェーディング、丸い天頂＝球＋円柱の併用【確】 |
| 輪郭 | まず1色の輪郭を引き、その後**隣接する内部色に合わせて明るく／暗くブレンド**【確】 |
| 固有パターン | リベットは兜の側面。バイザーの通気孔は**点列**。摩耗は「馬上槍試合の擦り傷」。金装飾は十字などに |
| 鎖帷子 | **市松の目の間隔・行のオフセット量は【未】**。確実に言えるのは①市松ディザは最低解像度で中間明度を作る最も一般的な手段で、パターンを反転すれば別の明度が得られる ②粗い面は「広く・柔らかく・鈍い」ハイライトになり、磨いた面の「鋭く狭い」と逆 |
| 識別点 | **板金**＝2面を分ける明確な境界線＋ベベルの細い曲線ハイライト／**鎖帷子**＝境界線を持たず、広く鈍いハイライト＋中間明度のパターン面 |

### 1-4. 宝石（カット石）

最も具体的な規則が取れた材質。

| 項目 | 規則 |
|---|---|
| 階調 | **基本4〜5色**で役割が固定。最暗色＝**高彩度・低明度** / 本体色2〜3色＝高彩度・高明度＋暗色 / 光の当たる部分＝**低彩度・最高明度（ほぼ白）**。各ファセットは**フラットな1色**にし、面の内部でグラデを作らない【確】 |
| ハイライト | 透明な石では**「光が最初に触れる場所ではなく、光が止まる場所（＝光源の反対側）が最も明るい」**。ここが金属と真逆。明るくない部分はかなり暗くしてよい【確】 |
| 輪郭 | **面の境界を線で描かない**。色の違いだけで表現する。外周はシャープな幾何エッジを保つ【確】 |
| 固有パターン | ①**キャンバスの偶奇**: 四角ベースなら偶数px、丸ベース（特に円形）なら奇数px（実例16×16と33×33） ②**ファセット分割**: 内側に上面（テーブル）のガイド線を引き、ガイド線と外周を直線で結んで多面体化。円形石は**外周を16等分** ③キラキラ増強は**色相を少しずらした色**で塗る【確】 |
| 禁止 | 面境界に線を引く／面の中でグラデ／**濁った石や柔らかい石を多面体加工する**／ダイヤの分散（虹色）をやり過ぎる |
| 識別点 | **宝石 vs 金属**: 金属は環境を映す（上＝空／下＝地面）が、宝石は単一の固有色を保ち、明部が光源の反対側に来る |

**実績**: 32px杖の玉（4段: 左上に最明1px→明→中→右下に陰）は依頼主から「球体をよく再現できている」と評価された構成。

### 1-5. ガラスのビン・ポーション

| 項目 | 規則 |
|---|---|
| 階調 | 実例24×24。中身の液体／栓／**ガラスと液体が重なる混色**／白のハイライト／暗色の影。16×16では「液体が透けて読める・**下側を暗い値にする**・上面はカーブしたメニスカス」【確】 |
| ハイライト | **胴と首の両方に小さな明部**。胴のハイライトは球面に見えるよう**わずかにカーブ**させる。16×16では1pxのハイライト気泡＋白い反射のスジ【確】 |
| 輪郭 | **半透明のガラスを内部に塗らず「境界だけ」描く**＝これで透明感の錯覚が成立。ただし外周は最暗部へ向けて影を強め、非常に強い輪郭を作る【確】 |
| 固有パターン | 描き起こし順は①液体②容器③栓④反射。**混色ピクセル（赤＋ガラス→ピンク）を明るいエリアに集中**させる。液面は円形の上面を見せ、液体の縁にサインカーブ状の波を入れる |
| 禁止 | **ディザを盛ってアルファ透明を模倣する**（最大の批判点）／背景が不定なのに実アルファに依存した設計 |
| 識別点 | **ガラス vs 宝石**: ガラスは内部を空けて境界のみ＋小ハイライト1〜2か所、宝石は内部をフラットな面色で埋め尽くす |

### 1-6. 鉱石・原石

専用チュートリアルは存在せず**大部分が【未】**。確実に言えることのみ:

- **原石は多面体化しない**。「濁りがあるか柔らかい石は多面体加工に向かない」→ 宝石の16等分・直線ファセット手順を原石に適用してはいけない
- 母岩＋結晶で構成し、**結晶部分だけ**に宝石の色役割（高彩度＋低彩度最高明度）を使う。母岩は石の規則で処理
- 同系色の環境に置くときは**わずかに色相をずらす**（砂漠の岩は砂より少し赤く）
- 【未】結晶の本数・角度の定石、鉱脈のpxパターン、光る鉱石のグロー半径

### 1-7. 石・岩

| 項目 | 規則 |
|---|---|
| 階調 | 少色数から段階的に（2色→4色）。練習サイズは24×24。**影は躊躇せず思いっきり濃く**——薄い影は遠目から分からない【確】 |
| ハイライト | 光源は横からより**上から**。**太陽がエッジに45°で直接当たるように**置くと、エッジが鋭さではなく丸みとして読める。輪郭線の上側を1段明るい色に置換【確】 |
| 輪郭 | 大きめの石は輪郭先行（角ばった線が鋭く硬い印象）、小さい場合は輪郭工程を省略。selout を欠けたディテールの定義付けに使う |
| 固有パターン | ①シルエットは**面取りされた円錐**——完全な垂直エッジを避け内側にテーパー ②岩肌は「垂直か水平のどちらかに、焼き網の跡のように」擦り傷を全面に引き、**その後で過剰な傷を削除** ③造形不足の兆候は**影の厚みが足りない**こと |
| 禁止 | **グラデーションを作り過ぎる**（影が薄い＋グラデ多用で何なのか分からなくなる）／擦り傷を消さずに残す |
| 識別点 | **石 vs 氷**: 同じ形のまま色を青に振ると氷として読まれる（形は共通、色相で分岐） |

### 1-8. 木材

| 項目 | 規則 |
|---|---|
| 階調 | **最低2段の茶**。木目の階調遷移は**急な段差ではなくグラデーションのように滑らかに**——金属とは逆方向の設計【確】 |
| ハイライト | **影色とハイライトの両方を「縦線」として使って模様を作る**。下側は基本的に影、さらに片側も影に（斜め光の方が自然）【確】 |
| 輪郭 | 真っ黒より、対象に近い暗い色（濃いブラウン） |
| 固有パターン | ①木目は**ほぼ平行だがくねくね**、一定の方向に従わせる ②節は**楕円／卵形** ③**板の構造を先に作り、木目は板ごとに適用**（面全体に一律で敷かない） ④文脈で十分伝わるなら木目テクスチャは不要 |
| 禁止 | テクスチャの入れ過ぎ＝「シロアリに食われたよう」／木目線に沿って急なコントラストを作る／木目沿いの色置き間違いによる「凹んだ」見え方 |
| **実測の教訓** | **32pxの杖（2px幅の円柱）に節や傷を入れたら「ボロボロで劣化している」と指摘された。2px幅の円柱は左列を明・右列を暗にして下へ1段ずつ落とすだけにする**【実】 |

### 1-9. 骨

技術解説が最も乏しい材質。

- ハイライト: **眉（眉上隆起）・頬骨・前頭部**をハイライトにして頭蓋に立体感を与える【確】
- キャンバスは**48×48**（通常32×32だが、ディテールのため拡大）
- **小サイズでは肋骨を全部入れない**——数本だけ見せて概念を伝える。**膝の皿は目立たせる**
- 曲線と極小ディテールを伝えるためAAを積極的に使う
- 汚れ・湿地の骨は脚の骨を暗いトーンに
- **骨の基色を純白にしない**【導】——白い基色ではそれより白い鏡面色が作れなくなる
- 【未】色数・段数、輪郭の規則、禁止事項

## 2. 有機物と布

### 2-1. 布（綿・麻／絹／ベルベット／襞）

| 項目 | 規則 |
|---|---|
| 階調 | 32pxで3段。布は**影の境界を柔らかく**＝段の面積を大きく取り、境界を折り返しの位置に置く【確】 |
| ハイライト | 綿・麻は**最小限（マット素材）**。絹は数pxで立てる。**ベルベットはハイライトを付けない**【確/導】 |
| 輪郭 | **襞をアウトライン（線）で囲まない**。襞は影・ハイライトのみで定義する【確】 |
| 固有パターン | ①襞線は**シルエットの最も鋭い曲がりに接続**させ、**形が方向を変える点から発生**させる ②襞は**関節（肘・膝・肩）と生地が寄せられている点から放射**する。裾が広がる布は下端から外へ放射、絞られた布は絞り点からゴムバンドのように放射 ③**大きな襞の間に「カーブしたU字」**を入れると柔らかさと奥行きが出る ④明るい部分が手前、暗い部分は生地が下に寄っている ⑤腕・脚・靴下のような筒は**個別のシリンダーとして陰影**を付ける ⑥柄は襞と影に従って曲がり、非常に暗い影の中では消える【確】 |
| 禁止 | **平坦で乱れていない面に襞線を入れる**／姿勢が非対称なのに**襞を左右対称に置く**／マット布にハイライトを乗せる／**襞に黒線を使う**（黒に囲まれた色は暗く濁り、全要素が同一平面に押し込まれ平坦化する） |
| **実測の教訓** | **しわは1pxの縦線を2行以上またいで並べ、行が下がるごとに本数を増やす**（32pxローブで y20=1本 → y21=3本 → y22=5本）。1行だけの単発や1pxおきの配置は**縞模様**に見えてローブ感が消える。上部のゴツゴツ率0%、裾54%が実績値【実】 |
| 識別点 | 金属＝高コントラスト＋1〜2pxの鋭いハイライト／布＝**低コントラスト＋境界が柔らかい＋ハイライトほぼ無し**。布と木材の差は「線が襞（放射・可変）か木目（平行・不変）か」 |

### 2-2. 革

- 【未】ピクセルアート専門文献に革の記述を確認できず
- 適用できる一般則: 艶のある革は**gloss則＝数pxで立てる**、なめし革は**dull則＝ハイライトを付けない**
- ベルト・ストラップのような細部は1px線で描く

### 2-3. 毛皮・獣毛

| 項目 | 規則 |
|---|---|
| 手順 | **先に陰影クラスターを「blob（塊）」で置き、次にそのクラスターの縁をギザギザ／波打つ形にする**【確】 |
| ハイライト | 【未】。「ふわふわ素材」はdull寄りに扱われている |
| 輪郭 | **ふわふわ素材は柔らかい有色の輪郭**にする（黒の硬い輪郭にしない）【確】 |
| 固有パターン | ①**毛を一本ずつ描かない。32px前後では毛の房を一本も描かなくてよい場合がある** ②**毛皮のパッチの中に「少数のスパイクや波」を入れる**だけで質感は暗示される ③少し陰影を付けた**後に**小さな尖ったタフト（房）をスケッチする ④少数のクラスターを繰り返し**分布パターンだけを変える**【確】 |
| 禁止 | 小スプライトで一本ずつ再現しようとする／装備など他の重要要素を犠牲にして毛を描き込む／**シルエット構造を作らずに毛の質感を落書きする** |
| 識別点 | **毛皮 vs 髪**: 毛皮は「**面（パッチ）の縁をギザギザにする**」、髪は「**房＝リボンの塊として流れを作る**」。**毛皮 vs 布**: 布はシルエットの縁が滑らかで内部に襞、毛皮は**シルエットの縁自体がギザギザ** |

### 2-4. 髪・髭

| 項目 | 規則 |
|---|---|
| 階調 | 32pxで3段が基本。実作例では4〜5層（ベース＋影2＋ハイライト2）まで【確】 |
| ハイライト | **前面に向いた部分に置く**。前髪はカーブを強調するため上部に。頭部全体のハイライトは球の陰影に従い**「ヘイロー（光輪）」**の形になる。**影とハイライトは控えめに使い、支配させない**【確】 |
| 輪郭 | 輪郭線なしで始めても、陰影の付け方だけで輪郭のように見える箇所ができる（lineless）。その縁は周囲をハイライトして整える |
| 固有パターン | ①**毛を一本ずつ描くには小さすぎるので「clump（房）」で描く** ②房を**「リボンの塊」**として捉えると流れが理解できる ③**主な房のflow lineは後頭部のつむじから出る** ④手順は「単色でblobを置く→影とハイライトで形を洗練」 ⑤主形状ができた**後に**はぐれ毛を数本追加【確】 |
| 禁止 | **髪を頭の輪郭に近づけすぎる（顔が大きく見える）**／影とハイライトを付けすぎる／毛を一本ずつ描く |
| **髭の実測ルール** | **生え際は最明の1〜2色でほぼ均一（ゴツゴツ率0%）にし、先端に向けて階調を増やしながら暗くする（先端50%）。縦線を全長に通すと縞模様になる。中央に1pxの分け目を入れると房として読める**【実】 |
| 識別点 | 髪＝大きな房が流れ、ハイライトが光輪状に一本通る／毛皮＝小さなギザギザが面全体に散り、ハイライトの帯はできない |

### 2-5. 鱗（爬虫類・魚・竜）

| 項目 | 規則 |
|---|---|
| 階調 | 面全体は**球として扱う**。光は直接当たる所が最も明るく、曲面を回り込むにつれ値が下がる【確】 |
| 輪郭 | **選択的輪郭。光が届く所は明るい輪郭、純黒は光が入り込めない所だけ。「全周に黒」は禁止**【確】 |
| 固有パターン | ①鱗板・甲羅は**crevice（溝）線で区切る。溝線は殻の3D形状に従わせ、均一に配置しない** ②**溝は純黒にしない。溝が受ける光量は「光がその溝にどれだけ直接向いているか」に比例** ③影は殻の下・脚が接する所に出る。**地面からの跳ね返り光**を考慮 ④レンガ則: **全ての単位を描くとノイズになるので一部の領域を空ける**。各単位の輪郭を強調しない。粗い質感を狙うなら**一部だけに影/ハイライトを足す**と数枚が飛び出したり沈んだりして質感が一変する【確】 |
| 禁止 | 上のピクセルを一律に明るく／下を一律に暗くする／明るい場所に純黒の輪郭／溝を純黒で塗る／全ての鱗を描き切る |
| 実測 | 参考Basicで鱗・鎖を持つ個体は隣接pxの変化率**70%**に達する。鱗は高密度が許される数少ない材質【実】 |
| 【未】 | 「2〜3pxの弧を市松にずらして並べる」等の具体的な鱗パターン数値 |

### 2-6. 羽根・翼

- **ピクセルアートに特化した羽根の作図ルールは【未】**（存在する資料は画像のみ）
- 適用できる一般則: **重なるアーチ形を連ねる**（雲の作り方）／反復＋分布変化／一部を空けて質感を暗示する

### 2-7. 人の肌

| 項目 | 規則 |
|---|---|
| 階調 | 32pxで3段。**柔らかいグラデーション**＝段の境界を長い緩い曲線にする。色相ランプは**影＝グレー寄りの暖かい紫／中間＝オレンジ／光＝ほぼ黄色**。屋外なら影に冷たいグレー、光に黄色を混ぜる【確】 |
| ハイライト | **控えめ**。影は暖色寄り（やや赤）【確】 |
| 輪郭 | selout。**口や鼻などの造作は「一般の暗色よりさらに暗い肌色」で描く。純黒を使うと口が開いているように見える**【確】 |
| 固有パターン | ①**顔は他の部位よりコントラストを下げる**（表情の可読性のため） ②**16×16では腕は1px幅。2pxにすると胴と融合する** ③目のサイズ: 最小1×1、16×16標準で1×2または2×1、32×32で2×2＋ハイライト ④**筋肉を示す線は1px**【確】 |
| 禁止 | ピロー・シェーディング／顔を高コントラストで陰影する／口に純黒／**黄色で影を付ける**／目を細めて明部と暗部が区別できない |
| **実測の教訓** | **32pxの顔に1px単位の交互配置を入れたら「ゴツゴツすぎる」と指摘された。肌はゴツゴツ率0%＝中心が明るく外へ単調に暗くなるだけの階調にする**【実】 |
| 識別点 | 肌と布はハイライトの有無で分ける（肌は控えめにあり、マット布はほぼ無し） |

### 2-8. モンスターの皮膚（ぬめり・ゴツゴツ）

| 項目 | 規則 |
|---|---|
| 階調 | **絶対黒に至るまで暗色を約3段、明色を1段（明るい点）**が実作例の構成。色相は**影を寒色（紫）寄り、ハイライトを暖色（黄）寄り**へシフト【確】 |
| ハイライト | ぬめり＝**数pxで立てる**。ゴツゴツ＝**反射ハイライトを持たない場合がある** |
| 輪郭 | エッジは常に隣接ピクセルよりパレット上で**1〜2段暗い色**にして可視を保つ |
| 固有パターン | 手順は「グレースケールで陰影→overlayでベース色を乗せる→統合して調整」。**粗い質感（殻など）にはディザを足し、殻の折れ目（kink）をフェードさせる**。ゴツゴツにはrandomディザ、重い硬質感にはcrosshatch |
| 禁止 | 設計スケッチを飛ばす／dull（ゴツゴツ）な皮膚にハイライトを散らす／ディザを輪郭上に置く |
| 識別点 | ぬめり＝小さく集約した高輝度ハイライト＋滑らかな段／ゴツゴツ＝randomディザのパッチ＋ハイライト無し。**同じ皮膚でも「ハイライトの有無」で二分される** |

### 2-9. スライム・粘液・半透明

| 項目 | 規則 |
|---|---|
| 階調 | 2段の間の遷移を柔らかくしつつ、**シルエットにはコントラストを足す**【確】 |
| ハイライト | 最も明るい色で光源が明白になるよう置く。**内部に物体を入れる時はハイライトを除去または減らす**【確】 |
| 輪郭 | **明るい輪郭を与えると半透明に見える**——これが半透明表現の核【確】 |
| 固有パターン | ①**内部の物体は「内側の暗い影」で示す** ②**ベースを少し外へ広げるとぷるぷるに見える。硬く見せない** ③動く時は必ずスクワッシュ＆ストレッチ（外へ伸びる分、内側が潰れて体積を補償） ④水は「透明感＋ハイライトで波紋を示す」 |
| 禁止 | 内部に物体を入れたままハイライトを残す／硬い立体のような形／半透明なのに輪郭を暗くする |
| 識別点 | **半透明の決定的サインは「輪郭が明るい」こと**。不透明素材は輪郭が暗い。この1点で全材質から分離できる |

### 2-10. キチン質（虫の外殻）

- **【未】** キチン質・甲虫外殻の専門解説は確認できず
- 適用できる一般則: 殻は粗い質感なので**ディザを足し折れ目をフェード**／**crosshatchディザ＝金属・重い質感**／分節は**溝線で区切り、溝を純黒にしない**
- 硬く光る殻であればgloss則＝数pxで立てる
